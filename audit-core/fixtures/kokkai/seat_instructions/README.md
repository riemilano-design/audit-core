# 席に渡した指示文(記録)

国会会議録の限定デモで、独立の 2 種類の席に渡した指示文をそのまま写したもの。**独立性を監査できるようにするため**に置く(席に何を渡し、何を渡さなかったかは、指示文を読まないと確かめられない)。

| file | 席 | 渡した材料 |
|---|---|---|
| `writer_seat.md` | 要約を書く席(1 回目・2 回目で別の席。会議の JSON の道と出力の道だけが違う) | 会議録の API 応答 JSON **1 本だけ** |
| `checker_seat.md` | 確認の席(1 回目・2 回目で別の席) | 会議録の JSON と、**書き手の席の要約 JSON** の 2 本だけ |

**どちらの席にも渡していないもの**: engine の出力(`out_*.json`)、engine のコード、計画・結果の文書、混入の記録、他の席の回答。指示文の本文にも engine の状態の語(GROUNDED・VALUE_MISMATCH など)は書いていない ― 確認の席の答えの語は 正 / 誤 / 対象外 / 判定不能 の 4 つだけである(memory: 盲検の席に渡す材料は否定文でも漏れる、の対策)。

**司令塔が席に申告させたこと**: 書き手の席は「引用と数を自分で機械確認したか」を報告した(2 回とも「した」と申告)。この申告は結果の文書に書いてある(1 回目 §4-3、2 回目 §4-3)。
