# 判定席への指示(2026-10-14)

あなたは、ある提出書類の本文の文と、その書類の元データ(XBRL の fact と context)だけを見て、
**各行の文が指している数値が、元データのどの fact に当たるか**を独立に判定する席です。

## 見てよいもの(この 3 ファイルだけ)

- `material_<docID>.json` ― 判定する行(文・対象の数・位置の手がかり)
- `facts_<docID>.json` ― 元データの fact(要素・context・値・単位・decimals)
- `contexts_<docID>.json` ― context の期間と member

他のファイル・他の席の回答・過去の回答・この書類についての外部の知識は見ない。
見たものがあれば「読んだファイル」に正直に書く。

## 答え方(1 行につき 1 object。`行` の配列に、material と同じ順で)

```json
{
  "行の鍵": "H-001",
  "判定": "独立判定" または "判定不能",
  "形": "単一" | "差(当期−前期)" | "率(比)" | "和" | "ポイント差" | "符号・方向" | null,
  "fact": [ { "役割": "単一" | "当期側" | "前期側" | "分子" | "分母" | "加算項",
              "要素": "<facts の 要素 をそのまま>", "context": "<facts の context をそのまま>",
              "期間": "...", "値": ..., "単位": "..." } ],
  "計算": "文の数が fact からどう出るか(数式と単位)",
  "文が述べている単位": "...",
  "対象の範囲(文から読める範囲)": "文が語っている範囲を、文中の語だけで短く(例: 全社 / セグメント名 / 不明)",
  "値は一致するか": "一致 | 一致(切り捨て) | 一致(方向) | 不一致 | 確かめていない",
  "同値の他の候補": [ { "要素": "...", "context": "..." } ],
  "判定不能の理由": null または "対象が文書に無い" | "集計項目が文に無い" | "その他",
  "判定の理由": "...",
  "迷った点": "..."
}
```

## 規則

1. **文の語だけで決める。** 文が指す対象に当たる fact が元データに無いときは、近い fact を選ばずに
   `判定不能` とし、`判定不能の理由` を 3 つから選ぶ。
   - `対象が文書に無い`: 文が語っている範囲・対象(例: 文が「グループ全体」や特定の部門を語っているが、
     元データにその範囲の数が無い)の fact が無い
   - `集計項目が文に無い`: 文に数はあるが、どの集計項目かが文から決まらない
   - `その他`: 上の 2 つに当たらない(理由を「判定の理由」に書く)
2. 対象の数が 2 つ以上の fact から出るとき(差・比・和・ポイント差)は、それぞれの fact を役割つきで書く。
3. 同じ値を持つ別の fact があれば「同値の他の候補」に入れる(選んだ 1 つの他に)。
4. 文中の数と fact の値が合わないときは、合わせるために別の fact を選ばない。選んだ根拠を書き、
   「値は一致するか」に `不一致` と書く。
5. 分からないことは分からないと書く。空欄で埋めない。
