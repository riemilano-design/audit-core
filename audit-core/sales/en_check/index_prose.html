英文決算短信の数字の点検 試作: 文章の中の数つき

日本語の決算短信の原本データ(XBRL)と、英文の決算短信の PDF を照らし、数字が食い違う欄の候補を出します。この試作は、英文の「概況」の文章に出てくる金額・率・ポイントも、日本語の「概況」の文章の数と照らします。file はこのブラウザの中で読むだけで、どこにも送りません。

この道具が見るもの・見ないもの

  • 見るもの: 日本語の原本データに入っている数(サマリーと財務諸表の表の数)が、英文 PDF の同じ並びの所に同じ値・同じ符号で在るか。
  • 見るもの(試作): 英文の「概況」の文章に出てくる金額・率・ポイントと同じ数が、日本語の「概況」の文章に在るか。数が在るかだけを見ます。何の数か(どの項目・どの期の数か)は見ません。
  • 見ないもの: 「概況」のほかの文章(注記など)の数、円のほかの通貨の金額、人数・数量など金額と率のほかの数、表の見出し・単位・期の字、英文に載せていない部分。
  • 候補には道具の当て違いが混ざります。「違う」と出た欄は、紙面で確かめてください。候補が 0 件でも、誤りが無いことの保証ではありません。
  • 生成 AI は使っていません。同じ file を入れれば同じ結果が出ます。
