## 2. 確かめ方

母集団: 文章の便と同じ乙 200 組・丙 150 組(手元の file。合わせて 350 組)。比べる相手: 文章の便の出力(`m.json`。sha256 の頭 `1de776fd`。取れた本は乙 119・丙 95、「日本語の文に同じ数が無い」行は乙 30・丙 8 の 38 件。うち AI の席が「数が違う候補」とした行は 24 件。人は読んでいない)。

試験の仕掛け: ページの写しから「どこにも接続できない」設定の 1 行を外し、手元の file を順に読ませる数行を足した物を、画面なしの Chrome で開く(S1 のときと同じ考え方)。木に置くページは設定を入れたまま。1 本ごとの時間はこの便では数えない(仕掛けの時計が当てにならない)。

数えるもの:

- **(a) 切り出しの一致**: 350 組のうち、「文章を切り出せた / 切り出せなかった」がページと script で同じ組の数。
- **(b) 候補の拾い**: 24 件のうち、ページが「同じ数が見つからなかった」に出した件数(同じ組・同じ種類・同じ数の字・同じ単位・同じ頁の行が在れば「出した」)。
- **(c) 出す件数**: ページが「同じ数が見つからなかった」に出す行の、350 組の合計(script は 38 件)。
- **(d) 行の一致**: 両方で切り出せた組のうち、行の集まり(種類・数の字・単位・判定の組を、順を見ずに数えた物)が script と全く同じ組の割合。
- **(e) 確かめた数**: 両方で切り出せた組で、ページが確かめた数(表の中・単位の断り書きに数えた物を除く)の合計と、script の合計の比。
- **(f) 止まる組**: ページが例外で止まった組の数。
