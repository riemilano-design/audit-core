# 収益化の計画(2026-11-10)

人間の決定(2026-11-10): ゴールは「このシステムで収益を生む」。売り方・進め方は司令塔に一任。
この紙は司令塔の案で、額はすべて**司令塔の提案**(測った数ではない)。変えるのは 1 行で済む。

## 1. 選んだ道

**無償診断 → 有償 PoC → 年額の利用料**を主の道にする。並行して「一式の譲渡」の話を 1 社と進める。SaaS は後回し。

| 道 | 採否 | 理由 |
|---|---|---|
| 無償診断 → 有償 PoC → 年額 | **主** | いま在る物(手元で動く engine・日本語の報告)だけで始められる。納品実績 0 件を最短で 1 件にできる。客の文での数が次の営業の材料になる |
| 一式の譲渡(買い取り + 顧問 / ロイヤリティ) | **並行** | コスモアビリティが買う意向。ただし実績 0 件のままだと額が低い。PoC を 1 件取ってから額を決めるほうが高い |
| 出所側との組み(Cabocia) | **並行** | 道具が止めた 2 行が相手の仕様変更に至った。相手の許可が出れば第三者の裏づけになる。「横断して原本と照らす」有償の仕事の種 |
| SaaS | 後 | 置き場・運用・問い合わせ対応が要る。客が 2〜3 社付いてから |

## 2. 売り物と額(提案)

| 段 | 中身 | 額(税別) |
|---|---|---|
| 無償診断 | 客の AI の文 3 本まで。数ごとの区分つきの報告(一致・違う・要確認・対象外・判断しない。見本は `AuditCore_見本の診断レポート_2026-11-10.pdf`)。合意から 2 営業日。原本が EDINET の有報の文 | 0 円 |
| 有償 PoC | 3〜4 週間・30 本まで。見込みを先に書面で出し、結果と並べて報告。つなぎ方の確認 | 50 万円(本導入のとき初年度に充当) |
| 本導入 | 客の環境に設置。年次のタクソノミ改正への対応と保守 | 年額 180 万円〜 |
| 一式の譲渡 | 買い取り + 顧問(12〜24 か月)+ ロイヤリティ | 個別(内部の目安は記憶 `cosmo-ability-buyer-2026-10-20`) |

額の置き方: PoC 50 万円は、部長決裁で通りやすい上限の近くに置いた。年額 180 万円は月 15 万円で、数字の見直しに掛かる人の時間より安く見えるはずの所に置いた(客の見直しの時間は測っていない。仮定)。どちらも客の反応で動かす。

2. **コスモアビリティ**: 資料を送り、「先に PoC を 1 件一緒に取る」形を提案する(相手は売り先を持つ SIer。相手の客 1 社で無償診断 → PoC)。
3. **AI の決算要約を出している事業者**(`docs/SALES_TARGETS_2026-11-02.md` の型 A。3〜5 社): 無償診断の案内を送る。相手の公開している AI 要約を 3 本こちらで診断して付けると返事の率が上がる見込み(測っていない)。公開の文を診断するだけなら 0 USD。**注意: 型 ① の表の相手の多くは原本が決算短信**(MINKABU・Yahoo!ファイナンス・日経)。短信は手元の試行で一致が 4 割台なので、無償診断の対象(原本が有報)から外れる。先に当たるのは有報の文を出している相手(exaBase 企業検索・eol AI レポート。eol は照合の中身を先に確かめる)。短信の相手は、有償 PoC の「つなぎ込み」の話として後に回す。
4. **開示支援・IR 支援の事業者**(型 B): 3 の反応を見てから。
