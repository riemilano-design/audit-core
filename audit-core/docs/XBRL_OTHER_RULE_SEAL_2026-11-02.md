## §1 「その他」の行の拾い方(字で固定)

対象は claims の 415 件(kind は札の file の行。engine の判定は使わない)。
1. **数の位置**: 文(`文`)の中の数の字を正規表現 `(△|▲|-)?([\d,]+(\.\d+)?)(百万円|千円|円|%|ポイント|名|人|株|社|件)` で全部拾い、字の値 × 単位の倍率(百万円 10^6・千円 10^3・円 1・他は 1)が `数` の大きさと一致する(相対 10^-6)ものを数の位置とする。一致がちょうど 1 つ → **位置が決まる**。0 → **位置なし**。2 つ以上 → **位置が曖昧**(その他の判定はしない。数だけ)。
2. **直前の字 W**: 位置が決まる行で、数の字の前の文。末尾の区切り(`:`・`:`・`、`・`は`・`が`・`を`・`で`・`に`・空白)を落とす。
3. **「同」**: W が `(同` か `(同` で終わる → この数は**直前の数と同じ主語の前期の値**。主語は、文の中でその直前にある数の W で決める(同じ手順)。直前の数が無ければ **同(主語なし)**。
4. **「その他」**: W(3 で辿った後の W)が正規表現 `その他(の[^、。::()()\s]{0,8})?$` に当たる → **その他の行**。「その他 37 百万円」も「その他の流動資産 513 百万円」も当たる。
5. **期**: 3 を経た行は 前期、経ない行は 当期。context は、当期 = `CurrentYear` で始まり `_` を含まない context、前期 = `Prior1Year` で始まり `_` を含まない context(member つきの context は除く)。
6. **u**(文の最下位の桁の幅): 数の字の単位の倍率(百万円 10^6・千円 10^3・円 1)。小数があれば 10^(−小数の桁) × 倍率。%・名などは 1(小数があれば同じ)。

**母数**: 札が 真 の「その他の行」。札が 偽・判定不能 の「その他の行」は数だけ(判定しない)。
