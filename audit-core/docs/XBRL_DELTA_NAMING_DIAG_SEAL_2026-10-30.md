### §2-4 差・帯・段(人間の条件 (3)(4)。司令塔の条件 (10)(11)(12))

- **差** `d` = 当期の値 − 前期の値(円。float。§2-2)。

- **帯** `w` = `UNIT_SCALE[unit]`(文の単位の 1 単位: 円 1・千円 1,000・百万円 1,000,000)。
- **段**(機械で 1 か所。この順で 1 つ):
  1. 比較不能(§2-2 の理由のどれか。理由を記録)。
  2. 大きさ: `e = | |d| − t |`。`e == 0` なら「完全一致」の候補、`0 < e ≤ w` なら「許容差内」の候補、`e > w` なら **不一致**。
  3. 符号(増減の型で向きが 増 か 減 に決まった行だけ): 向きが 増 なら `d > 0`、減 なら `d < 0` を期待。大きさが完全一致か許容差内で、符号が期待と逆(`d` が 0 でない)なら **符号不一致**。それ以外は 2 の段(完全一致 / 許容差内)。向きが不明・なしの行は符号を問わず 2 の段のまま(符号は記録に持ち、§2-6 で別に数える)。`d == 0` の行は符号を問わない。
- 大きさの照合に `decimals` の丸めは使わない(帯は文の単位だけ。fact の `decimals` が文の単位より粗い行は記録の欄で数えるだけ。§4 の 6)。

### §2-5 対照・前期残高との一致(司令塔の条件 (9)(13))

- **対照(偶然の一致)**: 同じ書類の instance で、候補の枠 `C` と対の枠 `P`(§2-2)の両方に fact を持つ**候補以外の全要素** `M`(`name != N`、unit が候補の fact と同じ、当期・前期の値の集合がそれぞれ 1 つ)について `d_M = 当期 − 前期` を作り、`| |d_M| − t | ≤ w` の要素の数 `m` と分母(`M` の数)を行ごとに記録する(符号は問わない。帯は候補と同じ `w`)。候補の段を `完全一致 / 許容差内` のとき「候補が一致」として、4 段 + 1: **候補だけが一致**(`m == 0`)/ **候補以外にも在る**(`m ≥ 1`)/ **候補は一致せず別の要素が一致**(候補が不一致・符号不一致で `m ≥ 1`)/ **どれも一致しない**(候補が不一致・符号不一致で `m == 0`)/ **候補が比較不能**(対照は `P` が在る限り作って `m` を記録するが、段は「候補が比較不能」)。記憶の原則: 値が一致する参照がちょうど 1 件でも同定ではない ― 「候補だけが一致」も出所の判定ではない。

## §4 限界(封の時点で分かっている限界。数を見てから足すときは日付つきの追記)
