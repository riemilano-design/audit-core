# Q2(新規接続の正しさ)をどこで測るか ― 2 つの案と司令塔の推し(2026-10-14)

## なぜこの判断が要るのか

最終評価用 8 書類は **8 件とも連結財務諸表を作っている会社**だった(k = 0)。
P20 の落とし込みは**連結の要素がゼロの書類でしか発火しない**ので、この 8 書類では
**P20 が 1 行も動かない**(実測 N-0 = 0)。

結果として:

| 問い | この 8 書類で | 
|---|---|
| Q1 再現性(50 / 10 / 40) | **測れる。**683 行でこれから測る(当初の想定より大きい標本) |
| Q3 誤接続の増減 | **測れた。0 件で通過** |
| **Q2 新規接続の正しさ** | **測れない。**発火しないので新規接続が 0 件 |

**Q2 は既定昇格の決め手**(あなたの条件「誤接続が 1 件でも出たら既定にしない」)なので、
別の書類で測る必要がある。どこで測るかで 2 案ある。

## 案 A: 直し用の 2 書類で測る(`S100YXGH`・`S100Z5CH`)

| | |
|---|---|
| 費用 | **取得 0 件**(開封済み)。ラベル 2 書類 × 2 席 ≒ 400 行 |
| 得られるもの | 新規接続 150 行の**誤接続の絶対値**(N-3) |
| **弱点** | **この 2 書類は P20 を設計するために中を読んだ書類である。**失敗の型を 1 件ずつ読んで規則を作った。つまり**未使用データではない** |

N-3(ポインタが正しい対象を指しているか)は**絶対評価**なので、設計に使った書類でも
「この 150 行は正しい対象を指していた / いなかった」は言える。
**言えないのは「他の会社でも同じ」**で、それはあなたの 3 分割の 3 番目(未使用データでの再現性)そのもの。

## 案 B: 予備 234 件から、連結の無い書類が 2 件出るまで順に引く

封 `88f8e16` §9-2 の並びは**再現を確認済み**(使用済み 6 / 直し用 8 / 最終評価用 8 の 3 群が完全一致)。
予備は `order[22:]` の 234 件で、**引く順番はすでに決まっている**(先頭は `S100YYVN` `S100Z404` `S100Z40G` …)。

| | |
|---|---|
| 費用 | **取得 の見込み 11 件**(連結なしの割合は 22 件中 4 件 = 18.2%、95% 区間 7.3〜38.5%。2 件引くまでの期待値 11 件、上振れで 27 件)。ラベルは 2 書類 × 2 席 ≒ 400 行(案 A と同じ) |
| 得られるもの | N-3 を**未使用データで**。あなたの 3 分割の 2 番と 3 番が同時に埋まる |
| 弱点 | 取得が 11 件前後に増える(API は無料だが、**引いた書類は使用済みになる**ので予備が減る) |

**引き方で封じること**: 「連結の有無だけを機械で見て、連結ありなら**中を読まずに**次へ送る」。
送った書類は予備に戻さず使用済みに移す(名前だけ見た書類を後で未使用と言わないため)。

## 司令塔の推し: **案 B**。ただし Q1 が終わってから

**案 B を推す理由**: Q2 は既定昇格の決め手で、既定昇格は「利用者が受け取る判定を変える」判断。
その根拠が**設計に使った 2 社**だと、あなたが最初に言った「訓練で効いた規則が未使用の書類では
効かなかった」の型を**もう一度踏む**。P17 でそれを実際に見ている。

**順番を分ける理由**: いまラベルの席が使用枠で止まっている。
**Q1(683 行 × 2 席)が未完のまま Q2(400 行 × 2 席)を開くと、どちらも終わらない。**
Q1 は封が済み・材料ができ・あなたの GO が出ている。先にこれを完走させる。

## 決めていただきたいこと(2 つ)

1. **Q2 は案 A / 案 B のどちらか。**(案 B なら、引く上限の件数も決めたい。司令塔の提案: **上限 30 件**。
   30 件引いて 2 件出なければ、そこで止めて「連結なしの会社の割合は想定より低い」と記録し、案 A に落ちる)
2. **ラベルの席の model。** 使用枠が回復するのを待つか、別の model で立てるか。
   **弱い model に差し替えるとラベルの質が落ち、L(2 席が一致した行)が縮んで判定不能に寄る。**
   司令塔は**待つ**ことを推す(封の合格線は L ≥ 100 を要求していて、質が落ちると届かなくなる)。

どちらも**封の本文は変えません**。案 B を選ぶ場合は、引く前に別の封(合格線は本封の N-1〜N-3 を
そのまま流用・引き方と上限を明記)を書き、あなたの承認を得てから引きます。
