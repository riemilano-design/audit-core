## §3 診断(封の外。repo の外の文と engine を 0 USD で走らせて数えた。予測ではないので判定しない)

### §3-1 engine の数の読み取りは「N,NNN万円」「N億N,NNN万円」を読まない

- O が黙った理由を 1 件ずつ追った。F5 の文で「その他」「その他の○○」の直後に数がある箇所 8 のうち、engine が claim にしたのは 1(P27 で既に GROUNDED)と、別の数の % の claim 1 だけ。残りは**数そのものが claim になっていなかった**。
- 【門なし】engine の数の読み取り(`extract.iter_numbers_2026_10_27`。旧の `iter_numbers` も同じ)に合成の文を当てた: 「1234万円」「1億2345万円」「84.2億円」「1,234百万円」「8,420,000千円」は読む。**「1,234万円」「12億3,456万円」(万の部分にコンマ)は読まない。**
- 【門なし】AI の文 200 本(前の便 160 + F5 40)で、円族の数の候補(単位「円」の前の数を緩く拾った)のうち engine が読めない数: F1 1,860 / 3,492・F2 897 / 1,752・F3 595 / 2,375・F4 1,132 / 2,248・F5 1,782 / 3,229。読めない数は**ほぼ全部が万にコンマの形**(その他の形で読めないのは 4)。
- **読めない数は claim にならない**。検査されず、止めた / 通したのどちらにも数えられず、**前の便とこの便のどの率の分母にも入っていない**。前の便の「札 真の行の GROUNDED 率」「札 偽の行を止める率」は、読めた数だけの率。
- 有報の MD&A は百万円・千円で書くので、これまでの実物の便ではこの形がほとんど出なかった(見立て。有報の書類で数えていない)。AI の書き手は「万円」とコンマを好んで使う。

### §3-2 推奨(封 §2-1)の読み

- 封 §2-1 の決め方は「決まった行 < 5 → P27E に戻す」で、機械の推奨は **P27E に戻す**。
- ただし §3-1 のとおり、O の形の数の多くは**読まれていない**ので、O が効くかどうかはこの材料ではまだ測れていない。数の読み取りを直したあとで O の効き方は変わりうる。
- 司令塔の提案: 外部の文の推奨は **いまは P27E に戻す**(P28E が足すものがこの材料で 0 だから。P28E は P27E の上に O を足しただけで、P27E より悪くなった行も 0)。数の読み取りを直す便のあとで O を測り直す。最後に決めるのは人間。
