## 4. C-1 が証明したことと、していないこと

**証明した(構造の側)**: Core は XBRL を知らない(禁止語 0・import の向き・Adapter が語彙・member・P-1〜P-8・期間の鍵・比較の癖を全部持つ)。Core を変えずに XBRL の 224 件が Core の実行器を通って探りと同じ答えを出す。Core の変更 0 で Adapter を 2 段(C-1c・C-1d)足せた。
