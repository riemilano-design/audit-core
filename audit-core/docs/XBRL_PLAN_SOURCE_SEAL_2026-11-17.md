# 封: 便 PS ― engine が「計画・予想の数」として止めた行に、同じ短信のサマリーの予想の fact という当てる先が在るかを数える ― 取得 0・0 USD・engine は 0 行 ― 2026-11-17

人間の問い(2026-11-17):「本当に万能を目指せると言えないの? これまでのやり方にこだわってるから言えないのでは」。司令塔はこう答えた:「これまで『外』と呼んだ行(見積り・計画)は、engine の限界ではなく、**当てる出所を添付の財務諸表だけに絞っていた**せいかもしれない。同じ短信の XBRL の中に当てる先が在るかを数える」。人間は「任せる進めて」と言った。

短信の便 TSS(2026-11-14)は、ZIP の中の `XBRLData/Attachment/` の iXBRL だけを engine に渡した。**サマリー(`XBRLData/Summary/`)は渡していない。** サマリーには業績予想・配当予想の fact が在る。この便は、engine が理由 `target_or_plan` で止めた数と、型の読みで「計画・予想・目標の数」(ウ)とした数について、**同じ ZIP のサマリーの予想の fact に同じ値が在るか**を数える。

この便で言えるようになること(結果が出たあと):「止めた行のうち、同じ短信のサマリーの予想の fact に値が合うものが在る行の割合」と「その割合が、別の短信の予想の fact に当てたとき(偶然の一致)とどれだけ違うか」。**言えないこと**: engine がサマリーを読めばその行を正しく結べること(engine は動かしていない)・値が合った fact が文の言う項目であること(読んだ標本の分だけ、AI の席の読みで言える)。

## §2 規則

### §2-1 行を作り直す

1. 本ごとに、3 の script の `cut` → `wrap` を**呼んで** TSS と同じ包んだ ZIP を作り、`verify_document(包んだ ZIP, "P33E")` と `build_raw_claims` で数の claim を得る(5 の script の `profile_rows` と同じ対応の付け方。鍵は (文の番号, 位置))。
2. 本ごとに、作り直した行(鍵・state・reason)が 1 の記録の行と**全部同じ**であることを確かめる。1 本でも違えば止まる(作り直しが TSS と同じ母集団を指していることの門)。

### §2-2 3 つの組

- **P(主)**: 400 本の数の claim のうち、reason が `target_or_plan` のもの全部。§0 の 1 から 794 行のはず。違えば止まる。
- **W**: 2 の記録の行のうち型が「ウ」の 20 行。(本の #, 文の番号, 位置)で作り直した claim に当てる。当たらない行が在れば止まる。
- **N(並べるだけ)**: 400 本の数の claim のうち、state が `GROUNDED` のもの全部(実績の数として結べた行。予想の fact に合う割合を P と並べる)。

### §2-3 サマリーの fact

1. 元の ZIP の `XBRLData/Summary/` で始まり file 名が `-ixbrl.htm` で終わる member(ちょうど 1 つ。違えば止まる)を、中身を 1 byte も変えずに `XBRL/PublicDoc/summary_ixbrl.htm` として 1 つだけ入れた ZIP を作り、`adapters.xbrl.instance.load_instance` で読む。
2. **予想の fact(F)** = その fact の context の members のどれかの、`:` の後の名前が `ForecastMember`・`UpperMember`・`LowerMember` のどれかであるもの。
3. **予想でない fact(R)** = サマリーの残りの fact。
4. 値が 0 の fact は F からも R からも除く。単位が無い fact も除く。

### §2-4 値が合う(1 つの claim と 1 つの fact)

engine の照合の関数をそのまま呼ぶ。両側に掛ける正規化はここに書いたものだけ。

- **円の claim**(raw の claim の単位が `円` で、`unit_scale` と `claim_scale` が None でない): fact の単位が大文字にして `JPY` で始まる(`JPYPerShares` を含む。engine の候補の取り方と同じ)とき、`vocabulary.match_value(fact の値, claim の値 × unit_scale, claim_scale, None, False)` が None でなければ合う(四捨五入の帯・切り捨ての帯・絶対値での照合を含む、engine の梯子そのまま)。
  - 当たる例: 文「売上高 1,200 億円を見込む」(値 1.2e11・claim_scale 1e8)と fact 120,034,000,000。当たらない例: 同じ文と fact 121,000,000,000。
- **% の claim**(raw の claim の単位が `%`): fact の単位が `Pure` のとき、`abs(fact の値 × 100 − claim の値) <= tol` か `abs(abs(fact の値 × 100) − abs(claim の値)) <= tol` なら合う。tol は raw の claim の `pct_tolerance`(無ければ 0.15)。
  - 当たる例: 文「5.2% 増を見込む」(tol 0.06)と fact 0.052。当たらない例: 同じ文と fact 0.053。
- **ほかの claim**(単位が上のどちらでもない・値が 0・円で `claim_scale` が None): 当てない。「当てない」と数え、分母には入れたままにする(主の率)。

### §2-5 行ごとの札

claim ごとに 4 つの真偽: **自**(その本の F に合う fact が 1 つ以上)・**実**(その本の R に合う fact が 1 つ以上)・**他**(§2-6 の別の本の F に合う fact が 1 つ以上)・**当てない**(§2-4)。ほかに、その本の F が空か。

### §2-6 偶然の一致の対照(別の本の予想の fact)

本を (群, #) の順に並べ、切れた本で F が空でないものだけを群ごとに輪にする。ある本の「別の本」= 同じ群の輪で次の本(最後の本は最初の本)。その本自身が輪に居ない(F が空)ときは、同じ群で # がその本より大きい最初の輪の本(無ければ輪の最初)。輪の本が群に 1 本以下なら止まる。

### §2-7 読み(P で「自」が真の行。AI の席・盲検でない)

- 「自」が真の P の行を (#, 文の番号, 位置) の順に並べ、`random.Random(20261117).sample(range(行の数), 60)` を番号の順に(60 に満たなければ全部)。W で「自」が真の行は全部読む。
- 読むための紙(文・値・合った fact の要素名と context)は **repo の外**に書く。司令塔(AI の席)が 1 行ずつ次の字を付ける: **あ** = 合った fact のどれかが、文の言う項目・期の予想そのもの/**い** = 値は合うが別の項目か別の期(偶然か取り違え)/**う** = 分けられない。
- 記録に持つのは (標本の番号, 本の #, 文の番号, 位置, 字) だけ。文・値・要素名は持たない。

## §3 分母と数えるもの

1. P: 行の数・「当てない」の数・F が空の本の行の数・自・実・他の数。**主の率 = 自 / P の全部の行**(当てない行も F が空の本の行も分母に入れる)。並べる率 = 自 /(当てた行で F が空でない本のもの)。群(甲・乙・丙)別と単位(円・%)別にも。
2. P の対照: 他 / P の全部の行。**自 ÷ 他** の比(他が 0 のときは比を書かず「他は 0」と書く)。
3. P の本: `target_or_plan` の行を持つ本のうち、自が真の行を 1 つ以上持つ本の数。いちばん多い 1 本が持つ自の行の数。
4. W: 20 行のうちの自・実・他・当てないの数。
5. N: 行の数と自・他の数(並べるだけ。予測は §4 の PS-5 だけ)。
6. 読み: 読んだ行の数と あ・い・う の数。
7. 「0」が出た欄は、結果に書く前に script の欠陥を先に疑う(F が全部空になっていないか・単位の字の取り違え・値の倍率)。F の fact の数の合計と単位別の数も記録に持つ。

## §4 予測(司令塔。外れうる形で。盲検ではない ― §0 の形を見たあとに書いた)

| # | 予測 | 外れ方 |
|---|---|---|
| PS-1 | P の主の率(自 / 794)は **20% 以上 50% 以下** | 20% 未満なら「当てる先はサマリーには少ない」= 司令塔の見立ての外れ。50% を超えれば見立てが控えめすぎた |
| PS-2 | P の対照(他 / 794)は **5% 以下**で、自は他の **5 倍以上** | 対照が 5% を超えるか比が 5 倍未満なら、値の一致は偶然と分けられない |
| PS-3 | P の「実」(予想でない fact に合う)の率は **自の率より低い** | 同じか高ければ、止めた行は予想より実績の数に近い |
| PS-4 | W の自は **20 行のうち 6 以上 14 以下** | 5 以下なら、型「ウ」の数はサマリーの予想ではない計画(中期の目標など)が多い |
| PS-5 | N の自の率は **P の主の率の半分以下** | 半分を超えれば、予想の fact への一致は「計画の数」に特有ではない |
| PS-6 | 読んだ行のうち **あ が 70% 以上** | 70% 未満なら、値の一致の多くは別の項目・別の期 |
| PS-7 | `target_or_plan` の行を持つ本 176 のうち、自の行を持つ本は **40% 以上** | 40% 未満なら、当てる先が在るのは一部の本に片寄る |

**読み方の決め(結果を見る前に)**: PS-1 の下の線(20%)と PS-2 の両方に届き、PS-6 が 70% 以上なら「止めた行のまとまった部分に、同じ短信の中の当てる先が在る」と読む。PS-1 が 20% 未満なら「この出所では少ない」と読み、司令塔の見立ては外れと書く。PS-2 か PS-6 が外れれば「値は合うが、当てる先と言えるかは割れた」と書く。

## §5 限界(先に書く)

1. **値が合うことは同定ではない。** 予想の fact は 1 本に 10〜20 個ほどで、桁の少ない数(% の 1 桁など)は偶然に合う。対照(§2-6)と読み(§2-7)はそのために置くが、読みは AI の席 1 席・盲検でない・人は読んでいない。
2. **engine は動かしていない。** サマリーを engine に渡したとき、予想の context を期として扱えるか・正しく結べるか・実績の行の結びを壊さないかは測っていない。「合う fact が在る」は「engine が確かめられる」ではない。
3. P は engine の規則(P27 の未来の期の門など)が止めた行で、文が本当に計画・予想の数かは読んでいない。W は型の読み(AI の席)の 20 行だけ。
4. 当てる先はサマリーの予想だけ。中期経営計画の目標・設備投資の計画・説明資料の数は、この出所には無い(無いことは「外」の残りとして数に出る)。
5. 材料は TSS の 400 本(上場会社の決算短信)。有報の配当政策の「見積り・計画」7 行(便 YS)は、有報に予想の fact が無いので範囲の外。型「エ」(向き・増減の書き方)の 7 行も範囲の外(engine の照合は絶対値でも当てているので、符号だけの違いは作りで 0 になる)。
6. 「あらゆる文書」の根拠にはならない。1 つの種類の文書で、出所を 1 つ足したときの数。
