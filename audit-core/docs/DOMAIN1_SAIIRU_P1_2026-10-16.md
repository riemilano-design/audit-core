## §2 構造

### §2-1 決算書 歳入

- sheet は **1 枚**(`歳入`)。歳出側(`歳出` 1 枚)と同じ作り。
- **会計の表題を 19 件同定した。**歳出側の決算書も 19 会計で、**集合は完全に一致した**
  (歳入だけ 0 件・歳出だけ 0 件)。
- **ただし 19 件のうち 16 件は表題が 2 行にまたがっていた。**
  長い会計名が折り返され、1 行だけ見ると
  `　　　　　　会計歳入歳出決算書`(会計名が空白)になる。
- 階層は **款・項**(歳出側と同じ)。

### §2-2 事項別明細 歳入

- sheet は **20 枚**(`目次` + (1)〜(19))。目次の項目は **19 件**。
- 階層の見出しは **款・項・目・節** ― **歳出側(款・項・目)より 1 段深い。**

### §2-3 **列の集合 ― ほぼ交わらない**

| | 列 |
|---|---|
| 決算書 **歳入** | 予算現額・**調定額**・**収入済額**・**不納欠損額**・**収入未済額**・予算現額と収入済額との比較 |
| 決算書 **歳出** | 予算現額・支出済額・翌年度繰越額・不用額 |
| **名前が共通の列** | **`予算現額` だけ** |

明細 歳入の列は 当初予算額・補正予算額・継続費及び繰越事業費繰越財源充当額・計・
調定額・収入済額・不納欠損額・収入未済額・備考。

**名前が同じでも同じ数とは限らない。**`予算現額` が歳出側の `予算現額` と
一致するかは **6a(値の重複)で別に測る** ― 特別会計は予算が均衡するので、
**歳入の予算現額が歳出の予算現額と等しい可能性が高い。**
等しければ **6a で落ちる**(同じ数の読み直し)。**これは P-2 で測る。**

## §3 **6e(出どころの重複)の判定 ― 再掲・参照は見つからなかった**

「歳出」の字を含むセル・`再掲`/`歳出に同じ`/`歳出参照`/`別表`/`歳出の` に当たるセルを
両方の file で全部拾った。

| | 件数 |
|---|---|
| 再掲・参照(**書類の表題を除く**) | 決算書 **0 件** / 明細 **0 件** |
| **除いた「書類の表題」** | 決算書 **19 件** / 明細 **19 件** |

**除いた形を字で残す**(でないとこの 0 は私の絞り込みが作った 0 になる):
`歳入歳出決算書` / `歳入歳出決算事項別明細書`。
これは**書類の名前**であって、歳出の数を再掲しているという意味ではない。

注記は 2 種類だけで、**どちらも歳出を参照していない。**

- 決算書 歳入: 「注：収入済額欄(　)内は還付未済金」
- 明細 歳入: 「注：備考欄の徴収猶予額は収入未済額のうち徴収猶予に係るもの」

### §3-1 P-1 の判定

**歳入側の 2 冊は、歳出側の 2 冊の再掲ではない。**
自分の列(調定額・収入済額・不納欠損額・収入未済額)と、
歳出側より 1 段深い階層(節)を持ち、**歳出への参照を含まない。**

**ただしこれは「独立した証拠になる」という結論ではない。**
6a(値の重複)・6b(代数的な導出)・6c(親子)・6d(一意性)は**まだ測っていない。**
**`予算現額` は 6a で落ちる見込みが高い**(§2-3)。

## §4 **先に私が 2 つ間違えた(数を記録する前に直した)**

| 誤り | 症状 | 直し |
|---|---|---|
| セルの値を `['v']` で読んだ(実際は `['value']`) | **「歳出を含むセル 0 件」と出た。**これは資料の事実ではなく私の欠陥 | 鍵を直して読み直したら 21 件・2 件が出た |
| 表題を 1 行だけで判定した | **19 件のうち 3 件しか同定できず、「会計の集合は歳出と違う」と出た** | 2 行にまたがる表題をつないだら **19/19 一致** |

**どれも「0 件」「違う」という形で出た。**記憶 `zero-count-may-be-my-own-bug` の型である。
**資料の事実として記録する前に、自分の読み方を疑って直した。**

### §4-1 緩める変異 ― **2 本が黙った。1 本は同値・1 本は歯が無かった**

| 変異 | 結果 | 対応 |
|---|---|---|
| 見出しから**階層の列を外す枝**を消す | 黙った | **同値だと測って確かめた。**見出しは `科目` の行とその次の行だけを見るので、余分に入るのは `款`・`項` の 2 つだけで、値の列の集合は変わらない。**2 行先まで広げたら同値でなくなる**ので、そちらに歯を付けた(`test_14`) |
| 会計の集合の比較を **`True` に固定**する | 黙った | **歯が無かった。**門が記録の `same_set` を読むだけだったため、真の値が `True` である限り気づけない。**壊した入力(1 件落とす・にせの会計を足す)で偽になること**を要求する門を足した(`test_16`) |

**どちらも「記録と突き合わせるだけでは足りない」型である**
(記憶 `test-built-from-same-table-is-blind`)。
列の集合・注記・会計の集合は**その場で測り直して**記録と比べるようにした。
