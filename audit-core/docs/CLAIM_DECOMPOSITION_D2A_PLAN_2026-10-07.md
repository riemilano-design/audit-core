# D-2a 計画と予測(封印) ― 分母を広げる。費用 0 円

2026-10-07。D-1(`90260b3`)の続き。**分解器を作る前に正解集合を広げる。**
理由: いま正解集合は 1 本(claim 9・uncovered 3)。この分母で分解器を走らせると、
「false pass 0 は分母が不明」と構造的に同じ誤りを自分で繰り返す。

封じた予測は書き換えない。規則・範囲を予測を当てるために動かさない。外れは外れのまま残す。

## 1. やること(LLM の API を 1 回も呼ばない。費用 0.00 USD)

- (a) 正解集合を **4 本**にする。新規 3 本(`gold_02` / `gold_03` / `gold_04`)。
      **各本を別々の独立した席が書く。互いの成果物も実装も見ない。**
      `gold_01`(sha `6839f642a4ddbeb101b0b48ed7bacfccb83cc713a5d947397130bd1b285f07fe`)は **1 バイトも変更しない**。
- (b) 1 本ずつ別の壊れ方を狙う:
      | 本 | 狙い |
      |---|---|
      | gold_02 | 導出値(合計・差分・比率)。分母が文中にしか無い |
      | gold_03 | 期間と母集団のずれ。同じ指標が別の期間・別の母集団で複数回出る(同値異行の種を濃く) |
      | gold_04 | 主張でない数を厚く(閾値・項目名の数字・日付・順位・ページ番号) |
- (c) `splitIntoSentences` の改行アーティファクトを**本番側で**直す(試験側の `.trim()` で吸収しない)。
- (d) 正解集合を **glob で全部拾う**試験にする。1 本足すたびに試験を書き足す形にしない。

やらない: 分解器そのもの(D-2b。ここで初めて費用が出る)、`seat-output.v0.1` の置き換え、
`decompositionProblems` の非公開化(試験 24 か所が直接呼んでおり安くない。D-2b の配線前に別便)。

## 2. 予測(封印。実装の前に書いた)

| # | 欄 | 予測 |

### 従属
E-2 と E-5 は従属する(改行の直しが既存の試験を壊しうる)。別々の当たり外れとして数えない。

## 3. 次(D-2b。人間の判断が要る)

- 分解器は**並走路**として足す。`seat-output.v0.1` を置き換えない(追加の省略可能な欄 1 つ)。
  席の契約に散文の欄は無いことを実測で確認済み(`finishReason`/`reason` は制御の欄)。
- 同じ入力に対し「席が直接出した構造」と「席の原文から分解器が出した構造」を比べる。
  差が出た場所が、分解層で壊れている場所。
- **費用が出るので人間の上限承認が要る。** 見込みは 1 周およそ 5 USD(直近 1 回 2.71 USD の約 2 倍)。
