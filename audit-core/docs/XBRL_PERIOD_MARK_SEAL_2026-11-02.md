## §1 期の印の拾い方(字で固定)

対象は claims のうち**数の位置が決まる**行(「その他」の便の `locate` と同じ。1 つに決まらない行は数だけ)。
1. **W**: 数の字の直前の文(「その他」の便の `subject_of` を辿る前の W。区切りを落とした後)。
2. **同**: W が `(同` か `(同` で終わる → 印 **同**(前年同期の値。期は 前期)。
3. **前期**: 2 でないとき、W の末尾 14 字に `前期末` `前期` `前年同期` `前年度` `前連結会計年度` `前年` のどれかが在る → 印 **前期**。
4. **当期**: 2・3 でないとき、W の末尾 14 字に `当期末` `当期` `当連結会計年度` `当年度` `期末時点` のどれかが在る → 印 **当期**。
5. どれでもない → 印 **なし**(文は期を書いていない。AI の文の既定は当期と読む)。
6. `2期前` `3期前` `5期連続` などの字は 3・4 に含まれない(印なしか、W に当期・前期の字があればそれ)。

## §2 突き合わせ(字で固定)

- **engine の期**: pointers の 1 つ目(`xbrl:prefix:Local@context`)の context を、`CurrentYear` で始まれば **当期**、`Prior1Year` で始まれば **前期**、`Prior2Year`〜`Prior9Year` で始まれば **2 期前以前**、それ以外は **他**。pointers が空なら **指せず**。
- **札の根拠の期**(札 真 の行だけ): 根拠の字に `前期` `Prior1Year` `前年` が在れば **前期**、`CY` `当期` `CurrentYear` `当年度` が在れば **当期**(両方在れば **両方**。どちらも無ければ **読めず**)。
- **文の期**: 印 同・前期 → 前期、印 当期・なし → 当期。
- **取り違え(engine)**: 文の期と engine の期が違う行(engine の期が 当期 / 前期 のときだけ数える)。向きを 2 つに分ける: **前期の文 × engine 当期**、**当期の文 × engine 前期**。
- **印の確かめ(札)**: 札 真・根拠の期が 当期 か 前期 の行で、文の期と根拠の期が違う行(字の規則の読み違い、または文自身の期の書き違い)。

## §3 数えるもの(字で固定)

- 位置が決まる行の 印の分布(同 / 前期 / 当期 / なし)。札ごと(真 / 偽 / 判定不能)。
- 印 × engine の期 の表(当期 / 前期 / 2 期前以前 / 他 / 指せず)。
- 取り違え(engine)の数と向き、その state の分布(GROUNDED のものは「engine が別の期の fact を受け入れた」形)。id の列。
- 印の確かめ(札): 文の期と根拠の期が違う行の数と id。
- 配線: N081・N145(「(同」。前の便で期も含めて正した)が 印 同・engine 当期 になるか。N039(従業員数。札の根拠は前期末)の印と engine の期。

## §5 言えないこと

- 印の字の規則は AI の文の書き方(「前期比」「前年同期比 N% 増」など率の文の印、2 期前の値)を全部は覆わない。「前期比 2.9% 増」の 2.9% は率の文で、印 前期 に当たっても期は当期の率。率の文(単位 %・ポイント)は印 × engine の表には入れるが、取り違えの数からは外す(字で固定)。
- engine が期をどう決めているか(P16 の内部)は読まない。見るのは pointers の context だけ。
- 1 書類(1 社)・1 model の AI の文。P16 の判定。いまの既定 P27 は期の結びつきを変えている(P22 以降「期を留める」)ので、同じ行が P27 でどうなるかはデスクトップ。
