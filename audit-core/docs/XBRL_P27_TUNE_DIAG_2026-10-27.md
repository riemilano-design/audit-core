## 4. 限界

封 §8 と日付つきの追記の限界のうち、この診断に効くもの(字は封の側が正本):

- 調整用の標本は、五月決算の中小型に寄る(封 §8 の標本の偏り)。前の三本(三月決算の大型・IFRS)とは形が違う。
- 評価用の XBRL は見たことのある書類で、新しいのは AI の文の側だけ(封 §8・§11-6)。
- 書き手は一つの model の一つの指示文で、文体の型を三つに分けても Claude の癖は残る(封 §8)。
- 書き手の席は repo の作法の文書と記憶の索引を文脈に持っていた(封 2 つ目の追記)。外れの向きは「文の側の行が普段の AI の文より少なく出る」側で、**今回は文の側の札が一つも付かなかった**。向きとしては合うが、書き手の慎重さと、実際に文の側の誤りが少ないことは見分けられない。
- 読み手の席も同じ文脈を持ち、「AI の文を道具が判定した」と知って読む(封 4 つ目の追記)。
- 注入は二つの型だけで、DB と原本の差の実際の分布ではない(T8_REL の r の四値は決め打ち。封 §8)。
- 記録だけでは再現できない。応答と文は repo の外にあり、再配布できない(封 §8)。

この便で足す限界:

- **二つの席は同じ model で、違うのは文脈だけ。** 全行が道具に揃ったことと、側の一致が全行であることは、道具の側の食い違いが実際に多いことと、二席が同じ偏りを共有していることを**見分けられない**。R-7・R-9 の実測はこの限界の下で読む。
- **読みはエージェントの読みで、人の目は無い。** 道5(その他)の形は読み手が書いたが、repo の外にあり、人は読んでいない(この診断も読んでいない)。
- 率の分母は行で、書類は独立でない。claim の多い書類が通した行・読む行を多く持つ(書類別の表)。群別の率の差は書類との交絡を含む。
- R-8 は封の字が分母の行を指定しておらず、読み方で当否が分かれる(§2。両方を表に出した)。
- **下見の数と本番の数が一致した。** 実装の席が本番と同じ配線(実 engine)で走らせた下見と、独立監査が走らせ直した実行の二つが、判定の記録と注入の記録について、走らせた時の HEAD の commit・engine の指紋・repo の外に置いた file の欄を除いて**全部の欄が本番の記録と一致した**(この session で欄ごとに比べた)。読みの記録は下見の札が実際の読みでないので比べていない。下見の記録は repo の外にあり、**門なし**。【門なし】
- 取得の記録(dbfetch)と書き手の記録(reports)の中身を縛る門は、封 2 つ目の追記のとおり、この便まで無かった。この便の門が両方に (a)〜(e) を掛ける(§5)。
