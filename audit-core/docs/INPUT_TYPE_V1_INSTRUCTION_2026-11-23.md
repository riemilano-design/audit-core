# 入力の型(第 1 版)の指示書

この文書は、会社の AI が「型の file」を書くための決めである。型の file を書くのは会社の AI、受け口の検査は型どおりかだけを見て、型どおりでなければ理由を付けて断る。
受け口は推さない・補わない。書かれていない所を機械が埋めることはしない。断られたら、断りの `行`・`欄`・`規則` が指す所だけを直して、もう一度出す。

## 1. 書くもの

- 型の file は JSON 1 つ(UTF-8)。頂は object で、鍵は `型の版`・`書類`・`独自の名`・`行` の 4 つだけ。同じ鍵を 2 回書かない(どの object でも)。
- `型の版` は字 `1`(数の 1 ではない)。
- 数は字で書く(`値`)。JSON の数にしない。表示の位・精度だけが整数。
- 書かないと決めた所を機械が推すことはない。必要な欄は全部書く。

## 2. `書類`

- 鍵は `提出者の識別子`・`識別子の scheme`・`当期の始まり`・`当期の終わり`・`提出日` の 5 つだけ。
- こう書く: 日は `YYYY-MM-DD`(半角・在る日)。`当期の始まり` は `当期の終わり` と同じかそれより前。`提出日` は `当期の終わり` と同じかそれより後。`提出者の識別子`・`識別子の scheme` は空白を含まない 1 字以上の字。
- こう書かない: 月を 13 にする・`2031/03/31` と書く・`提出日` を期末より前にする・識別子を空にする・5 つの鍵に別の鍵を足す。
- 断られた時の直し方: 規則 D1(鍵の数か日の形)・D2(始まりが終わりより後)・D3(提出日が期末より前)・D4(識別子)の `欄` の鍵を直す。

## 3. `独自の名`

- 行で使う提出者別の名(接頭辞が `_cor` で終わらない名)の全部を、1 回ずつ並びで書く。要素は `種類`(`科目`・`軸`・`member` のどれか)と `名` の 2 つの鍵だけの object。
- 並びは (種類, 名) の字(コードポイント)の昇順。`member` が先、次に `科目`、最後に `軸`。
- こう書く: 行の `科目`・`次元` に出てくる提出者別の名を、その種類で 1 つずつ。
- こう書かない: 行で使わない名・接頭辞が `_cor` で終わる名・同じ (種類, 名) の 2 回目・昇順でない並び。
- 断られた時の直し方: 規則 N3(行で使った提出者別の名が並びに無い)は並びにその (種類, 名) を足す。規則 N4(余計な名・重なり・並びの順)は余りを消して昇順に直す。

## 4. `行`

- 1 つ以上の並び。1 行 = 1 つの数か 1 つの文。要素は object。`種類` が `数` なら鍵は `種類`・`科目`・`期間`・`対象`・`次元`・`値`・`単位`・`表示の位`・`精度` の 9 つだけ。`種類` が `文` なら `種類`・`科目`・`期間`・`対象`・`次元` の 5 つだけ(`値` などを足さない)。
- 同じ (種類・科目・期間・対象・次元) の行を 2 つ書かない。1 つの科目を、時点の行と期間の行の両方に書かない。1 つの科目の数の行に単位を 2 通り書かない。1 つの科目を数の行と文の行の両方に書かない(規則 R10〜R13)。
- 断られた時の直し方: 規則 R1 は `欄` の鍵を過不足なく揃える。

### 4-1. `科目`・名の字

- こう書く: `<接頭辞>:<局所名>`。どちらも英数字と `_` と `-` だけ・1 字以上・`:` は 1 つ。接頭辞が `jppfs_cor`・`jpcrp_cor`・`jpigp_cor` の名は標準の辞書に在る名だけ。接頭辞が `_cor` で終わらない名は `独自の名` に書いた名だけ。
- こう書かない: `:` が無い名・辞書に無い名・`独自の名` に書いていない提出者別の名・軸の名を `Axis` で終えない・member の名を `Member` で終えない。
- 断られた時の直し方: 規則 N1(形)・N2(辞書に無い)・N3(独自の名に無い)・N5(軸・member の終わりの字)の `行`・`欄` の名を直す。

### 4-2. `期間`

- こう書く: 時点なら `{"時点": "YYYY-MM-DD"}`。期間なら `{"始まり": "YYYY-MM-DD", "終わり": "YYYY-MM-DD"}`。期の表に在るかどうかは問わない。`始まり` は `終わり` と同じかそれより前。
- こう書かない: `時点` と `始まり` を一緒に書く・`始まり` を `終わり` より後にする・`/` で区切る。
- 断られた時の直し方: 規則 R2 の `行` の `期間` を直す。

### 4-3. `対象`

- こう書く: `個別` か `既定`。個別の財務諸表の数なら `個別`、それ以外は `既定`(`既定` は連結とは限らない)。
- こう書かない: `連結` など別の字。
- 断られた時の直し方: 規則 R3 の `行` の `対象` を `個別` か `既定` に直す。

### 4-4. `次元`

- こう書く: 並び(空でもよい)。要素は `[軸の名, member の名]` の 2 つの字の並び。軸の名の字の昇順。同じ軸を 2 回書かない。
- こう書かない: 個別の軸 `jppfs_cor:ConsolidatedOrNonConsolidatedAxis` を書く(個別かどうかは `対象` に書く)・順を逆にする。
- 断られた時の直し方: 規則 R4 の `行` の `次元` を直す。

### 4-5. `値`(`数` の行)

- こう書く: `無い`(空の数)か、符号つきの本当の大きさの 10 進の字。形は `-?(0|[1-9][0-9]*)(\.[0-9]*[1-9])?`(半角。頭に余計な 0 を付けない・小数の末尾に 0 を付けない・`,` を入れない・`+` を付けない)。負の印の付いた 0 は `-0`。
- こう書かない: `1,234`・`+5`・`5.0`・全角の数字・JSON の数。
- 断られた時の直し方: 規則 R5 の `行` の `値` を上の形の字に直す。

### 4-6. `単位`(`数` の行)

- こう書く: `通貨:XXX`(XXX は英大文字 3 つ。例 `通貨:JPY`)・`株`・`純数`・`通貨:XXX÷株` のどれか。この 4 つの形に当たらない単位だけ `他:<分子>` か `他:<分子>÷<分母>`(分子・分母は measure の名を字の昇順に `*` でつないだ字)。
- こう書かない: `円`・`通貨:jpy`・4 つの形に当たる単位を `他:` で書く(例 `他:xbrli:pure`)。
- 断られた時の直し方: 規則 R6 の `行` の `単位` を直す。

### 4-7. `表示の位`・`精度`(`数` の行)

- こう書く: `値` が在れば 2 つとも整数(大きさは 1000 以下)。`値` が `無い` なら 2 つとも `null`。精度 + 表示の位 は 0 以上。`値` は 10 の(−精度)乗の倍数(例: 精度が −3 なら千の倍数)。
- `表示の位` は、書類に載せる数の字が、`値` を 10 の何乗で割った字かを表す整数(数の字の書き方)。例: `値` が `1234000` で書類には `1,234`(千単位)と載せるなら `3`・`値` をそのまま載せるなら `0`。
- `精度` は、`値` が 10 の何乗の位まで確かな字かを表す整数。例: 千の位まで確かな `1234000` は `-3`・一の位まで確かな `42` は `0`・小数第 2 位まで確かな `12.34` は `2`。
- こう書かない: 字の `"0"`・真偽・小数・`値` が在るのに `null`・`値` が `無い` のに数。
- 断られた時の直し方: 規則 R7(整数・null)・R8(精度 + 表示の位)・R9(倍数)の `行` の `欄` を直す。

## 5. 受け口の検査の規則

断りは 1 つずつ `行`(1 から数えた行の番号。行でない所は `null`)・`欄`・`規則`・`理由` で返す。全部の規則を掛け、当たった全部を返す(最初の 1 つで止めない。ただし S1・S2 に当たったら、ほかの規則は掛けない)。

| 規則 | 見る所 | 断る時 |
|---|---|---|
| S1 | file | JSON として読めない・頂が object でない・頂の鍵が 4 つちょうどでない・`型の版` が字 `1` でない・`行` が 1 つ以上の並びでない・`独自の名` が並びでない・`書類` が object でない |
| S2 | file | どこかの object に同じ鍵が 2 回在る |
| D1 | `書類` | 鍵が 5 つちょうどでない・日が `YYYY-MM-DD` の形の在る日でない |
| D2 | `書類` | `当期の始まり` が `当期の終わり` より後 |
| D3 | `書類` | `提出日` が `当期の終わり` より前 |
| D4 | `書類` | `提出者の識別子` か `識別子の scheme` が、空白を含まない 1 字以上の字でない |
| N1 | 名(科目・軸・member・`独自の名`) | `<接頭辞>:<局所名>` の形(どちらも英数字と `_` と `-` だけ・1 字以上・`:` は 1 つ)でない |
| N2 | 名 | 接頭辞が辞書の在る接頭辞なのに、辞書に無い |
| N3 | 名 | 接頭辞が `_cor` で終わらないのに、その種類で `独自の名` に無い |
| N4 | `独自の名` | 要素の鍵が 2 つちょうどでない・種類が 3 つのどれでもない・接頭辞が `_cor` で終わる名・どの行もその種類で使わない名・同じ (種類, 名) が 2 回・並びが昇順でない |
| N5 | 名 | 軸の名が `Axis` で終わらない・member の名が `Member` で終わらない |
| R1 | 行 | 行が object でない・`種類` が `数` でも `文` でもない・鍵がその種類の鍵ちょうどでない |
| R2 | `期間` | 鍵が `時点` だけ・`始まり` と `終わり` だけ、のどちらでもない・日が在る日の形でない・`始まり` が `終わり` より後 |
| R3 | `対象` | `個別` でも `既定` でもない |
| R4 | `次元` | 並びでない・要素が 2 つの字の並びでない・同じ軸が 2 回・軸の名の昇順でない・個別の軸(`jppfs_cor:ConsolidatedOrNonConsolidatedAxis`)が在る |
| R5 | `値` | 字でない・`無い` でも `-?(0|[1-9][0-9]*)(\.[0-9]*[1-9])?` の形(半角。全体が合う)でもない |
| R6 | `単位` | 字でない・上の形のどれでもない・4 つの形に当たるのに `他:` で書いている |
| R7 | `表示の位`・`精度` | 値が在るのに整数でない(真偽・小数・字は整数でない)・大きさが 1000 を超える・値が `無い` なのに `null` でない |
| R8 | `表示の位`・`精度` | 精度 + 表示の位 が 0 より小さい |
| R9 | `値`・`精度` | 値が 10 の(−精度)乗の倍数でない |
| R10 | 行と行 | (種類・科目・期間・対象・次元)の組が同じ行が 2 つ以上在る(後ろの行を断る) |
| R11 | 行と行 | 1 つの科目が、時点の行と期間の行の両方に在る(その科目の、数の少ない側の行を断る。同じ数なら期間の側) |
| R12 | 行と行 | 1 つの科目の数の行に、単位が 2 通り以上在る(その科目の、いちばん多い単位でない行を断る。同じ数なら字の昇順で先の単位を残す) |
| R13 | 行と行 | 1 つの科目が、数の行と文の行の両方に在る(その科目の、数の少ない側の行を断る。同じ数なら文の側) |

- 行の欄が形として読めない時(R1〜R7 のどれかに当たった行)は、その行を R8〜R13 に掛けない。
- 辞書の無い `_cor` の接頭辞(例 `jpdei_cor`)の名は、形(N1)だけを見て通す。

## 6. 断りの返り方

受理なら `{"受理": true, "断り": []}`。断りなら `受理` が `false` で、`断り` に上の 4 つの鍵の object が並ぶ。`理由` は上の表の「断る時」の 1 つ。
