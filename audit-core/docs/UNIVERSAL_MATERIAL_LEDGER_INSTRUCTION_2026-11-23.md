**渡された folder の外は読まない・書かない**(あなたが書いてよい file は、この folder の中の `材料.json` 1 つだけ)。
この repo の文書・script・別の folder を探しに行かない。素材は**読むだけ**(`素材.sqlite` を直さない・消さない・新しい表を足さない)。
やり直しは無い。1 回で書く。

## 1 渡されるもの

folder に次の file が在る。

- この指示書(`指示書.md`)
- `definition_C.json` ― 定義表。あなたが書く材料の一覧(30 行)。行ごとに `id`・`名`・`意味`・`単位`・`期`・`範囲`・`取り方` が在る
- `reading_def.json` ― 読込みの定義。素材の 3 つの表を結んだ 1 つの表「仕訳の行」の作り方
- `指定.json` ― 指定。鍵は `成果物`・`当期の始まり`・`当期の終わり` の 3 つ
- `素材.sqlite` ― 素材。ある会社の会計の帳簿(関係の表。SQLite の file 1 つ)

## 2 素材の読み方(仕訳の行)

`reading_def.json` のとおりに、素材の 3 つの表(元帳・科目・振替伝票)を結んだ 1 つの表を「仕訳の行」と呼ぶ。列は 9 つ。

`行の番号`・`日付`(字 `YYYY-MM-DD`)・`科目番号`(整数)・`科目の大分類`・`科目の小分類`・`伝票の種類`・`仕訳の種類`(空が在る)・`借方`・`貸方`

- 素材は標準の SQLite の読み方で読める。**読み取り専用で開く**こと(例: Python の `sqlite3.connect("file:素材.sqlite?mode=ro", uri=True)`)。
- 素材の中には、仕訳の行に使う 3 つの表のほかにも表が在る。科目の名・説明など、意味を読むのに役立つ列は、どの表から読んでもよい。
- 額は、行ごとに借方・貸方を 100 倍して最も近い整数へ丸めた値(最小の通貨の単位)で足す。浮動小数のまま足さない。

## 3 書くもの

`材料.json`(この folder の中)に、JSON 1 つを書く。頂の鍵は次の 2 つだけ。

- `型の版`: 字 `u1`
- `材料`: 並び。定義表の 30 行を、id の字の昇順に **1 回ずつ**(抜かさない・重ねない)

### 3-1 材料 1 つの書き方

材料の鍵は `状態` で決まる。

**`在る`** のとき。鍵は次の 7 つだけ。

| 鍵 | 書くもの |
| --- | --- |
| `id` | 定義表の id |
| `状態` | `在る` |
| `数値` | 10 進の字で小数 2 桁ちょうど(例 `1234.50`・負は頭に `-`)。仕訳の行の額の和(最小の通貨の単位)を 100 で割った値 |
| `単位` | 定義表の `単位` と同じ字 |
| `期間` | 時点の行は `{"時点": "YYYY-MM-DD"}`。期間の行は `{"始まり": "YYYY-MM-DD", "終わり": "YYYY-MM-DD"}` |
| `範囲` | 定義表の `範囲` と同じ字 |
| `出どころ` | 下の 3-2 |

**`無い`** のとき。鍵は `id`・`状態`・`無い理由` の 3 つだけ。`状態` は `無い`、`無い理由` は字 `素材が無い`。
素材を調べて、その行の意味に当たる仕訳の行が、その期に 1 行も見つからないときだけ `無い` と書く。
意味が合わないものを近い数で埋めない。

### 3-2 出どころ(仕訳の行を条件で絞った和)

鍵は次の 4 つだけ。

- `種類`: 字 `表の行の和`
- `表`: 字 `仕訳の行`
- `向き`: `借方−貸方` か `貸方−借方`。`借方−貸方` は、選んだ行の借方の和から貸方の和を引いた値。`貸方−借方` はその逆
- `条件`: 並び(1〜8 個)。**全部を満たす行**を選ぶ。条件 1 つは鍵 `列`・`比べ方`・`値` の 3 つだけ

条件の書き方:

- `列` は `日付`・`科目番号`・`科目の大分類`・`科目の小分類`・`伝票の種類`・`仕訳の種類` の 6 つだけ。
- `日付` の `比べ方` は `以上`・`以下`(値は日の字 `YYYY-MM-DD`。その日を含む)。
- ほかの列の `比べ方` は `等しい`(値 1 つ)・`どれか`・`どれでもない`(値の並び。1〜200 個)。`科目番号` の値は整数、ほかの列の値は字。
- 空の `仕訳の種類` の行は、`等しい`・`どれか` には当たらず、`どれでもない` には当たる。
- 選んだ行が 1 行も無い条件は書かない(その場合は `無い`)。

### 3-3 実物の形の例

次は**形の見本**。値・科目・分類の字・数値は全部作り物で、あなたの素材の答えではない。

```json
{"id": "x01", "状態": "在る", "数値": "1234.50", "単位": "通貨", "期間": {"始まり": "2001-01-01", "終わり": "2001-12-31"}, "範囲": "全社", "出どころ": {"種類": "表の行の和", "表": "仕訳の行", "向き": "貸方−借方", "条件": [{"列": "科目の小分類", "比べ方": "どれか", "値": ["作り物の分類 P", "作り物の分類 Q"]}, {"列": "仕訳の種類", "比べ方": "どれでもない", "値": ["作り物の種類 R"]}, {"列": "日付", "比べ方": "以上", "値": "2001-01-01"}, {"列": "日付", "比べ方": "以下", "値": "2001-12-31"}]}}
```

## 4 期の決め方

`指定.json` の `当期の始まり`・`当期の終わり` から、定義表の `期` ごとに決まる。

- `当期`: 始まり = 当期の始まり、終わり = 当期の終わり
- `前期`: 当期の始まりの 12 か月前の日から、当期の始まりの前の日まで
- `当期末`: 時点 = 当期の終わり
- `前期末`: 時点 = 当期の始まりの前の日
- `当期の月:k`(k は 1〜12): 当期の始まりから k 番目の月の、初日から末日まで

期間の行(当期・前期・月)は、条件に `日付 以上` と `日付 以下` を 1 つずつ書く。値は上で決めた始まりと終わり。
時点の行(当期末・前期末)は、条件に `日付 以下` を 1 つだけ書く(値は時点)。残高は素材の最初の日からの累計なので、`日付 以上` は書かない。`期間` の欄も同じ日にする。
