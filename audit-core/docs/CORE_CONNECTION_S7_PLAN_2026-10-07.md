### 1.2 I-6 は**偽陽性**だった(整理役は正しく振る舞っている)

`I-6` は「自分で計算した数(`selfComputedNumbers`)が代表の文に出ていないか」を見る検査で、**数の字面の一致**で判定している。実物を見ると、整理役は次のように**正しく**振る舞っていた。

- 比を計算して `selfComputedNumbers` に隔離し、`how` に「`statement` や `answers` の根拠には使っていない」と書いた。
- 文に出ていた `0` は、束に実在する値(`aggregates.groups.noSignature.aheadThenLost.numerator` = 0)を「分子0・分母2」として正しく引いたもの。

隔離した比が `0 ÷ 2 = 0` で、その値 `0` が束の分子 `0` と**字面で衝突した**。I-6 が落としたのは漏れではなく、**同じ数字が別の出どころで正しく出ている**だけである。

**同じことが 2 つの run で起きている。** `558b8a81-20261001-2` の `selfComputedNumbers[2]` と `43f8b69c-20261007-1` の `selfComputedNumbers[5]` は、どちらも同じ `aggregates.groups.noSignature.aheadThenLost` の比で、どちらも値 `0`。別の整理役の呼び出しで同じ形が出た。

**この検査は両方向に壊れている。**

| 向き | 例 |
|---|---|
| 偽陽性 | 隔離した値が `0`・`1`・`2` のような頻出の数だと、束の正しい数と衝突して落ちる(実物で 2 件) |
| 偽陰性 | 隔離した `3.111111111111111` を「約 3.1」と書いて漏らしても、字面が違うので通る |

**これは席側の E-5 と同じ検査の同じ欠陥である**(S-5 の実 run で `E-5: selfComputedNumbers[2] の値「0」が statement / answers の文に出ている` が出ていた)。人間は E-5 の字面一致の規則を**後回しと決めている**。**したがって I-6 もその決定の対象であり、この封では直さない。** 整理役の指示文で直せるものではない(「束の正しい 0 を書くな」は誤った指示になる)。

### 1.3 I-2 の 4 行のうち 3 行は**満たせない規則**だった(S-4 と同じ型)

I-2 は束(cluster)について 2 つを見る。

1. `packetRefs` の各根が**文法**に合うか(`lib/packetRef.ts` の 1 か所の文法)。
2. 束の**成員それぞれ**が、その根のどれかを根拠に持つか。

実物の内訳はこうなっていた。

| 行 | 原因 | 直せる場所 |
|---|---|---|
| `C-007 の packetRefs: facts.recognition.rows が文法に合わない` | 整理役が根を作った | 下記の通り**契約の矛盾の症状** |
| `C-007 の成員「1:I-1-007」が束の根を根拠に持たない` | 成員の観測が **0 件** | **満たせない** |
| `C-007 の成員「2:I-2-006」が…` | 同じ | **満たせない** |
| `C-008 の成員「1:I-1-008」が…` | 同じ | **満たせない** |

**C-008 が決め手である。** C-008 の `packetRefs` は `aggregates.branches.total.value` と `aggregates.longThink.total.value` で、**文法に合っている**。それでも同じ指摘が出た。成員 `I-1-008` の `kind` は `needed_observation` で**観測が 0 件**だからである。観測が 0 件の成員は、どんな根を書いても `roots.some(root => m.paths.has(root))` を満たせない。

そして契約 `integration.llm.v0.2` / `integration.v0.1` は `clusters[].packetRefs` に **`minItems: 1`** を課している。つまり:

```
契約: packetRefs は 1 件以上 必須
門 I-2: 成員は全員その根を根拠に持て

```

**S-4 で直した「契約が 1 件以上を求めるのに kind が 0 件を含意する」矛盾が、1 層上の `packetRefs` にもあった。** S-4 は `observations.minItems` を 4 本の契約で直したが、`packetRefs.minItems` は見ていない。整理役が `facts.recognition.rows` を作ったのは、**何かを書かねばならず、書ける正しい根が存在しなかった**結果である。文法の行も**同じ根本原因の症状**であり、整理役の自発的な誤りではない。
