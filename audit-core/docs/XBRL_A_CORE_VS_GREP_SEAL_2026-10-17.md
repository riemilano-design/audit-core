## §4 採点(**分母を別に書く。1 つの率にまとめない**)

| 記号 | 定義 | 分母 |
|---|---|---|
| **特定率** | 参照先が**正解と一致**した件 | **T5 の件数** |
| **誤認定率** | **誤った参照先を「確認済み」として採った件** | **参照先を出した件数**(腕ごと) |
| **保留率** | 参照先を出さなかった件 | 注入した件数(型ごと) |
| **T1 の通し** | 値がどこにも無いのに「確認済み」 | T1 の件数 |
| **T3 の名指し** | 参照先が無いのに名指した | T3 の件数 |

**層**: 改変後の値と**同じ値を持つ fact の数 `n`** で `n = 1 / 2〜5 / ≥6` に分ける。
**層ごとに 3 腕を並べる。**全体の 1 つの数で結論しない。

**対応が付かない件**(注入した場所に Core の主張が無い等)は
**「対応が付かない」として別に数える。推測で埋めない。**
