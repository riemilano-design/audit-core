## §2 席に見せるもの(**この 4 つだけ**)

1. **問い**(固定文。下の §3)
2. **改変後の本文**(1 書類ぶん)
3. **`refs` の一覧**(`Element@contextRef|値|単位` を 1 行ずつ。**その書類の fact 全部**)
4. **判定する 24 行**(`id` / 文の抜粋 / 数の字面 / 値)

**見せないもの**: 正解・注入の記録・Core の出力・profile 名・型の名前(T1/T3/T5)・
`GROUNDED` 等の内部の語。**`注入`・`正解`・`Core`・`engine`・`GROUNDED`・`pointer`・
`T1`・`T3`・`T5` の字が材料に 0 件であることを機械で確かめる。**

## §3 席の回答の形(**固定語彙。欄を増やさない**)

行ごとに次の 3 つだけ。

| 欄 | 許す値 |
|---|---|
| `id` | 材料の id のまま |
| `判定` | **`確認済み` / `誤りが在る` / `判定できない`**(この 3 語のどれか) |
| `参照先` | `Element@contextRef` の形 1 つ、または **`なし`** |

**「どちらとも言える」や自由文は受け取らない**(schema で閉じる)。
**24 行すべてに答える**(欠けた行は「欠けた」として数え、埋めない)。

## §4 腕の作り方(**同じ 1 回の回答から 4 つ作る**)

| 腕 | 作り方 |

| **D′** | 席の回答 + 値検索(v1 §4-1 の定義のまま) |
| **D″** | 席の回答 + 強くした値検索(v1 §4-2 のまま) |

**1 書類 1 便・席は 1 席・再生成なし。**
**使ったトークンを記録に残す**(封 v2 Δ5)。

## §5 止める条件

1. **材料に見せてはいけない字が 1 件でも在れば、生成の前に止める。**
2. **注入が 8 件そろわない書類は、そろった件数で進めて「そろわなかった」と書く。**
   **規則を緩めて 8 件にしない。**
3. **round-trip(`inject.revert`)が合わなければその書類で止める。**
4. **回答が schema を外れたら、その便を失敗として記録する**(埋めない)。
5. **結果を見てから §1〜§4 を変えない。**
