# 第 3 層 解釈(**ここから先は解釈である**)

## §3-1 この結果が言えること

- **Core の検証規則は、誤りを「確認済み」として通さない**(見落とし 0 件・偽警報 0 件)。
  **検証器の土台としては使える**という観測である。
- **ただし単体では、結べない主張の誤りを 1 件も捕まえられない。**
  **誤りの半分(4/8)は「どれを指すか決められない」で終わった。**
- **だから「LLM が住所を出し、Core が検証する」構えに値打ちが在るかは、
  LLM が結べない主張でも正しい住所を出せるかに全部かかっている。**
  **それは次の段(A 対 C)で測る。**

## §3-2 この結果が言えないこと

- **人工の誤りである。**実際の文書で起きる誤りの分布は測っていない(封 §7 の 1)。
  特に「**数値も参照先も正しいが文脈が違う**」型は作れていない。
- **誤りは正解集合の 24 件にしか植えていない。**別枠 11 件では**何が誤りかを
  定義できない**ので、そこでの検出能力は測れない。
- **保留 14〜17 件の実務的な重さは測っていない。**
  要確認が 14 件出る道具を顧客が受け入れるかは、ここでは分からない。
- **罠が示すとおり、私の切り出しの欠陥は検証器の偽警報になる。**
  **検証器の精度は切り出しの精度で上から抑えられる。**

封 §5 の条件はすでに封じてある(A 対 C の比較条件・採点基準・閾値 G-1〜G-3)。
