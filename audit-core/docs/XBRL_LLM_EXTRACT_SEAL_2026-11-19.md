## §2 規則

### §2-1 席に送る行と、席に渡す字

- **送る行** = 読みの札つきの行のうち、いまの engine で同じ state で引けた行(便 SC・便 PA の記録の「引けた行(分母)」と同じ引き方。便 SC の script の関数を呼ぶ。写さない)。前の記録では V の札 174 行(TSS 119・KAM 37・YS 18。分母から除く札の 1 行を含む)と G の札 247 行(KAM 96・YS 151)= 421 行。行の数が 421 と違えば、止めて司令塔に返す。
- 札の無い行(結んだ行の残り)には送らない。
- **配線の確認(予測ではない。違えば止める)**: 送る行の(鍵, state)の集まりが、便 PA の記録の「行」の中に全部在る。
- **渡す字**(便 SC・便 PA の段 3 が見た字と同じ範囲。それより広い字は渡さない):
  - **見出し** = 便 SC の封 §2-4 の決めで選んだ、その行の文より前で最も近い見出し 1 つ(便 SC の script の関数で選ぶ)。無ければ `(なし)`。
  - **文** = その行の文の全部(engine が切った文の字。NFKC 済み)。その行の数の字(便 SC の script と同じ位置と span の読み)の前に `【`、後ろに `】` を入れる。同じ文の別の数には入れない。
- 1 行につき 1 回の呼び出し(1 つの文に札つきの数が 2 つ在れば 2 回)。行の順は鍵の昇順。

### §2-2 指示文(字で留める。system は無し = user の 1 message。封の門が照らす)

`{HEADING}` と `{SENTENCE}` を §2-1 の字で置き換える。ほかは 1 字も変えない。

```
次は、日本の上場企業の開示書類(決算短信または有価証券報告書)の中の 1 つの文と、その文の直前に在った見出しです。文の中の【 】で囲んだ数について、2 つの問いに答えてください。渡した字だけで判断し、推測で埋めないでください。

見出し: {HEADING}
文: {SENTENCE}

問い 1(範囲): 【 】の数は、会社の全体(連結の全体、または提出会社の単体の全体)の数ですか。それとも、その一部分(特定のセグメント・事業・部門・地域・製品・子会社・関連会社・拠点・資産のまとまり・個別の案件や取引先など)の数ですか。
- 全体
- 一部分
- 分からない

問い 2(性質): 【 】の数は、すでに確定して報告・計上された実績の数ですか。それとも、これから先の予想・計画・目標・予定・見通しの数ですか。会計上の見積りを伴っていても、すでに計上された額は「実績」としてください。
- 実績
- 計画・予想
- 分からない

答えは次の形の JSON だけを 1 行で返してください。説明は書かないでください。
{"範囲": "全体 | 一部分 | 分からない のどれか", "性質": "実績 | 計画・予想 | 分からない のどれか"}
```

- 渡す字の描き方の例(**作り物**。材料の文ではない): 見出し `(なし)`・文 `当連結会計年度の売上高は【1,234】百万円となり、前期比 5.6% 増加しました。`

### §2-3 答えの読み方

- 返った text から最初の `{` と最後の `}` の間を JSON として読み、欄「範囲」「性質」が §2-2 の 3 つの語のどれかと字で一致するときだけ答えとする(前後の空白は落とす)。
- 読めない・語が違う・text が 0 字・stop_reason が `end_turn` でないときは、同じ指示文でもう 1 回だけ呼ぶ。それでも読めなければ、その席のその行は **答えなし**(どちらの規則でも止めない。数は別に書く)。
- 答えを司令塔が手で直さない。席の text を読んで規則を足さない。

### §2-4 止める条件

- **L-S(範囲)**: 席の答えの「範囲」が「一部分」で、かつ、その行の raw の claim の member の欄が空(便 SC の段と同じ対象)。
- **L-P(性質)**: 席の答えの「性質」が「計画・予想」(member の欄は問わない。便 PA の段と同じ対象)。
- **L-U(合併)**: L-S か L-P のどちらか。
- 「分からない」と答えなしは止めない。state は書き換えない(engine の外の数え直し)。
- **並べる相手(語の表)**: W-S = 便 SC の段 2・W-P = 便 PA の段 2・W-U = そのどちらか。2 つの記録の行の欄から読む(計算し直さない)。

### §2-5 数えるもの(席ごと・規則ごと。語の表の数を隣に)

1. V の札の行: 「範囲」の札(前の記録では 104 行 = TSS 75・KAM 25・YS 4)・「見積り・計画」の札(27 行 = TSS 20・YS 7)・「それ以外」(「範囲」でも「見積り・計画」でもない札。分母から除く札は除く。前の記録では 174 − 1 − 104 − 27 = 42 行。**便 PA の記録の「それ以外」は「範囲」を含む別の束**で、それとは違う)の、行の数と止めた数。便ごとにも。「それ以外」は属性ごとにも。
2. G の札の行(KAM・YS): 札 a(214 行)・b(27 行。「違うもの」が範囲の行は YS の 15 行)・c(6 行)ごとの、行の数と止めた数。
3. 席の答えの分布(範囲 3 語 × 性質 3 語 + 答えなし)を、便ごと・札の束ごとに。
4. 2 つの席の答えの一致(範囲・性質のそれぞれで、同じ答えの行の数。答えなしの行は別に)。
5. 語の表との重なり: 上の束ごとに、(語の表で止めた / 止めない)×(席で止めた / 止めない)の 4 つの数(S・P・U のそれぞれ)。
6. 呼び出しの記録: 席ごとの回数・やり直しの回数・答えなしの数・入力と出力の token の合計・USD(§3 の単価で)・返った block の type の並びの種類・stop_reason の種類。

### §2-6 記録に書かないもの

文・見出しの字・値・要素名・枠の id・pointer の字・主語の語・会社名・証券コード・docID・金額・席の返した text そのもの。行ごとに書くのは、鍵・state・member の欄が空か・席ごとの答え(§2-2 の語か「答えなし」)・その行の指示文の sha256・呼び出しの数だけ。指示文の型(§2-2 の字)は記録に書いてよい。送った文と返った text は、追跡しない置き場にだけ置く。
