4. **(二) 「表の値に近い」行を拾う規則**(実装者が 1 通りに書ける字で)。対象は、A(写さない)と B(期の名前を写した)の VALUE_MISMATCH の行のうち `recomputed` が数である行。`v` = `value`、`r` = `recomputed`。
   - **N-円**: `unit` が `円`・`千円`・`万円`・`百万円`・`億円`・`兆円` のどれか(倍率 `m` = 1・1e3・1e4・1e6・1e8・1e12)。`c = |v| × m`、`f = |r|`。`f > 0` かつ `0 < |c − f| / f ≤ 0.02`。
   - **N-桁**: `unit` が上の 6 つのどれかで、`form == "direct_value"` で、`v` が整数(`v == round(v)`)。`a` = `|v|` の整数の字、`b` = `floor(f / m)` の字 または 四捨五入(0.5 は切り上げ)した `f / m` の字。どちらかの `b` について、`a` と `b` の桁数が同じで 3 桁以上、かつ(ちょうど 1 桁だけ違う、または、となり合う 2 桁が入れ替わっているだけ)。
   - **N-率**: `unit` が `%`。`0 < | |v| − |r| | ≤ 0.5`。
   - 行は N-円・N-桁・N-率 のどれか 1 つ以上に当たれば「近い行」。当たった規則は行ごとに全部記録する。
   - 当たる例: `v` 15960・百万円・`r` 16145000000.0 → `|c − f| / f` = 0.0115 → N-円。`v` 12345・百万円・`r` 12435000000.0 → N-円 と N-桁(入れ替わり)。`v` 104.6・%・`r` 104.2 → N-率。当たらない例: `v` 98000・百万円・`r` 94400000000.0(0.038)、`v` 104.6・%・`r` 103.47(1.13)、`v` 15960・百万円・`r` 15960000000.0(差 0。そもそも VALUE_MISMATCH にならない形)。

5. **近い行を読む**: 近い行を(群 A が先・§1 の表の # の順・文の番号の順・位置の順)に並べる。A と B を合わせて 200 行以下なら全部、200 行を超えたら Python 3.9 の `random.Random(20261115).sample(range(行の数), 200)` で 200 行を引き、番号の順に並べる。司令塔(**AI の席。人は読んでいない**)が 1 行ずつ、文と、同じ ZIP の財務諸表の行を読み、次の型のどれか 1 つを付ける。読むための紙は repo の外(scratchpad)に置き、追跡しない。

   - (い) 別の項目・一部分・別の期・定義の違い(セグメント、内訳、文の中で計算した率や差 など)
   - (う) 計画・予想・目標の数
   - (え) 丸め・単位・符号
   - (お) 読んでも分けられない
