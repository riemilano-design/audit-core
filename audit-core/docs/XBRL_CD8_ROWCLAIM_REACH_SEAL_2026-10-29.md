### §2-3 位置で引く(この便が自分で書く対応付けの規則。1 つの関数 `claim_at` と、その前の写し)

1. **本文の位置 → engine の文**: engine が切った本文 `text_`(W-T)を `\n` で段落に切り、各段落を、その profile の `paren_sentence` が真なら `E.split_after_kuten_outside_parens(段落)`、偽なら `re.split(r"(?<=。)", 段落)` で断片に切る(engine の `_split_lines` と同じ切り方。断片をつなぐと段落に戻ることを確かめる)。`s and s.strip()` が真の断片だけを順に文と数え、文 i の**本文の始まり** = 段落の始まり + 断片の始まり + 断片の先頭の空白の字数、文 i の字 = `unicodedata.normalize("NFKC", 断片.strip())`。この文の一覧が engine の `sentences` と字で一致しなければ止める(W-T)。
2. **文の中の位置**: 断片.strip() が NFKC で変わらない文では、本文の位置 x の文の中の位置 = x − 文 i の本文の始まり。変わる文では、断片.strip() の 1 字ずつに NFKC を当てた字の長さを累積して写す(1 字ずつの NFKC をつないだ字が `NFKC(断片.strip())` と同じときだけ使う。同じでなければ、その文は**写せない文**)。
3. **行の範囲**: A1・A2 は `MB.build_rows`(A2 は `patched` の下の関数)が行に書いた `span` = 改変後の本文の [始まり, 終わり)。B は `IJ.apply_edits` の `placements[inj id]` = 改変後の本文の [始まり, 終わり)(T1・T5・T2 は差し替えた token、T3 は挿入した文)。**この範囲は verify に渡した本文の位置**で、`text_` がその本文と同じとき(W-T)だけ engine の本文の位置として使う。範囲の [始まり, 終わり − 1] が同じ 1 つの文 i の中に在り、その文が写せる文なら、(文 i, 文の中の [a′, b′))。そうでなければ(文をまたぐ・文の外の空白や捨てられた字に在る・写せない文・`text_` が違う)、**位置が決まらない**。
4. **位置の候補**: `verify_document` の出力の claim のうち、tap が拾った num の claim(`_build_raw_num_claims` が作った claim)に同じ id が在るものについて、生の claim の `sentence` = i、かつ、その claim の数の範囲 [pos, e) が [a′, b′) と 1 字以上重なるもの。e は同じ profile の `R._numbers_of(V.PROFILES[profile], 文 i)` が返す組のうち、始まりが pos の組の終わり(その組が無ければ e = pos + 1 とし、細目に「数の終わりが決まらない」と書く)。
5. **位置で引いた claim** = 候補がちょうど 1 つのときのその claim。候補が 0 なら「位置の claim が無い」、2 つ以上なら「位置で 1 件に決まらない」。

`claim_at` は 4・5 を持つ 1 つの関数とし、重なりを見る行(`pos < b′ and a′ < e` の形の 1 行)を総点検の門の宣言の根拠の字にする(§5)。

### §2-4 分類(機械で 1 か所。§3 の予測はこの語で書く)

2. **(位置で 1 件に決まらない)**: 位置の候補が 2 つ以上。

### §6-5 追記(2026-10-29、下調べの後。§2 の仕様の補い。§3 の字は変えない)

1. **§2-3 の 3 の補い(空白だけ違う本文の写し)。** verify に渡した本文と engine の本文 `text_` が字で違うとき、両方から空白(Python の `str.isspace()` が真の字。改行・`\xa0`・`　` を含む)を除いた字の列が同じなら、渡した本文の空白でない字の位置を、`text_` の同じ番目の空白でない字の位置に写す。行の範囲 [始まり, 終わり) は、その中の最初と最後の空白でない字を写した [写した最初, 写した最後 + 1) とする。空白を除いた字の列が違う単位は(位置が決まらない)(細目「空白以外が違う」)、範囲が空白だけの行も(位置が決まらない)(細目「範囲が空白だけ」)。この写しは `claim_at` の前の写しの関数に置く(規則は位置で引く 1 つのまま)。
2. **W-T の記録の語**: 単位ごとに「字で同じ」「空白だけ違う」「空白以外が違う」の 3 語で記録する。止めるのは、§2-3 の 1 で作り直した文の一覧が engine の `sentences` と違うときだけ(変えない)。CR-3 の当否は封の字のまま(「本文が字で同じ」)で判定する。
3. **細目の補い**: (位置だけ)の細目「値が違う」を、さらに「claim の値が行の値の 10 の冪の倍(円に直した形)」「符号だけ違う」「その他」に分けて記録する(機械で決める。どれかの形が多いかを数えるだけで、分類の順には入れない)。(値だけ)の細目に「行の範囲に engine の数(`_numbers_of`)が在るか」を足す。
4. **CR-25 の数え方**: §2-5 の「判定が変わる」は(値だけ)・(位置だけ)の行も含む(封の字のまま)。文書は、判定が変わる行を分類別にも並べる(当否は封の字の合計で判定する)。
5. 下調べの 2 書類は本番の書類に含まれる。本番の記録はこの 2 書類についても作り直す(下調べの出力は使わない)。下調べの script は `measure/` に入れない(本番の script は §2 と、この §6-5 のとおりに書き直す)。
