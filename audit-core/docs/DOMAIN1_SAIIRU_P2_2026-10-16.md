### §1-1 なぜ増えたのか ― **歳入の款は 1 つではない**

実例(公債費会計)。歳入側の款は 財産収入・繰入金・諸収入・都債 の **4 つ**で、

## §2 R-独立-6 をどう当てたか

- **6a 値の重複**。歳入側の値が**同じ会計の歳出側のどれかの値**と一致したら数えない。
  **99 件落ちた。18/18 の会計で効いた。**
- **6b 代数的に決まる**。**行ごとに**落とした(列ごとではない)。
  - `調定額 = 収入済額 + 不納欠損額 + 収入未済額` … 96 行中 **91 行で成立 → その 91 行を落とす**
  - `予算現額と収入済額との比較 = 予算現額 − 収入済額` … 96 行中 **57 行で成立 → 落とす**
  - **列ごとに「全部の行で成立」を要求すると緩い。**調定額は 5 行の例外があるので、
    列ごとだと 91 行も数えてしまう。**だから行ごとに落とした。**
  - `款 = Σ項` は **480 行中 480 行で成立**した。だから**項・目・節は数えない**
    (測らずに落としたのではない)。
- **6c 親子**。款だけを数えるので該当しない(I-2 は引き続き効く)。
- **6d 一意性**。その値を持つ正本が 2 つ以上なら数えない。**11 件落ちた**
  (不納欠損額・収入未済額の **0** が代表例)。
- **6e 出どころの重複**。P-1 で **0 件**(書類の表題 19+19 を除いた上での 0)。
- **6f**。**別の file だから独立とは書かない。**上の 6a〜6e を 1 つずつ測った結果だけを根拠にする。
