### §2-3 段 1 ― サマリーを足したときに動く行

「前」と「後」を鍵で突き合わせ、次を数える(全体・群別・前の state 別)。

- 前にだけ在る行・後にだけ在る行。
- 両方に在る行のうち、state が変わった行・state は同じで reason だけ変わった行・state も reason も同じで pointer の並びだけ変わった行。
- state の移り変わりの表(前 → 後)。前は `GROUNDED` で後は `GROUNDED` でない行・その逆。
- 変わった行を 1 行でも持つ本の数。
- 当たる例: 鍵が同じで前が `VALUE_MISMATCH`・後が `GROUNDED` → 「state が変わった行」。当たらない例: 鍵・state・reason が同じで pointer の並びだけ違う → 「pointer だけ」の欄に数え、「state が変わった行」には数えない。

### §2-4 段 2 ― engine の語彙は予想の枠の fact に届くか(engine は動かさず `measure/` の側で数える)

P の行 1 つずつについて、その本のサマリーの「予想の枠の fact」(以下 F)に、engine 自身の語彙で届くかと、値が合うかを別々に見る。

- F: `I.load_instance(PS.summary_zip(zb))` の fact のうち、`PS.is_forecast_context(その枠)` が真のもの。除く条件は `PS.split_facts` と同じ。名前を落とさずに持つ。F の個数が `PS.split_facts` の F の個数と違えば止める。
- 値が合う: `PS.match_fact(claim, fact の単位, fact の値, 読み)`。読みは「字のとおり」(主)と「円の族」(参考)の 2 通り。
- 主語の語: raw の claim の `subject`。
- 語の要素名: 手書きの `V.PROFILES["P33E"].subjects` の中で、語がその `subject` と字で同じ組の要素名を全部合わせたもの(engine が label で置き換えた後の語彙は外から取れないので使わない)。
- 名前が届く fact(N): F のうち、局所名(`:` の後ろ)が要素名のどれかと `instance.facts_for` の「完全一致」の条件で合うもの。1 つも無ければ、要素名のどれかを小文字にしたものが局所名を小文字にしたものに含まれるもの(`facts_for` の「部分一致」と同じ。完全一致が 1 つでも在れば部分一致は見ない)。

P の行の札は上から順に 1 つだけ(読みごとに):

1. 当てない: `PS.claim_kind(claim, 読み)` が `None`。
2. F が空: その本の F が 0 個。
3. 主語なし: `subject` が空。
4. 語彙の外: `subject` は在るが、手書きの語彙にその語が無い。
5. 両方: N の中に値が合う fact が在る。
6. 値だけ: N の中には値が合う fact が無い(N が空でもよい)が、F のどれかに値が合う。
7. 名前だけ: N は空でなく、F のどれにも値が合わない。
8. どちらも無し: N が空で、F のどれにも値が合わない。

- 札 3・4 の行は、F のどれかに値が合うかどうかを副の欄で数える。札 5 の行は、届き方が完全一致か部分一致かを副の欄で数える。
- 当たる例: 主語の語が語彙に在り、その要素名と局所名が同じ予想の枠の fact が在り、その fact が `match_fact` で真 → 「両方」。当たらない例: 同じ行で、値が合う fact が別の名前の fact だけ → 「値だけ」。
- 対照: 便 PS と同じ「別の本」(`PS.other_books` の輪で次の本)の F で同じ札を付け、「両方(他)」を数える。札 1〜4 は自分の本と同じ扱い(F が空は別の本の F で見る)。
- 読みの軸との重ね: `read_types_2026-11-17.json` の行のうち甲組と乙組(P の行。計 90 行)を鍵(本の #, 文の番号, 位置)で引き、円の族の読みの札を数える。鍵が引けない行が在れば数えて書く(止めない)。W 組は P の行でないので使わない。
