# 第 3 層 解釈(**ここから先は解釈である**)

## §3-1 言えること

1. **この標本では、LLM 単体が強すぎて、封じた合成規則では Core の出番が無かった。**
   席は T5 の 50 行すべてを自力で見抜き、**注入 64 行で一度も「確認済み」と言わなかった。**
2. **「席が迷ったところを埋める」という足し方では、値検索は有害である。**
   偽警報 1.6% → **48.4%**。**Core は 1 件も増やさなかった(1.6% のまま)。**
   **買い手にとっての差は「改善」ではなく「壊さないこと」だった。**
3. **参照先の特定は 4 腕すべて 70.0% で同じ** ― この標本では**参照先の質を決めたのは席**で、
   照合器(Core も値検索も)は**1 件も動かせなかった。**

## §3-2 言えないこと

1. **Core に価値が無いことの証明ではない。**測ったのは**この合成規則での価値**である。
   **Core が強いのは「席が参照先を名指した行を検査する」役**だが、
   **封はその役を与えていない**(「席を上書きしない」ため)。
2. **(ア) で測った「Core は止めながら参照先を 71.9% で名指す」は否定されていない。**
   今回は**その能力が使われる場面が 0 行だった**だけである。
3. **人工の誤りである。**実際の書類で起きる誤りではない。
4. **誤りを示唆する問いの下での成績である。**通常の読みでの成績ではない。
5. **8 書類・192 行・1 席の 1 回である。**別の席・別のモデルでは変わりうる。
6. **`S100YXF5` は T5 が 0 件**なので軸B の分母に入っていない(7 書類ぶん)。
7. **既存製品との比較・売却価値は測れない。**

## §3-3 次に測るべきこと(**人間の判断**)

**この便の結果で封を変えない。**次を**新しい封**として出すかは人間が決める。
