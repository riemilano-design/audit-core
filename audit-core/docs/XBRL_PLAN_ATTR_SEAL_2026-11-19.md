## §2 規則

### §2-1 行の引き直し

- 便 SC の script の関数を呼んで(写さない)、便 SC と同じ切り出し・同じ engine で 3 便の行を引き直す。行の鍵は便 SC と同じ(便, 本の #, 文の種類か節(TSS は無し), 文の番号, 位置)。
- **結んだ行** = state が `GROUNDED`(以下 G)か `VALUE_MISMATCH`(以下 V)の数の claim。**member の欄が空かどうかは問わない**(便 SC と違う。実績か計画かは範囲と別の軸なので)。
- **engine が止めた行** = state が `UNVERIFIABLE` で理由が `target_or_plan` の数の claim(以下 P)。

### §2-2 配線の確認(予測ではない。違えば止める)

- 引き直した結んだ行の鍵と state の集まりが、便 SC の記録の「行」の(鍵, state)の集まりと同じ(行の数も)。1 行でも違えば止めて司令塔に返す。
- 位置の欄の読み方は便 SC の script と同じ関数を使う(便 SC の結果の文書「封との差」(1)の読み替えのまま)。
- **当たるはずの行に当たるか**: P の行のうち、決算期の字の規則で止まった行(claim の欄 `p27_gate` が `future_period`)を除いた行に、下の「文の全部に類 P の語」を当てる。当たった数と当たらなかった数を記録に書く。当たる率が 95% 未満なら止めて司令塔に返す(語の当て方か文の取り方が engine と違っている疑い)。

### §2-3 手がかりの語(字で留める)

文の字は engine が切った文の字(NFKC 済み)をそのまま使う。語は部分一致(字の並びが在るか)で見る。

| 類 | 語 |
|---|---|
| P(engine の規則と同じ語) | 「目標」「計画」「見込」「見通」 |
| F(先の期・予定) | 「予想」「予定」「予測」「想定」「次期」「翌期」「来期」「翌事業年度」「翌連結会計年度」「方針」 |
| E(見積り) | 「見積」「仮定」「試算」 |

### §2-4 止める条件(3 段。狭い → 広い)

対象は結んだ行の全部。

- **前の字** = その行の文の、頭から数の位置の手前まで。
- **見出し** = 便 SC の封 §2-4 と同じ(文の列の中で、長さが 40 字以下・「。」で終わらない・数の claim を 1 つも持たない文)。最も近い見出しの決めも同じ(その行の文より前で最も近い 1 つだけ。無ければ当たらない)。
- **段 1**: 前の字に P の語が在る。(engine の規則の窓を、文の頭まで広げた形。)
- **段 2**: 段 1、または、前の字に F の語が在る、または、最も近い見出しに P か F の語が在る。
- **段 3**: 段 2、または、その行の文の全部(数の後ろも)に P か F の語が在る、または、前の字に E の語が在る。
- 止めた行は「計画・見積りで止めた」と数える。state は書き換えない(engine の外の数え直し)。
- 当たった類の記号: P・F・E は前の字、H は見出し、W は文の全部(前の字では当たらず、数の後ろの字で当たった)。複数に当たれば全部に数える。

### §2-5 数えるもの(段ごと)

1. 結んだ行の全部について、便ごと・state(G / V)ごとの、行の数と止めた数。KAM は文の種類ごと、YS は節ごとにも。P の行の数も便ごとに並べる(engine が既に止めている量)。
2. 読みの札つきの行(KAM 133・YS 169・TSS 120)。札の鍵がいまの engine で同じ state で引けた行だけを分母にし、引けなかった数を別に書く(便 SC と同じ引き方)。
   - V の札の行: 「見積り・計画」(便 AT の写しの表で 外(見積り・計画)に写る札。前の記録では YS 7・TSS 20・KAM 0)と「それ以外」(分母から除く札は除く)の、行の数と止めた数。「それ以外」は属性ごとにも。
   - G の札の行(KAM・YS だけ): 札 a・b・c ごとの、行の数と止めた数。
3. どの類で当たったか(P・F・E・H・W)の、段ごと・state ごとの数。
4. 便 SC の段 2 との重なり: 結んだ行の全部と、札つきの行のそれぞれについて、(便 SC の段 2 で止めた / 止めない)×(この便の段 2 で止めた / 止めない)の 4 つの数。便 SC の側は便 SC の記録の行の欄から読む(計算し直さない)。

### §2-6 記録に書かないもの

文・値・要素名・枠の id・pointer の字・主語の語・会社名・証券コード・docID・金額。行の鍵と state・段ごとの当たった類だけ。語の表(§2-3 の字)は記録に書いてよい。

## §3 分母

- 全部の結んだ行(便ごと。数は便 SC の記録と同じになる)。
- 札つきの行のうち、いまの engine で同じ state で引けた行。**「見積り・計画」の札の V の行は前の記録で 27 行(YS 7・TSS 20)しか無い。** YS の 7 行は全部が 1 つの節(配当政策)。率は 1 行で 3〜4 ポイント動く。

## §4 予測と外れ方(当たり外れは結果の文書で。主の読みは字のとおり)

率は「止めた数 / 分母」。合計は便ごとの分子と分母を足した率。「見積り・計画」の札の V の行の引けた分母が 15 行未満なら、PA-1・PA-5・PA-6 は「測れていない」と書き、当たり外れを付けない。

| # | 予測 | 外れ方 |

## §5 限界(結果の文書の頭に書く)

- engine は変えていない。止めた数は engine の外の後付けの規則の数で、engine の旗にしたときの数ではない。
- 読みの札は AI の席(司令塔)1 席が付けた。盲検でなく、人は読んでいない。この便は札の正しさを 1 つも確かめない。
- 「見積り・計画」の札の V の行は 27 行で、KAM は 0 行。YS の 7 行は 1 つの節。率は粗い。
- TSS の G の行には札が無い。「正しい結びの減り」を札で言えるのは KAM と YS だけ。
- 語の表は司令塔が書いた。盲検でない。別の語の表なら数は変わる。
- 止めた行が「止めて正しかった」かは札の在る行でしか言えない。止めたあとに計画の出所(サマリーの予想の fact など)へ結べるかは測らない(便 PS・SE が別に見た)。
- 見積りの数(類 E)は「計画」と性質が違う。KAM の「値が違う」の行に見積りの札は 0 行だったので、類 E が何かを正しく止めるかはこの便の札では言えない。数えるのは副作用の側だけ。
- 材料は決算短信の概況の文(400 本)と有報の KAM・3 つの節(201 本)。ほかの書類には言えない。
