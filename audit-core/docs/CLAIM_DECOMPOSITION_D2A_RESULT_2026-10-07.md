## 2. 取り返しのつかない記録の損失

**`gold_02` / `gold_03` / `gold_04` は、移行前の版が git のどこにも存在しない。**
作成直後にコミットせず、司令塔が移行してから初めて世に出したため、
`git log --all` にも `git stash` にも移行前の版が無い。

したがって **この 3 本について「移行が忠実だったか」は、永久に独立に検算できない。**
作成者が報告した移行前の sha(`b32d3b0d…` / `19d59ba4…` / `c3996672…`)と比べる対象が無い。
監査の確認は「現状の件数・form 分布が自己申告と一致する」という内部整合までで止まっている。

**規則(今後)**: 他人が作った材料に機械的な変換を掛けるときは、**変換の前にコミットする。**
変換してから世に出す運用は、以後この種の検算を永久に不可能にする。
