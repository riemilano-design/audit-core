> あの欄は A1 の経路が自分の記録として書いているだけ。**A1 が無い木では割れない。**

**本線が自分で測って違うと分かった**(本線の `P7` 188 件中 50 件が非 None)。
**こちらでも測り直した。8 書類:**

| 構成 | 行 | **`word` 有** |
|---|---|---|
| `base`(`P7`) | 1068 | **370** |
| `all8`(`P13`) | 1003 | **305** |

**0 ではなく 370 件だった。**

### 原因 ― **自分の絞り込みが作った 0**

帯の表を作るとき、こう絞っていた:

```python
if v is None or rec is None or u not in UNIT or not c: continue
```

**向きだけの主張(「増加しました」と金額を書かないもの)は `value` が無いので、
ここで全部落ちる。** そして `word` が付くのは**まさにその行**である。

| 構成 | 絞り込みを通った行 | **絞り込みで落ちた `word` 有の行** |
|---|---|---|
| `base` | 381 | **370** |
| `all8` | 427 | **305** |

**落ちた数と `word` 有の数が完全に一致する。** 0 は材料の性質ではなく
**こちらの絞り込みの帰結**だった。

### これは[[zero-count-may-be-my-own-bug]]の 3 回目で、**初めて他席に害が出た**

前の 2 回は自分の報告の中で止まっていた。今回は
**本線がこの 0 を受け取って「向きの語で割る」案の扱いを下げた。**
本線は「他席の見立てを自分で測らずに受け取った」のを自席の落ち度として記録したが、
**誤った数を渡したのはこちらである。**

**規則を 1 つ足す:** **他席に「0 件」を渡すときは、
その 0 を作りうる自分の絞り込みを同じ文に書く。**
「`word` は 0 件」ではなく「**`value` と `unit` が取れた行に絞ると `word` は 0 件**」
と書けば、相手は絞り込みを外して確かめられた。

## 2. **欠陥: 帯の表は `abs` を二重に掛けていて、負の残差が原理的に見えなかった**

本線の封A で**負の残差 2 件**(`N082` −0.236・`N084` −0.214 ― どちらも
**pointer は正しく、書き手が切り上げていた**)が出て、
「`< 0` の側も数える価値がある」と示唆された。**こちらの計器では数えられなかった** ―

```python
abs(abs(rec) - abs(v) * UNIT[u])     # ← 外側の abs で符号が消える
```

**符号つきで測り直した**(8 書類・`fixA1_amount`):

| 経路 | `< -1` | `= -1` | `(-1,0)` | `0` | `(0,0.5]` | `(0.5,1)` | `= 1` | `> 1` | 計 |
|---|---|---|---|---|---|---|---|---|---|
| `equals_within` | 15 | 0 | **0** | 138 | 4 | 10 | 0 | 171 | 338 |
| `diff(a-b) equals_within` | 0 | 0 | **0** | 33 | 0 | 0 | 0 | 56 | 89 |
| `builtin:sign(…)&amount` | 5 | 0 | **0** | 21 | 0 | 0 | 15 | 47 | 88 |

**読めること:**

- **書き手が切り上げた型(小さな負の残差)は、こちらの 8 書類で 0 件。**
  `< -1` の 20 件は**大きな負**で、丸めではなく束縛の誤り(§3 の型 A・B と同じ族)。
- **つまりこの軸も、こちらの材料では測れない。** 本線が封B で踏んだ
  「検出力不足」と同じ形 ― **「無い」ではなく「測れていない」。**
- 本線の `S100Z3JY` は **2/45 = 4.4%**。**書類で在る/無いが変わる。**

### `A1-A2` に効くこと

**いまの梯子の `truncate` 枝は `0 <= d < unit` なので、負の残差を一切通さない。**
書き手が切り上げる書類では、残差 `(-0.5, 0)` の**正しい主張が止まる**
(本線の 2 件がまさにこれ)。
**整数の差の導出は `|d| ≤ 1` なので、`A1-A2` の境界は最初から負の側も含む** ―
ただし**それを支える実測はこちらにはまだ 0 件**であることを封に書く。

## 3. 本線から受け取った申し送り(**根拠には使わない**)

| | |
|---|---|
| 向きの語は **`word` 欄では取れない**(`abs` 群 34 件は全件 None)。**span から読む** | こちらの訂正と整合 |
| 語彙を広げると数が変わる ― 「増加/減少」で 13 件、「増収・減益・拡大」まで入れて 15 件 | 封に語彙の範囲を書く |
| **`13/34` や `2/4` を率として移さない** | 書類で大きく動く(34 → 4) |
| **分母の見積りを先に書く** | 本線は書かずに検出力不足を踏んだ |
| `decimals` に初めて **`-6`** が出て、残差 0 の率が **100%(15/15)** ― 2 軸分離を支持。**ただし 1 書類・1 提出者で交絡**。根拠に使わない | `A1-B` でこの 15 件を使わない |
| **`N275`/`N276` 型** ― 金額・科目・期間はすべて一致するのに**区分・関係**が誤り。**封A も封B も届かない軸** | **`Binding` 封を立てる前に、こちらの 7 件と重なるか見る** |

## 4. 封を立てる前にやると決めたこと

1. **分母の期待件数を先に書く。** 材料の数はその後に決める。
2. **「0 件」は、それを作りうる自分の絞り込みと一緒に書く。**
3. **符号を潰さない。** 残差は符号つきで数える。
