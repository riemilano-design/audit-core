# 素材を作る席への頼み(便 UM2)

封: `docs/UNIVERSAL_THROUGH_SEAL_2026-11-23.md` §1-2。この紙と、空の folder 1 つだけを席に渡す(定義表・材料の型・検査の規則・封は渡さない・読まない)。司令塔は、頼みの頭に「会社の番号・業種・決算月」と「folder の path」だけを足す。

## 頼むこと

あなたは、架空の中小企業 1 社の経理の担当です。架空の会計ソフトと、その周りの道具(給与・固定資産・借入・販売の管理など)から抜き出した file 一式を、渡された folder の中に作ってください。folder の外は読まない・書かない(python の標準 library と、xlsx を書くなら openpyxl は使ってよい)。

1. 実在の製品の名・実在の会社の名は使わない。
2. **3 会計年度ぶん**(古い順に Y0・Y1・Y2)の取引が在ること。folder を 2 つ作る。
   - `期1/` ― Y1 の決算が済んだ時に担当が出せる file(Y1 までの中身)。
   - `期2/` ― その 1 年後に出せる file(Y2 までの中身)。
   - 同じ道具から出した file は、`期1/` と `期2/` で同じ名・同じ列にする。
3. 仕訳の行を全部持つ file(仕訳帳)を必ず入れる。ほかに何を入れるか(試算表・決算書・月次の推移・固定資産の台帳・借入の返済予定・給与や人員の表・部門別・予算 など)と、file の形式(CSV・xlsx)・文字コード・列・見出し・科目の体系は、あなたが「実際にありそうな形」で決める。
4. **数は file の間で会計として合うように作る**(仕訳から足した額と、試算表・決算書の額が合う。貸借が合う)。
5. 実際の帳簿に在る癖を、あなたの考えで入れてよい(決算整理の仕訳・補助科目・部門・消費税の行・途中で足された科目・取り消しの仕訳 など)。入れた癖は `正解/メモ.md` に書く。
6. 素材を作る script は `作り方/` に置く。乱数の種を固定し、もう 1 回走らせると同じ file が出ること。
7. `正解/正解.json` を書く。鍵は `期1`・`期2`。それぞれの下に、次の名の項目の値(本当の大きさ。円か人の整数)を入れる。素材から出せない項目は `null`。`期1` の当期は Y1、`期2` の当期は Y2。
   - `売上高_当期`・`売上高_前期`・`売上総利益_当期`・`営業利益_当期`・`営業利益_前期`・`経常利益_当期`・`当期純利益_当期`・`減価償却費_当期`
   - `現金及び預金_当期末`・`流動資産合計_当期末`・`資産合計_当期末`・`短期借入金_当期末`・`長期借入金_当期末`・`負債合計_当期末`・`純資産合計_当期末`・`純資産合計_前期末`
   - `月次の売上高_当期`(12 個の並び。期の初めの月から)・`借入の残高の合計_当期末`・`期末の従業員数_当期末`・`人件費_当期`
8. `正解/メモ.md` に、決算月と Y0・Y1・Y2 の始まりと終わりの日付・file の一覧・入れた癖・項目の意味をどう決めたか(例: 人件費に何を入れたか)を書く。

終わったら、作った file の数と、正解の値が素材と合うことを自分でどう確かめたかを、短く報告してください。
