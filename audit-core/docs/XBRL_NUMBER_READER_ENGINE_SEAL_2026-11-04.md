## §1 規則 N(engine の直し。字で固定)

### §1-1 読む形

正規表現(`extract.py`。`_SIGN_2026_10_21` = `(?<![\d.,])(△|▲|－|-|マイナス)?\s*` を頭に付ける):

```
_X_2026_11_04 = r"(?:\d{1,3}(?:,\d{3})+|\d+)(?:\.\d+)?"
_MAN_COMMA_RE_2026_11_04 = re.compile(
    _SIGN_2026_10_21 + r"(?:(" + _X_2026_11_04 + r")兆)?(?:(" + _X_2026_11_04 + r")億)?"
    r"(?:(" + _X_2026_11_04 + r")万)?(?:(" + _X_2026_11_04 + r"))?円")
```

当たりのうち **兆・億・万のどれか 1 つ以上の組がある**ものだけを使う(兆・億・万のどれも無い「1,234円」は使わず、既存の読みに任せる)。

### §1-2 値・単位・位(prec)・符号

- 値 = 兆 × 10^12 + 億 × 10^8 + 万 × 10^4 + 円の組(コンマを除いて float)。単位は「円」。符号は既存と同じ(印があれば −1)。
- 位(prec) = 書かれた**最小の位の組**の位(円の組があれば 1、無ければ万 10^4、無ければ億 10^8、無ければ兆 10^12)を、その組の小数部の桁数 k で 10^k 割る(P27 A と同じ。「1,234.5万円」は 10^4 / 10 = 10^3)。

### §1-3 既存の読みとの優先(§1-1 の当たりを t、`iter_numbers_2026_10_27(s)` の読みを (a, b, …) とする)

1. 既存の読みのどれかが t の範囲を**全部覆う**(a ≤ t.start かつ t.end ≤ b)なら、t は**使わない**(既存の読みのまま。「12億円」「12.3億円」「1,234億円」「2兆3,471億円」「380億6千4百万円」「12億3456万円」は 1 字も変わらない)。
2. それ以外の t は使い、t と範囲が**重なる既存の読みは捨てる**(G5 と同じ。「1万2,345円」で既存が読んだ「2,345円」は捨て、12,345 円を 1 つ読む)。
3. 返す列は位置順。`iter_numbers_2026_11_04(s)` は `iter_numbers_2026_10_27(s)` を包むだけで、覆われた t が無ければ出力は同じ。

### §1-4 例

- **当たる**(いまは読まない → 読む): 「1,234万円」= 12,340,000 円(位(prec) 10^4)。「12億3,456万円」= 1,234,560,000 円(10^4)。「1,234億5,678万円」= 123,456,780,000 円(10^4)。「1.5万円」= 15,000 円(10^3)。「△1,234万円」= −12,340,000 円。
- **当たる**(いまは下の桁だけ別の数として読む → 1 つの数に): 「1万2,345円」= 12,345 円(位(prec) 1。いまの読み「2,345円」は捨てる)。「1,234億5万円」= 123,400,050,000 円(10^4。いまの「5万円」は捨てる)。
- **当たらない**(既存の読みが全部覆うので変えない): 「12億円」「12.3億円」(P27 A の 10^7 のまま)「1,234億円」(単位 億円 のまま)「2兆3,471億円」(G5 のまま)「380億6千4百万円」「6万5千円」「148円22銭」「1,234円」「1,234百万円」「8,420,000千円」「3.5%」「1,234人」。
- **当たってしまう例(代価)**: 「1,234万」のあとに「円」が離れて続く形(「1,234万 円」= 空白あり)は `\s` を挟まないので当たらない(いまも読まない)。年月・注の文脈の除外(`EXCLUDE_CONTEXT`)は claim を作る側で今までどおり掛かる。
