## §3 記録の監査で見たこと(記録に欄の無い読み。結果の門は縛らない)

- **同じでない 2 本の理由は便 XT0 と同じ。** 監査の席が道具を直接呼んで読んだ。違うのは概念の書き出しの 1 行ずつで、型の欄の接頭辞の字だけ(元は標準の型の一覧の接頭辞・組み直しは部品が置いた汎用の接頭辞)。
- **組む命令は folder のほかを材料に読んでいない。** 監査の席が本番だけの書類から 5 本を選び、開いた file を全部記録する仕掛けを掛け、置き場も元の包みも見えない別の process で組んだ。開かれたのは folder の file・前の便の script・engine の module・標準の library だけで、zip・置き場・元の包みは 0 件。
- 同じ 5 本で、別の process で 2 回組んだ file は全部 bytes で同じ。組み直した包みと元の包みは別の包みで、置き換えた file の多くは元と bytes で違った。それぞれを道具に掛けた書き出し・fact・符号ごとの行の数は記録と一致した。
- **比べる元は `.xbrl` を除いた写し。** 監査の席が `.xbrl` を残して掛けたときは符号の行が増え、記録と合わなかった。除くと一致した。

- 混ぜ物のうち 3 個を監査の席が道具に直接掛けた: 数の字を変えたものは fact の行で・ラベルを変えたものはラベルの関係の行で違いが出て、符号は変わらなかった。計算の向きを返したものは符号が変わった。「fact を抜く」は監査では直接掛けていない(記録は 5/5)。
