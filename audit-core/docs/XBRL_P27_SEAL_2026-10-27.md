### §1-1 A 書かれた精度で照合する(旗 `written_precision_2026_10_27`)

- `extract.py` に新しい関数 `iter_numbers_2026_10_27(s)` を足す。`iter_numbers_2026_10_21(s)` の各 `(a, b, 値, unit, prec)` について、`unit` が `V.UNIT_SCALE` の key(円・千円・百万円・億円・兆円)で `prec` が None でないとき、`s[a:b]` の**最後の数字の組**(正規表現 `(\d[\d,]*)(?:\.(\d+))?(?=\D*$)` の当たり)に小数部があれば、`prec = prec / (10 ** 小数部の桁数)` にする(0.1 を掛けない。整数のべきで割る)。それ以外は `prec` を変えない。`iter_numbers`・`iter_numbers_2026_10_21` の字は変えない。
- `recipes._numbers_of`: 旗が真なら `E.iter_numbers_2026_10_27(s)` を返す(G5 の行より前に 2 行足す)。
- `recipes._direct_value_claim`: 既存の `scale = prec if unit == "円" else V.UNIT_SCALE[unit]` の行は変えず、その直後に「旗が真で、`unit` が `V.UNIT_SCALE` の key で、`prec` が None でなければ `scale = prec`」の 2 行を足す。この `scale` が照合の帯・`claim_scale`(Core の比較器の帯)・最後の枝の証拠 (i)〜(iii) の桁に、そのまま使われる。
- 変えないもの: 向きの語の金額(A1、`E.iter_numbers` を直接呼ぶ)、% の帯(P18・P23)、書類の丸め方の決め方(`decide_rounding` の字。ただし根拠の帯は狭い `claim_scale` で数えられる)。
- **当たる例**: 「売上高は12.3億円」(精度 1 億円 → 0.1 億円。fact 1,234,000,000 円なら round で |12.34 − 12.3| = 0.04 億 ≤ 0.05 億 で一致のまま。fact 1,270,000,000 円なら、今までは 0.4 億 ≤ 0.5 億 で一致、これからは 0.4 億 > 0.05 億 で一致しない)。「1,234.5百万円」(1 百万円 → 0.1 百万円)。「1株当たり利益は132.47円」(1 円 → 0.01 円)。

- 代価: 書き手が書類と違う丸め方で小数を書いた正しい文は、一致から外れうる(試作で A が一致から外した行は、調整用で 2(どちらも来期の予想の数が当期の実績に単位の帯で偶然合っていた行で、C3 も当たる)、97 書類のうち測った 87 で 0)。精度が細かくなるので証拠 (ii)(差 ≤ 2 × 主張の桁)も細かくなり、小数つきの数の整数の位を変えた誤りは (ii) で名指されなくなる(調整用の T1_VALUE で、名指して原本の値を返した行が P26 8 → P27 5・P27E 7。P27E でも名指さない 1 行は差が約 97% で B の外)。
