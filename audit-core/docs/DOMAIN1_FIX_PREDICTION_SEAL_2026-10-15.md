## 2. 修正の仕様(**何を変え、何を変えないか**)

### F-1(C-1)列の手がかりは**最も近い**語にする

- 変える: 列の手がかりは、数より前で**開始位置が最大**のものにする。同位置なら**長い語**を採る。
- 変えない: 列名の一覧そのもの(`COLUMNS` の 8 語)。主語の手がかりの窓。
- 試験: **1 文に複数の列名が並ぶ文**を手書きで作り、2 番目・3 番目の数が自分の列に付くこと。

### F-2(C-6)手がかりは**その位置で最長の語**でなければ採らない

- 変える: ある位置で当たった列名が、**同じ位置を覆うより長い語**(会計名・科目名・階層語
  `会計/款/項/目/合計`)の一部なら、**列の手がかりとして採らない。**
- 変えない: 列名の一覧。`計` を一覧から消さない(消すと `計` 列そのものが引けなくなる)。
- 試験: `地方消費税清算会計は…` の `計` が列として採られないこと。
  `…の計は1,000円` では `計` が採られること。

### F-3(C-7・C-3)**一意に同定できなければ結ばない**

- 変える: `R-1` で結ぶ条件に、**4 欄(会計・階層・科目名・列)が候補集合の中で一意であること**を足す。
  - 絞り込み後の候補が 4 欄で**割れている**なら、**値が一致する候補が在っても結ばない**(保留)。
  - 4 欄が**全部同じで file だけ違う**候補は、**同じ論理セルの重複**として扱い、結ぶ。
    採る file の順は **総括 → 決算書 → 明細** と**先に決める**(値で選ばない)。両方の参照を証拠に残す。
  - 数より前の区間に**異なる列の手がかりが 2 つ以上**あるなら(`歳入・歳出とも`)、**列は不定**として保留。
    区間は「同じ文の**直前の数の終わり**(無ければ文頭)からこの数の開始まで」。
- 変えない: **値が一致するだけのセルは結ばない**という既存の規則(仕様 §4)。`R-3`・`R-4` の順位。
  **帯を広げない。閾値は 1 つも動かさない。**
- 試験: 同値の 2 列を持つ文で保留になること。**`GROUNDED` が `保留` に落ちた件数を別に数える。**

### F-4(C-2)別名は**文字列だけでは決めない**

人間の指示: 「表記正規化と対象同一性の確認を分ける。**文字列が違うだけで同一と決めない**」。

- 変える: 会計名の別名表を**材料から機械で作る**。2 つの名前を同一の会計と認めるのは、
  次の **3 条件を全部満たしたときだけ**。
  1. **接尾一致**: 長い名前が短い名前で終わる(`東京都一般会計` は `一般会計` で終わる)。**前方一致は認めない。**
  2. **どちらも会計の層の名前**である(`款`・`項`・`目` の科目名は対象にしない)。
  3. **値の裏づけ**: 段 3 と同じ突き合わせ(総括の会計の行 ↔ その会計の決算書・明細の合計)が**通る**。
- 正本の名前は**総括の表記**にする(総括はこの文書自身が全会計を並べた面だから)。値で選ばない。
- 条件 1 だけで同一と決めない。**1 でも 3 が通らなければ「別名候補・未確認」として保留**にする。
- 別名表は**単射**でなければならない(1 つの明細の会計名が 2 つの総括の会計に向かない)。
- 変えない: 科目名(`款`・`項`・`目`)の照合。**ここに正規化を足さない。**
- 試験(人間の指摘「誤った会計同士が結びつく可能性」):
  - **前方一致を認めたら赤になる**試験 ― `公債費` (一般会計の款)と `公債費会計` (会計)が
    同一と判定されたら失敗。
  - **値の裏づけを外したら赤になる**変異。
  - 別名表が単射でなくなったら赤になる試験。

### F-5(C-5)主語は**その位置で最長の名前**にする

- 変える: 主語の手がかりも F-2 と同じ最長一致にする(`産業労働費` を `労働費` に負けさせない)。
- 変えない: 「数より前で最も近い名前」という規則そのもの。
