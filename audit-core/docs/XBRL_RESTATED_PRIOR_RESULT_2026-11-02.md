## §6 言えないこと

封 §4 のとおり:
- 97 社は 2026 年提出の有報に偏り、業種・規模の代表ではない。前年の有報が無い会社(5 社)は測れない。
- 「違う」は修正再表示・表示の組替え・会計方針の変更・誤りを区別しない。
- 注入は「翌期の前期欄の値をそのまま書く」1 型で、DB の値の実際の出方(四捨五入・単位・表示)ではない。
- R は measure 側の規則で、engine には入っていない。入れるときは別の封(既定にしない)。
- 名指しは「翌期の前期欄と一致」までで、なぜ翌期で値が変わったかは言わない。

実装の注で決めたこと(走らせる前に script の docstring に書いた):
- R は円族の単位の direct_value の止めた行にしか言わない。対照の分母は止めた行の全部で、言えない形の行も入る。
- pointer が無い行の要素は、手書きの主語の行(profile の subjects)からだけ引く。ラベルから足される行は使わなかった。名指さなかった 3 件はこの限界による。限界を外したときの割合は測っていない。
- 字の形は 2 種([符号]数[.小数] 単位語 と [符号]N兆M億円)だけ読む。千・百・万を混ぜた複合は site にしない(1 件)。丸めは四捨五入で、符号の字は動かさない。
- 候補が複数あるときは engine と同じ並び(計算書の fact を先)で最初に帯の中に入る fact を名指す。
- 同定は位置((sentence, pos))で、位置の字が「差し替えた字」と一致しないときは「対応が付かない」(今回 0 件)。
