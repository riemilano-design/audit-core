# 第 3 層 解釈(**ここから先は解釈である。測っていないことは測っていないと書く**)

## §3-1 なぜ変わらなかったのか ― **候補は 3 つで、どれも測っていない**

1. **天井。**A はこの 35 件で既に 24/24 だった。**変える余地が無い。**
2. **(C) の節の中立の字**(「正しいとは保証されていません。使っても、
   無視してもかまいません」)が、席に証拠を使わせなかった可能性。
3. **席が証拠を読まなかった可能性。**

**どれが効いたかは測っていない。だから断定しない。**
3 を測るには証拠の中身を変えた対照が要り、2 を測るには字を変えた対照が要る。
**どちらもこの封では走らせない**(封 §5 の「やり直しをしない」)。

## §3-2 **第 1 便の結論を訂正する**

第 1 便(`docs/DOMAIN1_POC_AB_RESULT_2026-10-17.md`)に私はこう書いた。

> **偽の確認: A 1 件 / B 0 件 ― Core の唯一の明確な勝ち。**

**§2-7 の診断により、この 1 件は Core の勝ちではない。**
報告文は正しく、席の答えも正しく、**Core の検出は自分の切り出しの符号落ちに
対する空振りだった。**

**したがって、この材料で Core が一般 LLM に勝っている点は 0 件である。**
残るのは**負けている点**(回収 50% 対 100%)と、
**差が無い点**(誤接続 0 対 0)と、
**定義次第の点**(M-3′ 16/16 対 34/35 ― 分母が違う)である。

**第 1 便の結果の文書には、日付つきの追記でこの訂正を足した。本文は書き換えていない。**

## §3-3 顧客にとって何を意味するか(**商談の結果ではない**)

- **「一般 LLM に Core の証拠を渡す」形では、この 35 件で追加価値を示せなかった。**
- **Core 単体の価値も、1 件の勝ちが消えたことで、この材料では示せていない。**
  残るのは「**19 件を保留する**」という挙動だが、
  **保留した 19 件のうち 12 件は一般 LLM が正しく答えていた。**
  **つまりこの材料では、保留は安全の代価であって安全の証拠ではない。**
- **測っていないこと**: 一般 LLM が**間違える**材料での比較。
  今回の 35 件は**一般 LLM が 100% 正しく答えられる材料だった。**
  **Core の価値を測るには、一般 LLM が誤接続する材料が要る。**
  **それはこの材料では作れない**(作ると材料を結果に合わせて選ぶことになる)。
