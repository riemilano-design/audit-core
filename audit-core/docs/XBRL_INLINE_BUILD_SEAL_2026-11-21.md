- **元の包み**: 置き場の zip から、名が `.xbrl` で終わる file を除いた写し(便 XV0 と同じ)。
- **剥がす**(script の部品。元の包みの PublicDoc の `.htm` を 1 つずつ):
  - **素の本文**: その file の字から、`ix:header` の要素を開きタグから閉じタグまで丸ごと除き、`ix:nonFraction`・`ix:nonNumeric`・`ix:footnote` の開きタグと閉じタグ(中身の無い自己閉じの形はそのタグ)だけを除いたもの。タグの中身の字・ほかの字は 1 字も変えない。根の `html` の開きタグ(名前空間の宣言を含む)は元の字のまま残す。
  - **表 F**: 除いた `ix:nonFraction`・`ix:nonNumeric`・`ix:footnote` の 1 つごとに、種類・素の本文の中の始まりと終わりの位置・属性の名と値の組。**属性の並びの順・タグの中の空白・引用符の書き方は持たない。**
  - **表 H**: 除いた `ix:header` の位置と、その中身を読んだ構造 ― 隠しの fact(種類・属性の名と値・中身の字)・参照(スキーマの在りか)・文脈(id・提出者の印・期・軸とメンバー)・単位(id・測りの名、割り算の形ならその上下)。**`ix:header` の元の字は持たない。**
- **組む**(script の部品): 素の本文・表 F・表 H **だけ**を受けて、`.htm` の字を返す。元の `.htm` も元の包みも読まない(引数に取らない)。属性の並びの順・空白・引用符・頭の部の字の形は、組む部品が自分の決めで書く(決めは開発の 5 本で決め、本番の前に script に字で留める)。
  - 組む部品が知らない形(知らない `ix:` の要素・知らない属性・頭の部の中の知らない子)に当たったら、その書類は **断った** に数え、包みは作らない。部品の中で例外が出た書類も断ったに数える。
- **組み直した包み**: 元の包みの PublicDoc の `.htm` を、組んだ字に置き換えたもの。**ほかの file(提出者別タクソノミの `.xsd` と linkbase・マニフェスト・画像・AuditDoc)は元のまま。**
- **比べ方**(1 本ごとに、元の包みと組み直した包みを同じ掛け方で 1 回ずつ):
  - **fact が同じ**: 2 つの CSV を csv として読み、行(全部の欄の字の組)を並べ替えた並びが同じ。どちらかの行が 0 なら同じとしない。
  - **鳴り方が同じ**: 便 XV0 の封 §1 の符号の読み方で数えた、符号ごとの指摘の行の数が全部同じで、1 回の類(走った・止まった・走らなかった)も同じ。
  - **字が同じ**: 組んだ `.htm` の bytes が元の `.htm` の bytes と同じ。`ix:header` を持つ file と持たない file を分けて数える。
- **混ぜ物**(比べ方が違いを見つけるかの確かめ。開発の 5 本 × 3 種類 = 15 個): 表 F を 1 か所だけ変えてから組んだ包みを作り、元の包みと比べる。
  - **抜く**: file の並びと位置の順で最初の、`xsi:nil` の無い `ix:nonFraction` を表から除く。
  - **文脈を替える**: 同じ fact の `contextRef` を、その書類のほかの `ix:nonFraction` が使っている別の値のうち順で最初のものに替える。
  - **符号を返す**: 同じ fact に `sign` が在れば除き、無ければ `sign="-"` を足す(中身の字が 0 だけなら、順で次の fact に当てる)。
