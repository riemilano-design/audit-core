# 様式への耐性の封 ― **抽出処理がどの字・位置・階層に依存しているかを数える(0 USD)**

2026-10-17。**実装・測定より先に commit する。**
人間の決定(2026-10-17)の **(b)** に従う。

> 次は **(b) 様式への耐性を 0 USD で測る**。その後、独立監査を通して (a) に進む。
>
> (b) で特に重要なのは、**「見た目が似ているか」ではなく、
> 「抽出処理がどの文字列・位置・階層に依存しているか」を測ること**です。

> 同じ種類の依存が残っている可能性があります。**

> 現在の封にある指示文は**そのまま記録として保持**し、次の実行用には
> **実際の資料に一致する指示文を新たに定義**して、**新しい版の封に明記**する。
> **既存の封と新しい封の結果を、同一条件の結果として混ぜない。**

**この封で測るのは私の道具の依存である。Core の照合能力ではない。**
**「直せば通る」とは書かない**(直していないので測れない)。

## §1 測るもの ― **3 つ。どれも 0 USD・通信なし・生成なし**

| 記号 | 測ること | 道具 |
|---|---|---|
| **測-1** | **抽出処理が判定に使っている字**を列挙し、層で分ける | `ast`(**grep ではない**) |
| **測-2** | その字が**令和５年度・令和６年度の材料に在るか**を数える | 両年度の 5+5 file を読む |
| **測-3** | **年度の字を外した形なら材料に何件当たるか**を数える | 材料の数え上げ |

**抽出器・parser・engine は 1 文字も変えない。**
**測-3 は材料を数えるだけであり、parser を直して通すことではない。**
直す判断は (a) であり、**独立した監査の GO を経るまで実装しない。**

### §1-1 **「判定に使っている字」の定義(実装者が 1 通りに書ける字で書く)**

**字が次のどれかの位置に在るときだけ「判定に使っている」と数える。**

| 当たる(数える) | 例 |
|---|---|
| 比較の相手(`==` `!=`) | `norm(a) == "科目"` |
| 所属の検査(`in` / `not in`) | `name in ("歳入決算額", ...)` |
| `startswith` / `endswith` の引数 | `a.endswith("決算書")` |
| `re.compile` / `match` / `search` / `fullmatch` の型 | `r"^令和６年度東京都(.+)歳入歳出決算書$"` |
| **読み出しの添字**(Load) | `book["総括"]` / `sheets["歳入"]` |
| 上の位置に名前が在るとき、**その名前の module 直下の代入に在る字** | `KESSAN_COLS` → 4 語 |

| 当たらない(数えない) | 例 |
|---|---|
| **書き込みの添字**(Store / AugAssign) | `counted["調定額 を検査"] += 1` |
| 出力の記録の鍵・説明文・`print` の文 | `rec["range_identified"] = ok` |
| docstring・コメント | 「出典: …令和６年度…」 |

**名前が module 直下の単純な代入に解けないときは「解けなかった」として件数に残す**
(**黙って 0 件にしない**)。

### §1-2 **数える範囲(file を字で固定する)**

|---|---|

**この 7 file の外は数えない**(採点器・材料づくり・封の門は抽出処理ではない)。
**数えなかった範囲は結果に書く。**

### §1-3 **層(1 つの字は 1 つの層にだけ入れる)**

| 層 | 定義(**どの判定に使われているか**) |
|---|---|
| **L1 file・シートの選択** | file 名、シート名の添字・比較 |
| **L2 ブロックの境界** | 表題で切る判定(`令和６年度東京都…決算書` 等) |
| **L3 見出しの行の位置** | `科目`・`会計別` のような**行を見つける**字 |
| **L4 列の見出し** | 列名の集合・表層形の表 |
| **L5 階層・科目の語** | `款`・`項`・`目`・`節`・コードの型 |
| **L6 会計名・自治体名** | `東京都`・会計の名前・別名表の字 |
| **L7 符号・単位・除外行** | `△`・`円`・`歳入歳出差引残額` 等 |

**層の割り当ては、その字が現れた判定の種類で決める**(字面の見た目ではない)。
**割り当てが 2 つに跨る字は「跨いだ」として別に数える。**

## §2 測-2 ― **材料に在るか(両年度を同じ関数で数える)**

両年度の **5 file ずつ**を `M1.read` で読み、**シート名の集合**と
**文字列セルの集合**を作り、字ごとに次の 3 つに分ける。**排他。**

| 類 | 条件 | 意味 |
|---|---|---|
| **両年度に在る** | 令和５・令和６のどちらにも 1 件以上 | **この 2 年では年度に依らない** |
| **令和６にだけ在る** | 令和６に在り令和５に無い | **別年度で外れる依存の候補** |
| **材料に無い** | どちらにも無い | 内部の鍵・正規表現の断片など |

**「字が材料に在る」ことは「判定が通る」ことではない**(位置・結合・行の順は別)。
**だからこの表だけで「直せば通る」と書かない**(§5)。

**正規表現の型は字の照合に使えない。**型は**別枠**にし、
`令和` と `年度` を含むかどうかだけを機械で見て、**手で分類しない。**

## §2-1 測-3 ― **年度の字を外した形で材料に何件当たるか**

**決算書 歳出・決算書 歳入の表題行**について、次の 2 つを両年度で数える。

| 型 | 字 |
|---|---|
| **いまの型** | `^令和６年度東京都(.+)歳入歳出決算書$` |
| **年度を外した型** | `^令和.+年度東京都(.+)歳入歳出決算書$` |

**これは材料の行を数えるだけである。**`sheet_m2_structure` は読み込むが、
**その字を書き換えない**(門で sha を固定する)。

## §3 止める条件・失敗の条件

1. **`ast` の読み込みが落ちた file が 1 つでも在れば止める**(数を出さない)。
2. **判定に使う字が 0 件なら止める** ― それは私の数え方の欠陥である
   (記憶 `zero-count-may-be-my-own-bug`)。
3. **1 つの字が 2 つの類に入ったら止める**(排他が壊れている)。
4. **この便で抽出処理を直さない。**直したくなったら (a) として別に出す。
5. **(2) の結果(`DOMAIN1_REPRO_RESULT_2026-10-17.md`)を書き換えない。**
   日付つきの追記だけを足す。
6. **予測が外れても基準を変えない**(人間の条件)。

3. **「直せば通る」とは言えない。**直すのは (a) であり、この便では直さない。
4. **Core の照合能力(C′ 対 D′ の差)は測っていない。**(2) は止まったままである。
5. **判定に使う字の列挙は、私が字で固定した 7 file の中だけである。**
6. **売却価値は測れない。**
