## 3. 2 席を並べて言えること / 言えないこと

**言える**: **「書き手が切り上げる」型は、在る書類と無い書類がある。**
本線は 5 書類中 1 書類で観測し、並行席は 8 書類で 0 件と報告した。
**どちらも「無い」ではなく「その材料では出なかった」。**

**言えない**: 発生率。母集団が比較できないので
「13 書類中 1 書類」のような合算をしてはいけない
(本線 5 書類 + 並行席 8 書類 = 13 という足し算を**しない**)。

## 4. 実装の判断に効くこと(**判断はまだしない**)

いまの `truncate` 枝は `0 <= fv - t < unit` で、**負を一切通さない。**
したがって**切り上げる書類では、残差が (-0.5, 0) の正しい主張が止まる** ―
本線の `N082`・`N084` がまさにそれである。

| 規則 | 本線 5 書類 165 件での誤停止 |
|---|---|
| 現状(`round` を先に試す) | 0 件 |
| **切り捨て専用**(`0 <= d < unit` だけ) | **2 件** |

**封A の A-5 は「既存 3 書類で 0 件」で当たりだが、新しい材料を入れると 2 件になる。**
「切り捨て専用にしてよい」とは、この実測からは言えない。

## 5. 相手の席から受け取った規則(本線でも守る)

> **他席に「0 件」を渡すときは、その 0 を作りうる自分の絞り込みを同じ文に書く。**

その席の「`word` は 0 件」は、`value` と `unit` が取れた行に絞った結果だった
(**向きだけの主張には `value` が無いので全部落ち、`word` が付くのはまさにその行**)。
実測は 1068 行中 **370 件**。
**絞り込みを書かない 0 は、受け取る側にとって検証不能な主張である。**

本線はこの 0 を**自分で測らずに受け取って**、「向きの語で割る」案の扱いを下げていた。
**他席の数を根拠にする前に自分で測る**([[verify-peer-claims-and-path-coverage]] の型)。
なお本線の実測「`abs` 群 34 件は全件 `word=None`」は正しく、
**向きの語は span から読むしかない**という結論は変わらない。
