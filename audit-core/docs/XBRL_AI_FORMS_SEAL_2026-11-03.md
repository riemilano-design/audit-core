## §1 測るもの(字で固定。全部「形 × model × profile」で割る)

1. **配線**: 生成できた本数、1 本あたりの数の claim(P27)の分布、文の字数、費用。
2. **札の分布**: 数の claim のうち 真 / 偽 / 判定不能 の数と率。2 席目の 32 本での一致率。
3. **engine の判定(無改変)**: 4 state の分布。**札 真の行の GROUNDED 率**(= 正しい文を通す率)、**札 真で止めた率とその reason の内訳**(`no_subject`・`no_same_value`・`other_concept` …)。**札 偽の行で止めた率**(= 誤りを止める率)と通した数。
4. **profile の差**: 同じ行で P27 → P28E の state の動き(向き別)。「その他」の形の行の数と決まった数(provenance から)。P27E → P28E の差 = O の効き、P27 → P27E の差 = B の効き。
5. **注入**: 型ごとに 通した / 名指して原本の値を返した / 名指したが別の値 / POINTER_NOT_FOUND / UNVERIFIABLE / 対応が付かない(`classify` の字)。率の分母は対応が付いた注入。
6. **形の性質**: 1 行に数が 2 つ以上ある claim の率、主語が取れた率(`subject` が空でない)、行頭が記号(「・」「|」「Q」「A」)の文の率。
