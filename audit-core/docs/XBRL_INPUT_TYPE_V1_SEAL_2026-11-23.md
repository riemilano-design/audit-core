### 型(第 1 版。書類ごとに JSON 1 つ。UTF-8)

頂は object で、鍵は次の 4 つだけ。

- `型の版`: 字 `1`。
- `書類`: object。鍵は `提出者の識別子`・`識別子の scheme`・`当期の始まり`・`当期の終わり`・`提出日` の 5 つだけ。日は `YYYY-MM-DD` の字。
- `独自の名`: 並び。要素は object で、鍵は `種類`(`科目`・`軸`・`member` のどれか)と `名` の 2 つだけ。行で使う提出者別の名(接頭辞が `_cor` で終わらない名)の全部を、(種類, 名) の字の昇順に、1 回ずつ書く。行で使わない名は書かない。
- `行`: 並び(1 つ以上)。1 行 = 1 つの数か 1 つの文。要素は object で、鍵は `種類` が `数` なら次の 9 つだけ、`文` なら 1.〜5. の 5 つだけ。
  1. `種類`: `数` か `文`。
  2. `科目`: 名の字(`<接頭辞>:<局所名>`)。
  3. `期間`: object。時点なら鍵は `時点` だけ。期間なら鍵は `始まり` と `終わり` だけ。値は日の字。**期の表に在るかどうかは問わない**(第 0 版の型の外 (a) を無くす)。
  4. `対象`: `個別` か `既定`。
  5. `次元`: 並び(空でもよい)。要素は [軸の名, member の名] の 2 つの字の並び。軸の名の字の昇順。
  6. `値`: 字。`無い` か、符号つきの本当の大きさの 10 進の字。
  7. `単位`: 字。`通貨:XXX`・`株`・`純数`・`通貨:XXX÷株` のどれか(XXX は英大文字 3 つ)。この 4 つの形に当たらない単位だけ `他:<分子>` か `他:<分子>÷<分母>` と書く(分子・分母は measure の名を字の昇順に `*` でつないだ字。第 0 版の型の外 (d) のうち `unitRef` の在るものを無くす)。4 つの形に当たる単位を `他:` で書かない。
  8. `表示の位`: 値が在れば整数・`無い` なら `null`。
  9. `精度`: 値が在れば整数・`無い` なら `null`。
- 第 0 版と同じもの: 対象の決め方(個別の軸と member)・値の作り方(負の印つきの 0 は `-0`)・同じ鍵の fact は 1 行にまとめる・型の外の理由 (b)(c)(e)(f)(g)(h)。型の外 (a) は無くなる。型の外 (d) は「`unitRef` が無い・単位の定義が読めない」だけになる。
