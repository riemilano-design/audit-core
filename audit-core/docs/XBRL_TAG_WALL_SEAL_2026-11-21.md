## §2 数えるもの

書類ごとに PublicDoc の `_ixbrl.htm` の file を全部読み、engine の `_TR_RE` で行(`<tr>`)に切る。

1. **タグの数(XG0-1 の分母)**: `<ix:nonFraction ... name="P:L"` の数。`P` が `jppfs_cor`・`jpcrp_cor`・`jpigp_cor`・`jpdei_cor` で始まる(`P` の頭が `jp` で、`_cor` で終わる)ものを **標準**、それ以外を **提出者別** と数える。
2. **計算書の行(XG0-2〜6 の分母)**: 行の中の `ix:nonFraction` の `name` が、(a) 1 つ以上在り、(b) 全部が同じ 1 つの名で、(c) その接頭辞が `jppfs_cor` で、(d) engine の `_row_label(row)` が字を返す行。行の字 T は `_row_label` の返す字を NFKC にそろえたもの。要素 E は name の局所名。
   - (b) を満たさない行(名が 2 つ以上)・(c) を満たさない行(接頭辞が `jppfs_cor` 以外で 1 つ)・(d) を満たさない行は、それぞれの数を記録に書き、分母に入れない。
3. **行の類**(表 L2 で。L1 でも同じ数え方で副の数を出す):
   - **U**(1 つに決まり、正しい): T に当たる要素がちょうど 1 つで、それが E
   - **A**(候補に在るが 1 つに決まらない): T に当たる要素が 2 つ以上で、E を含む
   - **W**(当たるが違う): T に当たる要素が 1 つ以上で、E を含まない(引き当てだけで付けると黙って違う要素になる行)
   - **N**(当たらない): T に当たる要素が無い
   - 「当たる」は字の完全な一致(部分の一致は使わない)。
4. 書類ごとの U の率(その書類の計算書の行が 0 なら、その書類は書類ごとの数から外し、外した数を書く)。
