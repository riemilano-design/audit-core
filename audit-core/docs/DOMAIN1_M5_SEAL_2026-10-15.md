## 1. 新しい答えの形と正解ラベルの定義(C-9)

### 1-1. 採点単位

> 採点単位は、**会計・階層・親・科目・列・値**を対応させた主張とする。

| 欄 | 中身 | 空欄にする層 |

| 階層 | `会計` / `合計` / `款` / `項` / `目` | ― |

| 列 | 列の見出し(`歳入決算額`・`支出済額` など) | ― |

### 1-2. 合計の行(C-4。前回 3 件が判定不能になった穴)

**空欄にしない。**2 席に渡す問いに、この 1 行を**例つきで**書く。
engine 側も同じ字を出す。

### 1-3. 一意性の要件(**これが C-9 の本体**)

  **1 より大きい組が残る階層は、採点の対象から外す**(その階層の主張は保留が正解になる)。
- > 親が特定できない場合は、**値が一致しても正しい接続としない。**
- **値で候補を絞ってはならない。**欄が決まらなければ保留。

## 2. C-8 ― 階層の手がかりの仕様と回帰条件

### 2-1. 仕様

- 文中の階層の語(`款別`・`項別`・`目別`・`款の`・`項の`・`目の`)を**階層の制約**として読む。
- 制約が在るなら、**階層が一致する候補だけを残す。**
- > 値の一致を使って候補を絞るのではなく、**文章の階層指定と資料の階層が一致する候補だけを残す。**
- 階層の語は、列の手がかりと同じ**区間**の規則で拾う(直前の数の終わりからこの数まで。
  無ければ同じ括弧の深さの直前の主張から引き継ぐ)。
- > **階層情報があっても候補が複数残るなら保留です。**

### 2-2. 回帰条件(**両方を同時に満たすこと**)

> 今回の R007 型を救うことと、別の同名科目を誤接続しないことは、**同時に検証する必要があります。**

## 4. 別名の独立した裏づけの定義(③ + 補足条件)

### 4-1. 条件(**全部満たしたときだけ同一対象として扱う**)

1. **独立した 3 本以上**の対応根拠がある(独立の定義は §4-2)。
2. 対応根拠に**食い違いが 0 件**。
3. **会計の層と階層が整合する**(別名は会計の層の名前同士。根拠の行は同じ階層同士)。
4. **接尾一致**である(長い名前が短い名前で終わる)。**前方一致は認めない。**
5. **値が一致するという理由だけで、別名の同一性を認めない。**
6. 条件を満たさない別名は**未確認として保留**する。
   未確認の会計に属する行へは**結ばない**(会計が決まらないので欄が埋まらない)。

### 4-2. 「独立した 1 本」の定義(**人間の補足条件**)

| I-1 | **相異なる科目名**の行であること(同じ行を別の列で 2 回数えない) |
| I-2 | 互いに**親子関係にないこと**(款とその唯一の項は 1 本と数える) |
| I-3 | 一致した値が**互いに異なること**(同じ数が 3 か所に出ても 1 本) |
| I-4 | **2 つの異なる file** をまたぐ一致であること(明細 ↔ 決算書) |
