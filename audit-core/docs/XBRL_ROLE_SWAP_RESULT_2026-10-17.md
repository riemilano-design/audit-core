## §5 上回らなかった原因(**封 §7 の 3 分類で数える**)

| 原因 | 行 | この標本で結論を左右したか |
|---|---|---|
| **contract 不足**(contract が無い・主張が無い・2 本要る) | **31** | **した。**A が通した 41 行のうち 31 行が実証不能になった主因 |
| **未検査属性**(単位・期間・次元・重複) | 0 | **していない。**注入を通した行も、無改変を拒否した行も 0 件 |
| **意味的裏づけの不足**(第 2 層) | ― | **測れない。**リンクベースを読んでいないので材料が無い |

**未検査属性がこの標本で効かなかった理由も書く。**
注入は **T5(他の fact の値を貼る)**だけで、**単位・期間・次元を狙った注入は材料に無い**
(`T2_UNIT` は値が残るため除外されている)。
**だから「単位の穴が危険だ」も「安全だ」も、この材料では言えない。**

## §6 言えないこと

1. **B は A を上回っていない。**「同じ」である。
2. **A の危険な誤通過は 0 件なので、B が誤通過を減らすことは示せない**(封 §5)。
   示せたのは**増やさないこと**だけである。
3. **`検査通過` は「正しい」ではない。**未検査属性 4 つが残る。
4. **席の答えは A と B で同一である。**替えたのは実証の層だけで、
   **LLM の特定能力の差は測っていない。**
5. **同じ 8 書類である。**新しい標本での再現は測っていない。
6. **現行 Core の限界が出たが、それだけで Core に価値が無いとは言わない**(人間の指示)。
