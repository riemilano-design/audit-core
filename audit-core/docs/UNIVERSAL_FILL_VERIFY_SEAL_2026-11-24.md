### 1-3 確かめの状態(段 2 の出力を機械が読んで付ける)

確かめる席は行ごとに `見立て` を書く。表の `状態` が `在る` の行: `合う`・`合わない`・`見つからない`・`決めが要る`。`無い`・`分からない` の行: `無いで合う`・`在るはず`・`決めが要る`。`合う` の行には `出どころ`(便 UM2 の指示書 1-4 の形)を必ず、別の file からも同じ数が出せるなら `別の道`(同じ形)を書く。`合わない`・`在るはず` の行には `正しいと見る数値` と、その `出どころ` を書く。

script は `出どころ` を素材に当てて数を計算し直し(便 UM2 の検査の、出どころから数を出す所だけを使う。見出し・期・単位・範囲の規則は当てない)、行ごとに状態を 1 つ付ける。

| 状態 | 条件 |
| --- | --- |
| 確認済み(2 道) | `合う`・`出どころ` の計算が表の数と同じ・`別の道` の計算も同じ・2 つの `file` が違う |
| 確認済み | `合う`・`出どころ` の計算が表の数と同じ(上に当たらないもの) |
| 根拠なし | `見つからない`。または `合う` なのに `出どころ` が無い・形が読めない・計算が表の数と違う |
| 不一致 | `合わない` |
| 要確認 | `決めが要る` |
| 無いを確かめた | `無いで合う` |
| 無いに異議 | `在るはず` |
| 答えなし | 行が無い・見立ての字が上のどれでもない・file が無い |

- **通す**と数えるのは、確認済み(2 道)・確認済み・無いを確かめた の 3 つ。ほかは**通さない**。
- 不一致・無いに異議 の行で、`正しいと見る数値` が正解と同じなら「直せた」、違えば「直しが違う」、無ければ「直しなし」。

### 1-4 壊した表の作り方(script の `--mutate`。機械。回 α の値の表と `罠.json` から)

1. **罠の値 ×2**: 罠の行のうち、回 α の数が罠の値でない行を id の昇順に 2 つ。`状態` を `在る`・`数値` を罠の値にする。
2. **桁 ×1**: 普通の行で、数の絶対の値が 1000 以上の最初の行。上から 2 桁目の字 d を (d + 1) を 10 で割った余りに置き換える。
3. **隣 ×1**: 2 の行の次の普通の行。`数値` を、その次の普通の行の回 α の数にする(同じ数なら、さらに次)。
4. **無いのに在る ×1**: 無いの行で、回 α の `状態` が `在る` でない最初の行。`状態` を `在る`・`数値` を、a01 の回 α の数を 10 で割って切り捨てた整数にする。
5. **在るのに無い ×1**: 3 で値を借りた行の次の普通の行。`状態` を `無い`・`数値` を `null` にする。

当たる行が無い種類は作らず、作れなかった数を書く。変えた行は、変える前から正解と違っていても「壊した行」に数える(壊した後の数が、たまたま正解と同じになった行は外し、外した数を書く)。

## §3 読み方の決め(結果を見る前に)

- **仮説の判定の字**: 「取得が型の席 + 検査より多い(UM4-G1 の境でなく、1 行でも)」かつ「通した誤りと決めを通したの合計が型の席 + 検査以下」の時だけ、「この 4 社の作り物の素材では、仮説の形になった」と書く。片方だけなら、どちらが成り立ち、どちらが成り立たなかったかを数で書く。**「改善した」「優れている」とは書かない。**
- 通した誤り・決めを通した・壊した行のうち通した行は、0 でなければ結果の文書の頭に数を書く(確かめる席の負け)。止めすぎ・型の席 + 検査が止めた正しい行も頭に書く(それぞれの負け)。
- 壊した表の数は「司令塔が決めた 5 種類の壊し方に対する数」で、「席が自分で作る誤り」に対する数ではない。2 つを足さない。
- 埋める席の誤りが 0 なら、「確かめる席が、席の誤りを止める」は測れていないと書く(壊した表の数だけが在る)。
- 確かめる席は埋める席と同じ種類の AI。「独立に確かめた」とは書かない(文脈が別の席、と書く)。
- 秒と道具の呼び出しは並べるだけ。「速い」「安い」とは書かない。
- **言えないこと**: 「実物の会計の素材で」「人の確かめが要らない」「別の種類の AI でも同じ」「2 期目でも同じ」「資料が正しい」「罠に強い」(罠は 1 社 4 つ・作った席の考えた罠だけ)。

## §4 限界

- 素材は作り物の 4 社・1 期。罠・無い・決めは、素材を作る席が頼まれて入れたもので、実物の帳簿に在る頻度ではない。数(3・4・2)は司令塔が決めた。
- 正解・罠の値・決めの読みは、素材を作った席が書いたもので、独立に確かめていない。素材を作る席・埋める席・確かめる席・型の席は同じ種類の AI で、「ありそうな形」「紛らわしい形」の考えを共有する。
- 確かめる席の頼みの紙は司令塔が書いた。紙の字が、止める・通すの割合を変えうる。紙は 1 通りだけ。
- 機械が計算し直すのは、確かめる席が書いた出どころの数だけ。出どころが項目の意味・期・範囲に合うかは、確かめる席の見立てに任せている(型の席 + 検査は、そこを規則で見る)。
- 型の席 + 検査は便 UM2 の 1 期目の形(人が見出しの表に足す段は無し)。人が確かめた後の数ではない。
- 原の表は回 α だけ。回 β の表は確かめない。1 社につき確かめる席は表ごとに 1 つで、確かめる席の揺れは測らない。
- 司令塔は便 UM2・UM3 の結果を知って予測を書いた(§0)。

## §5 次の便の候補(この封で留める。結果の文書はここに無い候補を足さない)

- (i) 確かめる席の出どころに、便 UM2 の検査の規則(見出し・期・単位・範囲)を当てる形(埋める → 確かめる → 規則)を、新しい素材で測る。
- (ii) 確かめる席の頼みの紙を変えて、通した誤りと止めすぎの動きを測る。
- (iii) 人が「要確認」「不一致」の行を確かめる段を人の手で測る。
- (iv) 2 期目(前の期の確かめの状態を持ち越す)。
- (v) 実物に近い素材(日本の会計ソフトの試しの事業所。アカウントと鍵は人間)。
- (vi) 埋める席か確かめる席を別の種類の AI にする(有料なら別の封と払う前の知らせ)。
