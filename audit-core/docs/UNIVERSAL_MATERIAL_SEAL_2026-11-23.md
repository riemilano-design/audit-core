### 1-2 会社(作り物)と分け方

- 会社は番号 `i` で決まる。**開発の 3 社**は `i` = 101・102・103。**本番だけの 12 社**は `i` = 1〜12。値の乱数の種は `20261123 * 1000 + i`。
- 開発の 3 社は、実装・指示書・検査を作る間に何度見てもよい。席の試しも開発の 3 社でだけ、**多くて 3 巡**。

- 作りで決まる所(`i` で決まる。乱数に依らない):
  - 当期の終わり: `i % 3` が 1 → 2026-03-31・2 → 2025-12-31・0 → 2025-09-30。当期はそこで終わる 12 か月・前期はその前の 12 か月。
  - 形: `i % 3` が 1 → 形 L1・2 → L2・0 → L3(§1-3)。
  - お金の表示の単位: `(i // 3) % 3` が 0 → 円・1 → 千円・2 → 百万円(`決算.xlsx` の中だけ。CSV は円)。
  - 期の言い方: `i % 2` が 1 → 「当期」「前期」(貸借は「当期末」「前期末」)・0 → 「YYYY年M月期」(貸借は「YYYY年M月末」)。
  - 列の順: `i % 4` が 0 か 1 → 当期が左・2 か 3 → 前期が左(罠 T1)。
  - 人員の素材: `i % 3 == 0` の社は `人員.csv` が無い(a30 は無い)。
  - 減価償却費: `i % 4 == 0` の社は減価償却費の行が無い(a08 は無い)。
  - 表に無い言い方(罠 T5): 並び `[a03, a06, a07, a09, a10, a12, a13, a14]` の `i % 8` 番目と `(i + 3) % 8` 番目(0 始まり)の id の行の見出しを、§1-4 の「表の外」の 1 つ目の字にする。
  - 負の数の書き方(CSV と、字で書いた cell): `i % 3` が 1 → `-1,234`・2 → `△1,234`・0 → `(1,234)`。経常利益か当期純利益のどちらかが負になる社を、本番に少なくとも 2 社入れる(`i` = 5・10 は当期純利益を負にする)。
- 値は整数(表示の単位での整数)。会計の関係が成り立つように作る: 月次 12 か月の和 = 売上高(当期)・総資産 = 負債合計 + 純資産・借入金一覧の残高の和 = 短期借入金 + 長期借入金・部門の和 = 売上高。単位が千円・百万円の社では、CSV(円)の側の値を、決算の側の値 × 倍率に一致するように作る。

### 1-6 材料の型(第 0 版。共通構造。会社ごとに JSON 1 つ)

- 材料 1 つの鍵:

  - `無い` の時は、あと `無い理由`(字 `素材が無い`)だけ。
  - `在る` の時は、あと次の 5 つだけ: `数値`(本当の大きさの 10 進の整数の字。千円の表の 1,234 は `1234000`。負は頭に `-`)・`単位`(定義表のとおり)・`期間`(時点なら鍵 `時点`、期間なら鍵 `始まり`・`終わり`。日の字)・`範囲`(`全社`)・`出どころ`。

  - `出どころ`(`素材の和` の行): `種類`(字 `素材の和`)・`file`・`列`(m)・`行の並び`(n の昇順の並び)・`列の見出し`・`表示の倍率`。

### 1-7 材料の検査(5 段目。答えを読まない)

読むのは `指定.json`・定義表・材料の束・素材の folder。材料ごとに「通す」「止める(規則の名の並び)」「無いを受ける」を返す。束の形が K0 に当たらなければ束ごと断る。

- 読み方の決め:
  - cell の数: xlsx の数の cell はそのまま。字の cell と CSV は、前後の空白と桁区切りの `,` を取り、`-`・`△`・`▲` が頭に付くか全体が `(` `)` で囲まれていれば負。残りが半角の数字だけなら数。ほかは数でない。
  - 見出しの正規化: NFKC → 空白(全角を含む)を全部取る → 頭の「`I`・`V`・`X` か数字の 1 つ以上の並び + `.`・`、`・`)` のどれか 0 か 1 つ」を、取った後に 1 字以上残る時だけ取る。
  - 行の見出し: 同じ行で、その cell より左の cell を右から左へ見て、最初の「空でなく、数でない」cell の字。列の見出し: 同じ列で、その cell より上の cell を下から上へ見て、最初の「空でなく、数でない」cell の字。無ければ空の字。
  - 表示の単位: その sheet(CSV は file)の中の「単位:円」「単位:千円」「単位:百万円」(`:` は全角でもよい。括弧は在ってもよい)の cell。0 個なら円・1 個ならその倍率・2 個以上なら読めない。
  - 期の読み(列か行の見出しの字 → 期): 正規化の後、「当期」「前期」「当期末」「前期末」は字のまま(期間の行なら 当期・前期、時点の行なら 当期末・前期末 として読む。「当期」を時点の行で読む時は当期末、「前期」は前期末)。「YYYY年M月期」は、その年月で終わる 12 か月(時点の行ならその月の末日)。「YYYY年M月末」はその月の末日。月は「M月」(当期の中のその月)・「YYYY年M月」・「YYYY/MM」。**これ以外の字は読めない**(「当期予算」「前年同月」は読めない)。
- 規則:
  - K0 形: §1-6 の鍵・値の形・id が頼まれた行とちょうど同じ・重複なし。当たらなければ束ごと断る。
  - K1 値: `位置` の cell が数で、cell の数 × `表示の倍率` = `数値`。`素材の和` は、`行の並び` の cell の和 × 倍率 = `数値`。
  - K2 見出しの申告: 申告した `行の見出し`・`列の見出し` が、素材から読み直した見出しと、正規化の後に一致。
  - K3 意味: `素材` の行は、行の見出しと列の見出しのうち**ちょうど一方**が、その id の `見出し` の表(正規化の後)に在る。`素材の和` の行は列の見出しが表に在る。
  - K4 期: `期の読み` が `要る` の行は、K3 で表に当たらなかった方の見出しが、指定の当期から出した「その行の期」と同じ期に読め、材料の `期間` もその期と同じ。`無し` の行は、材料の `期間` が指定から出した期と同じことだけを見る。K3 でどちらの見出しも表に当たらなかった行・両方が当たった行では、K4 の見出しの側は見ない(材料の `期間` と指定の期の一致だけを見る)。
  - K5 単位: `単位` が定義表と同じ。`円` の行は `表示の倍率` が素材から読んだ表示の単位と同じ。`円` でない行は倍率 1。
  - K6 和の行: `素材の和` の `行の並び` が、その列の cell が数で、1 列目の見出し(正規化の後)が「合計」「計」でない行の全部と、ちょうど同じ。
  - K7 関係: K1〜K6 を通った材料だけで、定義表の関係を見る。関係の両辺の材料が全部通っていて、等しくなければ、その関係の材料を全部止める。どれかが止まっているか無いなら、その関係は見ない(見なかった数を数える)。
  - K8 範囲: `範囲` が定義表と同じ。
  - K9 無い: `無い` と書いた行は、素材の全部の cell を見て、その id の `見出し` の表の字(正規化の後)と同じ cell が 1 つでも在れば止める(「無いと言ったが候補が在る」)。無ければ「無いを受ける」。
- **形だけの検査**(比べる相手): K0 だけを掛ける。変異の表で「何もしなかったら」の行として並べる。

### 1-8 計算で作る・置き場・B の計画(6 段目)

- 置き場(会社ごとの JSON): 通った材料・無いを受けた行・止まった行(状態 `確認待ち`)・計算の行(`在る`・`無い`・`保留`)。行ごとに出どころと、どの成果物の時に入ったか。
- 計算の行: 入力が全部 `在る`(通った)なら式で作る。入力に `無い` が在れば `無い`(理由 `入力の材料が無い`)。入力に `確認待ち`・`保留` が在れば `保留`。
- B の計画: 定義表 B の行を「置き場に在る(通った・無いを受けた・確認待ち)」「新しく要る(素材)」「計算で作る」に分ける。席には「新しく要る」行だけを頼む。**確認待ちの行を席に取り直させない。**
- 人が確かめて見出しの表に足す所(確認待ち → 通す)は、この便では作らない・やらない。

### 1-9 資料と資料の検査(7 段目)

- 資料は markdown。数は `<数の字><単位の字>[材料:<id>]` の形で書く(例: `1,234百万円[材料:a01]`・`12.3%[材料:a32]`・`4.5年[材料:a33]`・`45人[材料:a30]`)。`無い` の行は `無い[材料:<id>]`、`確認待ち`・`保留` の行は `確認待ち[材料:<id>]`。
- 資料の検査(置き場と定義表と資料だけを読む):
  - 定義表の行の全部が、札(`[材料:id]`)で 1 回以上出ている。定義表に無い id の札が無い。
  - `円` の行: 単位の字は `円`・`千円`・`百万円`。数の字(桁区切り可・負は `△` か `-`)は、置き場の値をその単位で割って整数へ四捨五入した値。`純数` の行: `%` で小数 1 桁、置き場の値 × 100 を小数 1 桁へ四捨五入。ただし b04 は `円` の行と同じ読み。`年` の行: 小数 1 桁。`人` の行: 整数。
  - 置き場で `在る` でない行に数が書いてあれば赤。`在る` の行に `無い`・`確認待ち` と書いてあれば赤。
  - 結ばれていない数: 札の付いた数の字と、日付の形(`YYYY年M月D日`・`YYYY年M月期`・`YYYY年M月`・`M月`・`YYYY/MM`・`YYYY-MM-DD`)と、見出しの頭の番号(行の頭の `#` の後ろ・行の頭の `1.` の形)を除いて、数字が 1 つでも残れば赤(残った数を数える)。
- A の資料は席が書く(置き場と定義表 A と指示書の資料の章を渡す。素材は渡さない)。B の資料は確かめる側が決まった型で組む(AI を使わない)。

### 1-10 変異

- **材料の変異**(正解の束から、材料 1 つにつき 1 か所): M1 数値に 1 を足す/M2 数値を 1000 倍にする/M3 表示の倍率を別の値にする(数値はそのまま)/M4 位置を同じ行の「もう一方の期の列」へ移し、数値と列の見出しもその cell に合わせる(期の読みが要る `素材` の行で、xlsx の行だけ)/M5 位置を 1 つ下の数の行へ移し、数値と行の見出しもその cell に合わせる/M6 期間をもう一方の期に書き換える(位置はそのまま)/M7 位置を 1 つ下の数の行へ移し数値もその cell に合わせるが、行の見出しの申告は元のまま/M8 `在る` を `無い` にする/M9 `無い` の行を `在る` にし、数値 `1000000`・位置は素材の空の cell・見出しは表の 1 つ目の字にする/M10 2 つの材料(id の昇順で隣どうし。値が違うもの)の `出どころ` と `数値` を入れ替える/M11 `素材の和` の `行の並び` から最後の 1 行を外し、数値もその和に合わせる。作れない組(その形が無い)は「作れなかった」に数える。
- **資料の変異**(資料の検査を通った資料から、札の付いた数 1 つにつき): D1 数字 1 つを別の数字に/D2 単位の字を別の単位に(`円` の行だけ)/D3 値の違う隣の札と札を入れ替える/D4 札を消す/D5 `無い`・`確認待ち` を `100円` に。
- 変異は全部、変異した後の file が元と違うことを見てから数える。

### 1-11 席

- 席はこの PC の Claude Code の subagent。**1 社・1 役につき 1 回。やり直しは無い。** 道具の故障で席が何も書かずに終わった時だけ 1 回だけ取り直し、その数を記録する。
- 材料を書く席に渡す folder: 指示書・定義表・指定・素材。資料を書く席に渡す folder: 指示書・定義表 A・置き場。席にはこの folder の外を読むなと指示する。司令塔は席の会話の記録で、folder の外の path への読み書き・この封・作る側の script・正解に触れた席を数え、触れた席の社は「汚れ」として別に数える(集計からは外さず、外した数も並べる)。
- 席の出力は、司令塔も実装者も直さない。形が壊れていれば壊れたまま検査に掛ける。

## §2 測る量と分母

本番だけの 12 社。素材の行(定義表 A の `素材`・`素材の和` の行)は 12 × 30 = 360。作りから、無い行 7(a30 が 4・a08 が 3)・表に無い言い方の行 24・残り 329。

- **段 A(席を使わない。正解の束)**: 検査の結果(通す・止める(規則ごと)・無いを受ける)。変異ごとの、作れた数・断ったか止めた数・通した数。形だけの検査が通した数。
- **段 B(席)**: 行ごとに、席の答えが正解どおりか(状態が同じ。在るなら数値と位置が同じ。`素材の和` は行の並びも同じ)× 検査の結果、の 4 つの枠と、無いの行・表に無い言い方の行の内訳。束が K0 で断られた社の数。「位置は正解と違うが、検査を通り、数値は正解と同じ」は別に数える。
- **段 C(資料)**: A の資料(席)・B の資料(型)が資料の検査を通った本数。結ばれていない数の数。資料の変異の、作れた数と通した数。B の新しい行(b01。12 行)の席の答え。B の計画の 3 つの枠の数(**作りから決まる数。予測にしない**)。
- **通し**: 1 段目から 7 段目まで、人の手の直しなしに走り、A・B の両方の資料が資料の検査を通った社の数。

## §4 読み方の決め(結果を見る前に)

- UM0-A1〜A3 は、作りから決まる所が多い。当たっても「検査が、司令塔の決めた罠を、司令塔の決めた規則で止めた」以上のことは言わない。**外れた時に価値が在る**(検査か素材の作りの欠陥)。
- UM0-B2 が外れたら(通した行に違う値が在ったら)、それがこの便の一番大きい負けで、結果の文書の頭に書く。0 でも「素材は作り物・罠は司令塔が決めたもの」の中の 0 と書く。
- 言えること(当たった時でも): 作り物の素材で、この PC の席が材料の束を書き、検査が素材の位置を読み直して確かめ、確かめた材料から資料 2 本が出る所までを 1 本で走らせた数。
- **言えないこと**: 「実物の会計の素材で動く」「会社の AI がこの型で書ける」「誤りが無くなる」「人の確かめが要らない」「開示の書類が作れる」「専用の道具が要らない」。席は 1 種類・1 回ずつで、ほかの AI では測っていない。

## §5 限界

- 素材は作り物で、形 3 つ・罠 9 つ(T1・T3・T4・T5・T7・T9・T10・T12 と負の書き方)は司令塔が決めた。検査の規則も同じ司令塔が決めた。**素材と検査が同じ前提を共有する**ので、ここに無い形の誤りは見えない。
- 見出しの表と「表の外」の言い方も同じ司令塔が決めた。表の外で止まる数(24)は作りから決まる数で、実物でどれだけ止まるかを言わない。
- `期の読み` が `無し` の行(a29・a30)は、素材がどの期のものかを検査が見ていない。
- 範囲は `全社` だけ。部門・連結と単体の別は作っていない。
- 人が確かめて表に足す所は作っていない。確認待ちは確認待ちのまま資料に出る。
- 資料の検査は、札の付いた数だけを置き場と比べる。札を付けずに字で書いた数(「約 3 割」など)は「結ばれていない数」で赤にするだけで、文の意味は見ない。
- 席はこの repo の文脈(`CLAUDE.md`・記憶の索引)を持つ subagent で、会社の AI エージェントそのものではない。

## §6 次の便の候補(この封で留める。結果の文書はここに無い候補を足さない)

- (i) 素材の形を、検査の規則を知らない別の席が決める版(素材と検査の前提の共有を外す)。
- (ii) 実物の素材(人間が用意した時)。
- (iii) 人が確かめて見出しの表に足す所と、2 期目の使い回し(確かめた見出しを次の期へ持ち越す)。
- (iv) 同じ材料の型から、開示の側(便 XJ0 の入力の型)へ写すつなぎ。便 XR0 の続き(経営指標の定義表)はここに入れる。
- (v) 札を付けない自由な文の資料の数を、置き場の材料に結ぶ(engine の結びを材料の型へ向ける。engine を変えるなら人間の決め)。
