## §1 手がかり(主語の要素の集合 S。engine の記録だけから取る。字で固定)

pointer の字は `xbrl:<prefix>:<LocalName>@<context>`。`xbrl:` で始まり `@` を含むものだけを要素として読み、`<prefix>:<LocalName>` を取る(`formula:a-b`・`builtin:sign(...)` などの導出の印は要素でないので捨てる)。context(期)は問わない。

| 手がかり | 取り方 |
|---|---|
| **A1** 自身の pointer | その claim の pointers の要素 |
| **A2** 同じ主語の字に engine が結んだ要素 | A1 が空で subject が null でないとき、entry の全 claim のうち subject の字が同じものの pointers の要素の和 |
| **A3** 隣の主張の pointer | entry の並びで前後 3 つ以内の kind num の claim で、文の窓が重なる(一方の 文 の先頭 12 字か末尾 12 字が他方の 文 に含まれる)ものの pointers の要素の和 |

S = A1 ∪ A2 ∪ A3。**S が空の行は「手がかりなし」で、判定しない(数だけ記録。全探索の判定を並べる)。**

## §2 近傍 N(S) と制約(字で固定。文を見て足さない)

- 計算リンク(`*_cal.xml` の calculationArc)で、N(S) = S ∪ S の親 ∪ S の子 ∪ S の兄弟(S の親の子)。深さ 1。計算リンクに出ない要素は自身だけ。
- 候補の作り方・v・G・帯・段・行の判定(候補 1 → 導出一致、2 以上 → 保留、0 → 不一致)は前の便の封 §2 と同じ。**候補を残す条件**だけを足す:

| 型 | 残す条件 |
|---|---|
| D1 単一 | fact の要素 ∈ N |
| D2 差・D3 増減率 | 要素(2 つは同じ name)∈ N |
| D4 合算 | 親 ∈ N、または子の全部 ∈ N |
| D5 比率 | 分子と分母の両方 ∈ N |
| D6 一株あたり | 金額の fact の要素 ∈ N(株数の fact は問わない) |

- **遷移**: 行ごとに(全探索の判定, 制約つきの判定)を記録し、3 × 3 の表に数える。「導出一致 → 不一致」は正しい候補を近傍の外に落とした疑いの行(札の根拠と照らして数だけ書く)。
- **根拠との照合(参考。判定には使わない)**: 導出一致の行で、候補の要素の local name が札の根拠の字に含まれるか(前の便と同じ字)。
