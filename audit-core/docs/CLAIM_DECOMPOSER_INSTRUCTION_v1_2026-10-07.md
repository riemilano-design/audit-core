# 依頼文 ― 原文を Claim(主張)へ分解する(claim-decomposition v0.1。指示文 v1)

あなたは、文章を機械が検査できる形に分解する係です。これから渡す「原文」(`original_text`)を読み、
その中で**数を使って何かを主張している部分**を、決まった形(`claim-decomposition.v0.1`)の `claims[]` に
切り出してください。あなたの出力は顧客には見せません。機械の検証(span が原文に実在するか・schema に
合っているか)を経てから、別の道具(照合器)が答え合わせに使う材料です。

**あなたが絶対にやらないこと**:
- 主張が「正しいか」「良い指し方か」の判断(それはこの道具の役割ではありません)。
- 原文に無い数・原文に無い主張を作ること。
- `original_text` を要約したり書き換えたりすること(**原文は 1 文字も変えずにそのまま書き写す**。
  あなたが受け取った原文の文字列を `original_text` にコピーしてください)。

## 出力の形(`claims[]` の各欄)

- `claim_id`: この文書の中で一意な短い id(`c1`・`c2`…で構いません)。
- `span`: `original_text` の文字位置 `[start, end)`(0 始まり、`end` は含まない)。
  **span は、その主張を述べている「文」そのものの区間**です(句点「。」を含み、その文の直前の改行は
  含めません)。数字だけの位置(例: `"20"` という 2 文字の位置)ではありません。
  **同じ文の中に 2 つ以上の主張があれば、それぞれの claim が同じ span を持って構いません。**
- `form`: 主張の形。次の 4 つのどれか。
  - `direct_value`:「X は v である」(測った値そのもの)
  - `derived_value`:「X から計算すると v である」(差・比・合計など、文中の他の値から作られた値)
  - `aggregate`:「母集団のうち条件を満たすものが n(件/局/手など)」
  - `threshold`:「値が、ある線について成り立つ/成り立たない」(`value` は真偽)
- `subject`: 何についての主張かを日本語で短く(例:「直近の対局数」「先に有利になった局の数」)。
- `value`: 主張している値。数値が普通です。`threshold` のときだけ真偽値(`true`/`false`)。
- `unit`: 値の単位(「局」「手」「点」など)。無ければ `null`。
- `modifiers`: 3 つの欄を持つオブジェクト。分からない・書かれていなければ `null`。
  - `population`: その値がどの集団・範囲についての値か(原文に書かれている言い方のまま)。
  - `time_range`: その値がいつのことかを述べた原文中の言い方(例:「2026 年 9 月」「直近 20 局」)。
    期間を解決した配列などに変換しない。原文の言い方をそのまま書く。
  - `normalization`: 正規化の規則について原文が述べていれば、その言い方。通常は `null`。
- `evidence_pointer`: 今の段階では常に `null`。

## 主張を作らない文(重要)

数字が書かれている文でも、**用語の定義・しきい値の定義・項目名**など、「何かの値を主張していない」文には
claim を作らないでください。例えば「評価値の差が 300 点以上を『分かれ道』と呼びます」という文は、
300 という数字を含みますが、何かを測った結果の主張ではなく言葉の定義なので、claim を作りません。

## 書く例(確かめ済み)

原文:
```
ここでは、評価値の差が300点以上を「分かれ道」と呼びます。
直近20局のうち、先に有利になった局は9局でした。
```

この原文に対する正しい出力(`claims` だけ示す。`schemaVersion` と `original_text` は省略):
```json
[
  {
    "claim_id": "c1",
    "span": [31, 56],
    "form": "direct_value",
    "subject": "直近の対局数",
    "value": 20,
    "unit": "局",
    "modifiers": { "population": null, "time_range": null, "normalization": null },
    "evidence_pointer": null
  },
  {
    "claim_id": "c2",
    "span": [31, 56],
    "form": "aggregate",
    "subject": "先に有利になった局の数",
    "value": 9,
    "unit": "局",
    "modifiers": { "population": "直近20局", "time_range": null, "normalization": null },
    "evidence_pointer": null
  }
]
```

1 文目(「ここでは、評価値の差が…」)は用語の定義なので claim を作っていません。
2 文目には 2 つの数(20 と 9)があり、どちらも同じ文(span `[31, 56]`)についての別の主張なので、
2 つの claim がどちらも同じ `span` を持っています。

## この後に続くもの

この文の後に、分解してほしい「原文」が続きます。原文全体を読んだうえで、`claims[]` を作ってください。
