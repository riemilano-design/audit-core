## 7. 限界

- 精度の物差しは「注入か」だけ。無改変の行の値が正しいこと(原文のまま)は前提で測っていない。
- **G1 に注入が 0 件。3 群の精度が 100 / 100 / 100 なのは標本が無いため**で、一致が信頼の印かどうかは段 1 の数では言えない。
- 席は sonnet の 1 回の答え(席 A)。席を替えれば表は変わる。書類は gen_c の 8 書類と cd8 の 8 書類(各 24 行 = 注入 8 + 無改変 16)。
- α 型は席の参照先に依る(席が参照先を出さない行には効かない。G1 では該当 0 行)。Core 自身の「対応なし」は行 ↔ claim の写像の限界を含む。
- Core 自身の GROUNDED は『Core が行の数の字面から claim を作り、値が合う fact を見つけた』であって、参照先が席の名指しと同じとは限らない。α 型との重なりは §2-4。
- G3 の VALUE_MISMATCH の読み(席の側か Core の側か)は人の読みで記録の外。
- cd8 の材料は P16 の記録の材料(材料の Core は P16 で作った値)。既定で当て直した Core 自身の値は本記録にだけ在る。

## 8. 迷った点(封の字で 1 通りに決まらなかった所。数を見る前に決めた読み)

1. **Q-2・Q-3a・Q-3b**: 封の本文に定義が無い(H-5 に『Q-2 精度の土台』の字だけ)。人間の指示の字から、Q-2 = 精度の土台(Core が注入を GROUNDED にしないか。H-5)、Q-3a = 止めた件数(H-6 と G3)、Q-3b = 一致の信頼(3 群の精度。H-1)と読んだ。

3. **H-1 の判定**: α 型だけでなく Core 自身の 3 群も 100 / 100 / 100 であることを当たりの条件にした(厳しい側)。
4. **H-3 の判定**: 幅の部分(記録の数)と読みの部分(VALUE_MISMATCH の過半が席の側。人の読み)の両方が合って当たり。過半は両集合の VALUE_MISMATCH を合わせて数えた。
5. **H-7 の判定**: 前半(P16 明示が材料の Core と全 384 行一致)と後半(GROUNDED の集合が同じ)を別に出し、封の『1 行でも違う』により後半で外れ。

7. **合成 H**: 席が確認済みの行の Core は α 型(全行に参照先が在る)、席が判定できない行の Core は Core 自身(その行に参照先が無い)。席が誤りが在るの行は Core を見ずに『誤り(席)』。
