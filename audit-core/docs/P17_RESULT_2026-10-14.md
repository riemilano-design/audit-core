P18 の副作用(16 書類で正しい文を 2 件止めるようになった): S100YMFV N066「自己資本比率は…52.5%」(fact から計算した値と 0.06 ポイント以上ずれる)、S100Z1WR N013「営業利益は 4,610 百万円(前年同期比 43.9% 増)」(同)。会社が表示の丸めた数から % を計算している文で、exact な fact からの計算と合わない。許容を緩める方向には直さない(計画 §7 の棄却条件)。

## 4. 正直に書く点

1. **訓練 2 書類の 79.7% は訓練の数**。P17 の規則はこの 2 書類の失敗を読んで作ったので、未使用の書類で同じ数が出る保証は無い。設計に使っていない S100Z4Q1 では +1(146 → 147)しか動いていない ― その書類にセグメントの文も「により」の文も少ないからで、「効かない」ではなく「測れていない」。**未使用の書類で測るまで、相手に 79.7% を言わない。**
2. A の 1 回目は 16 書類で GROUNDED を 71 件失った。予測(0〜3)を大きく外し、棄却条件どおり外した。A'(2 回目)は従来の段落内の引き継ぎを消していて 3 件失った(実装が計画の字より狭かった誤り)。A''(3 回目)で 0。**3 回目で当たったのは、2 回外れたからであって、最初から当てたのではない。**
3. 誤りを通す率の「0」は **% について**で、全体では 1/203。残る 1 件の型(書かれた最小の桁の中)は engine では消せない。
4. 誤りを通す率は 3 書類・2 種類の変え方で測ったもの。単位のずれ(千円 ↔ 百万円)・原文に無い数・値が偶然一致して参照先が違う型は、2026-10-08 の道具(`measure/inject.py`)の測定(30/30 検出)があるが P17/P18 では測り直していない。

5. **D(差を単一として読む 5 件)は、誤りを通す率を 0 に近づける方針と両立しない形で、今夜は入れない。** 診断: H-037・H-134 は差の形と読めている(「から 773,361 千円増加」)が、fact 同士の差 773,362 と 1 単位ずれて止まる。H-039・H-102・H-107 は「X の増加 N 千円」が差の印に無く(印は「増加額/減少額/比べて」と数の直後の「増加/減少」だけ)、単一として読む。印を足しても同じ 1 単位のずれで止まる。これを通す規則は「表示の丸めた値同士の差」も一致と認めることだが、それは **773,361 と 773,362 の両方を一致にする**= 差の主張では末尾 1 単位の誤りが見分けられなくなる(誤りを通す率が上がる側)。人間の「0 を目指す」に反するので入れない。消すには文を書く側に「差は exact な値から計算するか、桁を揃える」を求める(議事録デモの「根拠を添えさせる」設計と同じ向き)。
