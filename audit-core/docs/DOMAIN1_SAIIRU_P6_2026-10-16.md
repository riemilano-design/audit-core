## §2 **D-3 歯の測定 ― 段 10 で足りなかったのはここである**

段 10 の負の対照は **D-2 = 0 だったが歯が無かった。**
決算書の合計行の値が 20 会計すべて異なるため、**規則を 1 列に緩めても 0 件のまま**で、
「2 列を要求したことの価値」を示せなかった。

**今回は規則を 1 つずつ緩めて、誤った対が何件通るかを測った。**

| 緩めたもの | 誤った対の受理 | |
|---|---|---|
| **`MIN_INDEPENDENT` を 1 にする** | **324 / 324** | **全部通る** |
| **値の食い違いを無視する** | **286 / 324** | **通る** |
| 6d(一意性)を外す | **2 / 324** | **通る** |
| 6a(歳出側の値と一致)を外す | 0 / 324 | 通らない |
| 6b(代数的に決まる)を外す | 0 / 324 | 通らない |
| 全部緩める | **324 / 324** | **全部通る** |

**対照に歯が在る。**つまり **D-2 = 0 は「材料がたまたま衝突しない」からではなく、
規則が効いているからである。**

### §2-1 どの規則が何を守っているか(**混ぜて書かない**)

| 規則 | 守っているもの | 誤った対への効き |
|---|---|---|
| **`MIN_INDEPENDENT = 3`** | **同定の安全** | **1 本で足りることにすると 324/324 通る。いちばん効いている** |
| **値の完全一致** | **同定の安全** | **無視すると 286/324 通る** |
| 6d 一意性 | 同定の安全 | 外すと 2/324 通る |
| 6a 歳出側の値と一致 | **独立性**(同じ数の読み直しを数えない) | **0 件。誤った対には効かない** |
| 6b 代数的に決まる | **独立性** | **0 件。誤った対には効かない** |

**6a・6b は「安全」の規則ではなく「独立性」の規則である。**
誤った別名を止めているのは **閾値 3 と値の完全一致**であって、6a・6b ではない。
**この 2 つを安全の根拠として書いてはいけない。**
