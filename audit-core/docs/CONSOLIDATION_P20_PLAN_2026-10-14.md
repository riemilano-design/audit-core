### 1-1. 設計に直結する落とし穴(**自分で踏んだ**)

最初の判定は `jppfs_cor`(日本基準)だけを数えていた。すると **IFRS を使う会社(`jpigp_cor`)が「連結を作っていない」に見えた**。実際に `S100YYQX` を一度そう誤分類した。この会社は連結枠に 131 要素を持ち、一致 40% を出している。

**つまり素朴な「連結が無ければ単体へ落とす」を `jppfs_cor` だけで判定すると、IFRS の会社で単体へ誤って落ちる。** 人間が警告した「違う対象の数値を正しい根拠として扱う」が、まさにこの経路で起きる。

書類自身の DEI には連結の有無の宣言が**無かった**(欄は `NumberOfSubmissionDEI` だけ)。だから**宣言ではなく fact の在り方で判定する**しかない。

## 2. 規則(P20。**字で固定する**)

既定は P16 のまま。P20 は `PROFILES` に候補として足すだけ。

**書類レベルで 1 度だけ決める**(主張ごとに決めない。主張ごとに決めると、同じ書類の中で連結と単体が混ざる)。

```
財務の接頭辞 = ("jppfs_cor:", "jpigp_cor:")      ← **両方。日本基準と IFRS**
連結の枠     = CurrentYearInstant / CurrentYearDuration / Prior1YearInstant / Prior1YearDuration
               (member の付かない素の期間 context)

consolidated_elements = 財務の接頭辞を持つ fact のうち、連結の枠に在るものの要素の種類数

if consolidated_elements == 0:
    この書類は「連結財務諸表が無い」。単体(NonConsolidatedMember)の枠を連結の枠の代わりに使う。
else:
    この書類は「連結財務諸表が在る」。**単体へは落とさない**(1 要素でも落とさない)。
```

**3 つ目の場合(判断できない)の扱い**: `consolidated_elements` が 1 以上なら、たとえ少なくても**落とさない**。14 書類に中間の例は無かったが、**無かったことを「無い」と決めない**。少数の連結要素しか無い書類では、落とさない方が安全である(誤った根拠を返すのではなく止まる)。

**人間の 3 分類との対応**

| 人間の指示 | P20 の扱い |
|---|---|
| 連結決算が存在する会社: 連結を優先 | `consolidated_elements >= 1` で連結のみ。単体へ落とさない |
| 連結決算が存在しない会社: 単体を使える条件を明示 | `consolidated_elements == 0` のときだけ。条件は上の式そのもの |
| どちらか判断できない場合: 判定を保留 | `1 <= consolidated_elements` の少数例も落とさない = 止まる = 保留 |

## 3. 予測と合格線(**実装の前に封じる**)

測るのは**直し用 8 書類**(933 主張)。最終評価用の 8 書類は**開かない**(封 `431f436`)。

| 番 | 測るもの | 予測 | 合格線 |
|---|---|---|---|
| **C-1** | **連結が在る 6 書類で状態が変わった行の件数** | **0 件** | **0 件。1 件でも変わったら不合格** |
| C-2 | 連結が無い 2 書類(236 主張)で一致になった件数 | **94 〜 165 件(40〜70%)** | **71 件以上(30% 以上)** |
| C-3 | 連結が無い 2 書類で書類レベルの `UNVERIFIABLE` が外れるか | **2 件とも外れる** | 2 件とも外れる |
| C-4 | 8 書類全体の一致率 | 41.3% → **51 〜 59%** | 46% 以上 |

**C-1 がこの直しの本体である。** 検出件数(C-2)がいくら大きくても、C-1 が 0 でなければ**不合格**とする。人間の指示「検出件数を増やすより、違う対象の数値を正しい根拠として扱わないこと」をそのまま合格線にした。

**棄却条件(症状ではなく原因で書く)**

- **C-1 が 1 件以上**なら、切り替えが書類レベルになっていない(主張ごとに漏れている)。**許容を緩める方向には直さず、切り替えの置き場所を直す。**それでも 0 にならなければ **P20 を採用しない**と記録する。
- **IFRS の会社(`jpigp_cor` を持つ書類)が `consolidated_elements == 0` に分類されたら**、接頭辞の数え方が落ちている。**字で 2 つ並べた接頭辞を疑う。**
- C-2 が **30% 未満**なら、止まっている原因は連結・単体だけではない。**単体へ落としても結べない**ということなので、原因を 1 件ずつ読んでから次を決める(落とし込みを広げる方向には進めない)。
