### §0-2 司令塔の決定

1. **母集団は §1 の表の 201 本**(sha256 で留める)。足さない・引かない。切れない本も母集団に残し、「切れない」と数える。
2. **本は ZIP の sha256 と §1 の表の # だけで呼ぶ。** 会社名・証券コード・提出者の番号・docID(cache の file 名)・監査法人の名は、追跡する file(封・記録・結果・門・script)に書かない。記録は件数・state・位置・番号だけで、文・span・値・pointer の字・要素名を持たない。
3. **切り出しの規則**(実装者が 1 通りに書ける字で。連結と単体で札の名前だけが違う):
   - ZIP の member のうち、名前に `/AuditDoc/` を含み `.htm` で終わるものを名前の順に、utf-8(strict)で読む。読めない file が 1 つでも在れば「切れない(decode)」。
   - 各 file で、正規表現 `<ix:nonNumeric\b[^>]*\bname="<札の名前>"[^>]*>` の**最初の一致**を探す。札の名前は連結が `jpcrp_cor:KeyAuditMattersConsolidatedTextBlock`、単体が `jpcrp_cor:KeyAuditMattersNonConsolidatedTextBlock`(`name="…"` の完全一致。`DescriptionIncludingReasonKeyAuditMattersConsolidatedTextBlock` などの入れ子の札には当たらない)。
   - 一致の在る file が 0 = 「切れない(札なし)」、2 以上 = 「切れない(札が複数)」。一致した始まりの札の字に `continuedAt` が在れば「切れない(続きあり)」。
   - 終わり = 始まりの札の直後から、正規表現 `<ix:nonNumeric\b[^>]*?(/?)>|</ix:nonNumeric>` の一致を順に見て深さを数える(始まりの札で深さ 1。開く札(自分で閉じる `/>` を除く)で +1、`</ix:nonNumeric>` で −1)。深さが 0 になった一致の手前までが塊。0 にならなければ「切れない(閉じない)」。
   - 文 = 塊を `measure/xbrl_tanshin_2026-11-09.py` の `html_to_lines` で行にし、各行に NFKC を掛けて前後の空白を落とし、空の行を捨て、`\n` でつないだもの。空なら「切れない(空)」。
   - 当たる例: 連結の監査報告書の中の、見出し「監査上の主要な検討事項」からその区分の終わりまでを包む最も外の札。当たらない例: 塊の中の「内容及び決定理由」「監査上の対応」だけを包む入れ子の札・単体の監査報告書の札を連結の札の名前で探したとき・監査報告書の KAM 以外の区分(監査意見・その他の記載内容など)。
   - NFKC を掛けたことは記録に書く。
4. **判定**: `adapters/xbrl/verify_document.py` の `verify_document(元の ZIP の bytes, "P33E", text=文)`。ZIP は `measure/` の側では 1 byte も変えない(文の差し替えは engine の入口が memory の中でする)。数の claim = `claims` のうち `kind == "num"`。連結の文と単体の文は**別々に** 1 回ずつ渡す。**数は連結と単体を足さない**(単体は §0-1 の 7 の限界の上の数)。
5. **profile は P33E だけ**(README の推奨)。
6. **材料は cache の 3 つの folder を読むだけ。** 1 file も足さない・写さない(cache の一覧の sha256 が前後で同じ)。script は 3 つの folder の `.zip` の sha256 を数えて §1 の表の本を探す(file 名は使わない・記録に書かない)。201 本そろわなければ止める。ネットワークには出ない。
7. **読む行**(司令塔 = **AI の席**が読む。**人は読まない**。盲検でない。読むための紙(文・span・結んだ先・値)は repo の外(scratchpad)に置き、追跡しない):
   - **V 連結** = 連結の VALUE_MISMATCH の全部の行。**V 単体** = 単体の VALUE_MISMATCH の全部の行。
   - **G 単体** = 単体の GROUNDED の全部の行。
   - **G 連結** = 連結の GROUNDED の行を(§1 の表の # の順・文の番号の順・位置の順)に並べ、Python 3.9 の `random.Random(20261115).sample(range(行の数), 60)` で 60 行を引き、番号の順に並べたもの。行の数が 60 に満たなければ全部。
   - V の行に付ける型(1 行に 1 つ):
     - (ア) 一部分の数(セグメント・子会社・事業・資産のグループ・相手先・内訳)を、全体の fact と比べた
     - (イ) 見積り・仮定・将来の数・計画の数
     - (ウ) 連結と単体の取り違え(文の言う側と結んだ fact の側が違う)
     - (エ) 期の取り違え(文の言う期と結んだ fact の期が違う)
     - (オ) 定義の違い(同じ名前でも文の言う範囲が fact と違う。(ア)〜(エ) に入らないもの)
     - (カ) 丸め・単位
     - (キ) 損失・マイナスの符号
     - (ク) **本当の差の候補**(文がその項目・その側・その期の全体の数を言っていて、同じ有報の fact の値と違って見える)
     - (ケ) 読んでも分けられない
   - G の行に付ける型(1 行に 1 つ):
     - (a) 文の言う項目・範囲・側(連結 / 単体)・期が、結んだ fact と合う
     - (b) 値は同じだが、項目・範囲・側・期のどれかが結んだ fact と違う(違うものを 1 つ書く: 項目 / 範囲 / 側 / 期)
     - (c) 読んでも分けられない
   - (ク) は候補で、紙面で確かめるまで「食い違い」と呼ばない。会社も監査法人も名指さない。
8. **注入はこの便では測らない。** 行が少ない(GROUNDED は連結 136・単体 36)ので、注入の便を作るかは結果を見てから別の封で決める。
9. 0 USD。LLM の席(API)は呼ばない。外へは何も出さない。engine(`core/`・`adapters/`)は 0 行。
