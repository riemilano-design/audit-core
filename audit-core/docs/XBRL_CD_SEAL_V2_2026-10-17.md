# 封 v2 ― **主比較は A(LLM 単体)対 C′(LLM + Core)。差分だけを書く**

2026-10-17。人間の方針転換(2026-10-17)。**v1 を直さず、差分だけをここに書く。**
**継ぐ封**: [XBRL_CD_SEAL_2026-10-17.md](XBRL_CD_SEAL_2026-10-17.md)(**v1。1 文字も直していない**)。

> **今やるべきことは、LLM＋Core が LLM 単体より本当に優れているかを、
> 未使用データで確かめることです。**
>
> * **A(LLM 単体)対 C′(LLM＋Core)を主比較にする。**
> * **C′ は LLM の主張を上書きせず、Core の照合結果を追加する。**
> * **D′(値検索)は副比較にする。**
> * **停止判定と参照先の正しさは別々に評価する。**
> * **未使用 8 書類を使い、誤認定・見逃し・正しい参照先の特定・保留を比較する。**
>
> **費用上限の再設計は、今回の実験を始める前提条件から外します。**
> ただし、**実行環境や利用枠の制約まで無視するという意味ではありません。**
>
> **新しい指標を増やしたり、東京の別ドメインへ寄り道したりはしません。**

**この封は差分である。**v1 の §1(対象 8 書類と引く規則)・§2(材料)・§3(注入)・
§4-1(D′ の定義)・§4-2(D″)・§4-3(合成)・§5-2(正解の基準)・§5-3(層)・§6(対称性)・
§8(止める条件)・§10(示せないこと)は **そのまま効く。**

## §1 変える 5 つ(**これだけ**)

| 記号 | 変えること | v1 ではどうだったか |
|---|---|---|
| **Δ1** | **主比較は A 対 C′。D′・D″ は副比較。B(Core 単体)は参考** | v1 は主比較を字で決めていなかった(腕を 5 つ並べただけ) |
| **Δ2** | **C′ は席の申告を上書きせず、Core の照合を足すだけ** | v1 §4-3 のまま(**確認であって変更ではない**) |
| **Δ3** | **軸を 2 つに分ける**: **軸A 停止判定** / **軸B 参照先の正しさ** | v1 は軸3 を 1 つにし、「GROUNDED でなければ参照先を捨てる」読み方だと**正しく止めた Core が 0 点**になった |
| **Δ4** | **比べる数は 4 つだけ**: **誤認定・見逃し・正しい参照先の特定・保留** | v1 の §5 は 5 つ(検出・見落とし・保留・偽警報・種類)。**偽警報と種類は記録に残すが、主比較の判定には使わない** |
| **Δ5** | **席のモデルを字で記録する**(`model=sonnet` で呼び、**記録に出た ID をそのまま書く**)。**使ったトークンを必ず報告に載せる** | v1 は「sonnet 1 席」。**費用の上限は判定条件にしない**(人間の決定) |

**新しい指標は 1 つも足さない。**Δ3・Δ4 は**既にある数の読み方を決めるだけ**である。

### §1-1 **軸の定義(前便の字をそのまま使う)**

[XBRL_AXIS3_DECISION_2026-10-17.md](XBRL_AXIS3_DECISION_2026-10-17.md) §2-1 の字のまま。

| 軸 | 定義 | 分母 |
|---|---|---|
| **軸A 停止判定** | 誤りを入れた行で **「確認済み」と言わなかった**か | **対応が付いた注入の件数**(型ごとにも出す) |
| **軸B 参照先** | **`state` に関わらず**、名指した参照先が正解と**厳密一致**するか | **(a) 名指した件数** と **(b) T5 の件数** の**両方** |

**「止めた」ことを軸B の正解に数えない。**
**軸A × 軸B の表を必ず出す**(「止めたが参照先は誤り」を隠さないため)。
**対応が付かない行は軸A の分母から外し、件数を別に書く。**

### §1-2 **比べる 4 つの数(腕ごと。分母を必ず書く)**

| 数 | 定義 | 分母 |
|---|---|---|
| **誤認定** | 誤った参照先を「確認済み」として採った | **参照先を出した件数** |
| **見逃し** | 誤りを入れた行で「確認済み」と言った | **対応が付いた注入の件数** |
| **正しい参照先の特定** | 参照先が正解と厳密一致 | **T5 の件数**(と名指した件数の両方) |
| **保留** | 参照先を出さなかった | 注入した件数 |

**A・C′・D′・D″ の 4 腕に同じ関数を当てる。**
**主比較は A 対 C′ の 4 つの数の差**である。
