# 資料を作る席への頼み(便 UM3)

封: `docs/UNIVERSAL_PROCESS_SEAL_2026-11-24.md` §1-2。この紙の「1 期目」か「2 期目」の章と、folder 1 つだけを席に渡す。司令塔は、頼みの頭に「folder の path」と「どちらの章か」だけを足す。この紙のほかの文書(封・前の便の文書・記憶の file)は、席に渡さない・席は読まない。

## 共通

- 渡された folder の中だけを読み、その中にだけ書く。folder の外の file・この repo の file・記憶の file は開かない。python の標準 library は使ってよい。やり方は自由(どの file から見るか・script を書くか・どう確かめるかは、あなたが決める)。
- `指定.json` に、作る資料(成果物)と当期の始まり・終わりが在る。`definition_A.json` に、資料に要る項目(id・名・単位・期)が在る。`取り方` が `計算` の項目は、`式` と `入力` のとおりに計算する。
- 素材の folder は、架空の中小企業の経理の担当が、会計ソフトとその周りの道具から抜き出した file 一式。作り物。

## 出すもの(folder の直下に、この名で)

1. `資料.md` ― 銀行向けの説明資料(日本語。形は自由)。項目の数を使って書く。
2. `値の表.json` ― `{"行": [ {...}, ... ]}`。`definition_A.json` の全部の id について 1 行ずつ。1 行の欄:
   - `id`
   - `状態` ― `在る`(数を出した)・`無い`(素材からは出せないと判断した)・`分からない`(決められなかった)のどれか
   - `数値` ― `在る` の時だけ。本当の大きさ(円・人は整数の字。比や年は小数の字)。ほかは `null`
   - `出どころ` ― どの file のどこから、どう出したか(自分の言葉で短く)
   - `自信` ― `高`・`中`・`低` のどれか
3. `道具/` ― 作業で書いた script を残すなら、ここに置く(置かなくてもよい)。
4. `作業の記録.md` ― 全部が終わってから 1 回だけ書く。次の 6 つに、短く答える: (a) どの file を、どの順で見たか (b) どの file を数の出どころに選び、どれを選ばなかったか・その理由 (c) 迷った項目と、どう決めたか (d) 自分で確かめたこと(どの数とどの数を突き合わせたか) (e) やり直したこと・直したこと (f) 自信の無い項目と、その理由

## 1 期目

folder に在るもの: この紙・`指定.json`・`definition_A.json`・`素材/`(当期の決算が済んだ時の file 一式)。

## 2 期目

folder に在るもの: この紙・`指定.json`(1 年後の期)・`definition_A.json`・`素材/`(1 年後の file 一式)・`前の期の素材/`・`前の期の成果/`(1 年前に、別の人が同じ頼みで作った `資料.md`・`値の表.json`・`作業の記録.md`・`道具/`)。前の期の成果を使うか・どこまで信じるかは、あなたが決める。`作業の記録.md` には、上の 6 つに加えて (g) 前の期の成果のうち何を使い、何を使わなかったか・その理由 を書く。

終わったら、出した file の名だけを短く報告してください(数や中身は報告に書かない)。
