## 1. 手元に在るもの(調べた結果)

- 実物は repo の外の `~/.cache/audit-core/` に在る。有価証券報告書の zip(XBRL・iXBRL)が 4 か所で重なりを除き 324 社、決算短信の zip が 400 社分と 17 社分(17 社は有報と 1 対 1 で結んである)。
- 正解は機械で出せる。engine の `adapters/xbrl/instance.py` の `load_instance` で fact を読み、`vocabulary.py` の表で項目に結べる(売上高・営業利益・経常利益・当期純利益・減価償却費・現金及び預金・資産合計・負債合計・純資産・長期借入金・従業員数 など)。engine は読むだけで、変えない。
- **新しく取ってくるものは無い。** 通信も鍵も要らない。
- **月次の売上高・仕訳の実物は無い。** 公開データには、会社の中の細かい数が出てこない。

## 2. 通せるもの・通せないもの

| 部品 | 実物で通せるか |
|---|---|
| 保存の時の札(期・単位・性質・範囲)・印・種類・標準 | 通せる。連結と単体・当期と前期・百万円と千円が、実物の表に自然に在る |
| 貯めた行だけで埋める・作る時に聞く | 通せる |
| 文の中の数(従業員数など) | 通せる(有報の文) |
| 足し漏れの照合(S10′)・円の行で答え直す(SV15) | **通せない**(仕訳が無い) |
| 千円以上の表を止める照合(S11) | **このままでは使えない**。公開の数は正解そのものが百万円や千円に丸めてあるので、全部を止めてしまう。項目ごとに「どの位まで要るか」を持たせる直しが要る |

## 3. やり方の案(便 RD0)

- **素材:** 有報と決算短信が 1 対 1 で結んである 17 社から 6 社。1 社の folder に、決算短信と有報の表を CSV に直したもの(機械)と、有報の文の file を置く。前の年の表も入れる。決算書の形のまま置くので、仕訳の無い会社の folder になる。
- **正解:** その社の XBRL から機械で出す(連結・当期を正とし、単体と前期は「範囲」と「期」の取り違えとして数える)。
- **席:** 1 社に 4(保存・文・埋める・項目)。6 社で 24 席。素材を作る席は要らない。
- **照合:** S1〜S9・形 A。S10′ と S11 は当てない(上の訳)。
- **数えるもの:** 正しい行・資料に残る誤り・止めた正しい行・聞く項目。作り物の SV13 と並べる。
