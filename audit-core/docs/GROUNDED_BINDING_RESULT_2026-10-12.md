# 手順 ⑦ GROUNDED 側の束縛 ― 結果(2026-10-12、独立監査 GO)

人間の決定 `D-006` 追加 1:

> **B3(別 fact への束縛)は値が偶然一致すれば偽通過になるため、束縛の誤りが GROUNDED 側にも在るかを測る**

対象は再監査 B の **GROUNDED 60 件**(真と札付けされ engine が通した行。母集団は真×GROUNDED **177 件**)。
測るのは「値が合っているか」ではなく「**engine が結んだ pointer が文の指す項目を本当に指しているか**」。

## 1. 結果

| 判定 | 件数 |
|---|---|
| `correct` | 53 |
| **`wrong_binding`(誤った結び先)** | **5** ― `N219`・`N289`・`T023`・`T038`・`T086` |
| `ambiguous` | 1(`N249`) |
| `undecidable` | 1(`T020`) |

**5 件はすべて、盲検の再監査 B が「真」と札付けした行である**(司令塔が突き合わせた)。
つまり**主張は正しく、engine は別の fact に結んだまま値が合って通した** = **正しい主張を誤った根拠で通した。**

**狭義の偽通過(偽の主張を通す)ではない。** しかし**偽通過を生む機構そのもの**であり、これが初めて数になった。

| | 点推定 | 95% 区間 |
|---|---|---|
| 誤った結び先の率 | **5/60 = 8.3%** | [2.8%, 18.4%] |
| 真×GROUNDED 177 件中 | 15 件 | 5〜33 件 |
| **根拠まで正しい通過** | **162 / 391 = 41.5%** | 36.9%〜44.0% |
| (最悪 ― `ambiguous`・`undecidable` も誤りに数える 7/60) | 156 / 391 = 40.0% | 35.1%〜43.1% |

**通過 177/391 = 45.3% は「根拠まで正しい通過」ではない。** 正しくは **41.5%(36.9〜44.0%)**。
**この数は `S100Z4Q1` の 1 書類・60 件の標本から出たもので、文書別の集計は不成立。一般化しない。**

## 2. 独立監査(別個体。実装席の作業ファイルを見ていない)― **GO**

- `rows` 60 件・id が材料の `reaudit_B_strata.GROUNDED.ids` と差集合 0。`counts` を rows から再計算して一致。
- **engine を自分で回して 60 件すべてが `GROUNDED` であることを確認**(非 GROUNDED 0・`res` に無い id 0)。
  さらに **60 行全件の `engine_pointer` を自分の実行結果と突き合わせ、不一致 0 件**。

## 3. 5 件の中身

### `N219` ― **「同値 fact が 1 件しかない」という篩が効かない型**

文: 「有利子負債は 1 年内返済予定分 **234** 百万円と長期借入金 **275** 百万円の**合計 510 百万円**」。
engine は `LongTermLoansPayable@Prior1YearInstant` = **510,637,000**(**前期末の長期借入金単独**)に結んだ。
当期の 234,864,000 + 275,773,000 = **510,637,000** で **1 円まで一致**する。
**有利子負債合計の単一 fact は instance に存在しない。** 同値 fact は **1 件だけ**。
**科目も期も誤っているのに、偶然の一致が完全一致だった。**

### `N289` ― 直前の語彙語に引かれた(抽出段の誤りも併発)

文: 「関係会社株式の売却による収入 **9** 百万円」。
engine は直前の語「無形固定資産の取得による支出」の当期−前期の差 8,882,000 に結んだ。
正しい `ProceedsFromSalesOfStocksOfSubsidiariesAndAffiliatesInvCF@CurrentYearDuration` = 9,834,000 は
**instance に実在し同じ梯子(truncate)で一致するのに選ばれていない**(`claim.subject` 自体も誤抽出)。

### `T023`・`T038`・`T086` ― **「率・1 株当たり」の文を同名部分列の「額」に結ぶ 1 つの型**

| id | 文が述べている対象 | engine が結んだ先 |
|---|---|---|
| `T023` | 売上総利益**率** 32.5% → 29.8% | 売上総利益の**額**の差 −684,279,000 の符号 |
| `T038` | 売上高営業利益**率** 7.3% → 3.8% | 営業利益の**額**の差 −1,250,537,000 の符号 |
| `T086` | **1 株当たり**純資産額 2,096円83銭 → 1,897円74銭 | 部分一致した「純資産」**総額** 17,165,944,000 / 15,498,746,000 の符号 |

- `T023`・`T038`: **率の fact は instance に 0 件**(監査が `GrossProfitRatio` 等を検索して確認)。
  **正しい束縛は原理的に不可能**で、額が同方向だったため偶然通った。
- `T086`: **正しい `NetAssetsPerShareSummaryOfBusinessResults` は当期 2096.83・前期 1897.74 が実在する**のに使われていない。
- **方向だけの主張では同方向の要素対が 40〜45 件在るので、符号が通ったことは束縛の証拠にならない。**

## 4. `ambiguous` / `undecidable`(監査も「変更は要らない」と判定)

- `N249`(剰余金の配当 652 百万円): 同値 fact 7〜8 件。4 件は単体(`NonConsolidated`)で母集団の印で除けるが、
  残る連結内訳(`RetainedEarnings` / `ShareholdersEquity` member)は定義上同一額で、`CashDividendsPaidFinCF` も同じ事象。
  **単体 member も同値なので、連結を選べたことは選別規則の証拠にならない。**
- `T020`(「売上高の伸び率 2.9% を大きく上回る原価の伸び」): **2 つの伸び率の比較**で、単一科目の符号主張ではない。
  該当の比率 fact も無い。engine は売上高の当期−前期の符号で通した。

## 5. 取りこぼし(実装席の申告。監査が妥当と判定)

- **(a) 件数で篩うと `N219` 型を落とす** ― 同値 1 件でも誤束縛は起きる。
- (b) 文の読みは実装席 1 人 → **監査席が第 2 読者になり、5 件とも支持・`correct` 53 件に反例 0**。
- (c) 60 件すべて pointer の context は member 無し(連結)で、**単体 member への束縛は 0 件** ―
  **連結/単体の取り違えはこの標本では観測できていない**(`N249` のとおり同値の単体 fact は在る)。
- (d) `_match_value` の `abs` 分岐が偶然一致の余地を広げている 7 件(§2 で確認)。
- (e) 標準タクソノミの日本語ラベルが ZIP に無く(会社独自 15 件のみ)、要素の意味は英語要素名から読んだ。
