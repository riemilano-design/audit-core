## 6. 決めたこと(封に無い解釈。監査に回す)

1. 候補の数は形が真の行の全部に数え、決まったは engine が GROUNDED にしなかった行だけ。封 O-5 の「候補 0 の行」に engine が GROUNDED にした行(投資その他の資産)が入るため。別案は GROUNDED の行の候補を数えない形で、その場合 O-5 の候補 0 は幅の外になる。
2. N-6 の分母は決まった行の全部(E が取れない行は「指せず」= 同じでない)。実装の前に script の注に固定した。E の取れた行だけを分母にした割合は参考として並べた(表の N-6)。今回は分母 0。
3. `no_subject` の行に O が当たる(封 §2-2 の 1 の字どおり。`subj` を条件に入れていない)。97 書類で決まった 1 行は主語なしの行で、`subj` を条件にすると 0 行になる。AI の文は 7 のまま(7 行とも主語あり。配線の表)。**判断は監査に回す**。
4. 読む行は 1 行(決まった行が 1 だったため)。N-7・K-3 は分母 1 で判定した。
5. 旗の守りは dispatch と関数の頭の 2 か所に置いた。片方だけ外す変異は黙り、両方外すと赤になる(冗長)。
6. `LATER_HARNESS_FILES` への宣言は足していない。門 `test_xbrl_inject_harness_review.py` の規準(注入の仕掛け・副産物の検査)に新しい script 3 本が当たらず、宣言すると「古い宣言」で赤になるため(使い捨ての clone で確かめた)。docID を材料の名として持つ記録 3 つは `LATER_NAMING_FILES` に宣言した。
7. 既存の試験の遷移は封 §2-3 の型で足した。assertion を緩めた所は無い。

## 7. 走らせた回数と直し

- AI の文: 試し走り 1 回(scratchpad に出力)→ 本走り 1 回(記録の中に `(span, value, unit)` の字が入ったので鍵の文言を直して採り直し 1 回。結果は同じ)。

## 8. 限界・言えないこと

- 97 書類は提出年の偏った有報の標本である(P27 の封 §8 と同じ標本)。決まった行が 1 なので、決まった行の正しさ・偽の一致の率・近傍の要否は言えない。

- 読みは同じ model の 2 席で 1 行。独立した証拠ではない。
- 増減額の文に O を当てない規則、「その他流動資産」「その他有価証券評価差額金」などを拾う形の拡張は、この便の範囲の外。
