## 2. 範囲の同定(人間の指示 1。**結合の左上セルや列位置だけで対象を決めない**)

対象(行)の同定は、次の 3 つを**すべて**満たして初めて成立する。

1. **会計**: `事項別明細` の**目次シート**が持つ(シート名, 会計名)の対応表、
   または `決算書 歳出` の**ブロックの表題行**(「令和６年度東京都○○会計歳入歳出決算書」)。
   **全角と半角の正規化を掛ける**(目次は「（１）」、実際のシート名は `(1)`。
   **正規化を掛けたことを記録に書く**)。
2. **款・項・目**: **コードのセル**(列の位置)と**名前のセル**の**組**。
   コードだけ・名前だけ・列の位置だけでは同定としない。
   **2 つの様式がある**(どちらも実測):
   - `決算書 歳出`: **同じ行**にコードと名前(`A9`=`01`, `B9`=`議会費`)、**次の値行**に数。
   - `事項別明細`: **名前の行の次の行**にコードと数(`B8`=`議会費`, `A9`=`01` と数)。
3. **列**: 見出しの**結合範囲**の中にある数値の列。
   見出しの列と値の列は**同じとは限らない**(M-1 §4-7: 「差額」は `F7:G7`、値は `G9`)。

**符号は隣のセルに在る**(実測): `事項別明細` の負数は「`△`」が**別の列**に入り、
絶対値が次の列に入る(`F9`=`△`, `G9`=`104528000` → **−104,528,000**)。
**△ の列を見ずに値を読むと符号が逆になる。**

### 範囲の証拠(記録する欄)

同定ごとに次を全部記録する。**1 つでも欠けたら `GROUNDED` にしない。**

| 欄 | 中身 |
|---|---|
| `scope` | 会計名(と、どこから引いたか: 目次 / 表題行) |
| `code_ref` / `code` | コードのセル参照と値 |
| `name_ref` / `name` | 名前のセル参照と値 |
| `rows` | 合計に**含めた**行の一覧(セル参照) |
| `excluded_rows` | **除いた**行とその理由 |
| `column` | 列の見出しのセル参照と、値のセル参照 |
| `normalizations` | 掛けた正規化(全角半角・空白・ふりがな) |

## 3. 合計と内訳(人間の指示 2。**どの行を含め、どの行を除くかを明示する**)

- **含める**: 同じ親の直下の子だけ(款の下は項、項の下は目)。**孫は含めない。**
- **除く**: (a) 親自身の値行(**二重計上の防止**)、(b) 表題行・見出し行・単位行(「円」)、
  (c) 空行、(d) 合計行(「歳出合計」)、(e) `歳入歳出差引残額` の行。
  **除いた行は理由つきで記録する。**
- **比べるのは同じ列どうし**(予算現額は予算現額、支出済額は支出済額)。
  `事項別明細` の予算現額は**当初予算額・補正予算額・繰越・流用増減・計**に分かれるので、
  **`計` の列だけ**を `決算書` の `予算現額` と比べる。
- 一致の判定は**完全一致**(円単位の整数)。**帯は使わない。**
  一致しなかった件は**1 件ずつ読む**。帯を広げて合わせることはしない。

## 4. 根拠の分離(人間の指示 3)

記録は 2 つの欄に**分けて**持つ。

| 欄 | 中身 |
|---|---|
| `range_identified` | 範囲の証拠が §2 を満たしたか(真偽と、満たさない理由) |
| `value_match` | 合計が一致したか(真偽と、差) |

- **両方が真のときだけ `GROUNDED`。**
- `value_match` だけ真で `range_identified` が偽 → **`UNVERIFIABLE`**(偶然の一致を通さない)。
- `range_identified` だけ真で `value_match` が偽 → `VALUE_MISMATCH`。
- 範囲が同定できず値も合わない → `POINTER_NOT_FOUND`。
