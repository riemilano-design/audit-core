## §1 材料と決めごと(字で留める)

- **書類**: 便 XG0 の封 §1 と同じ 67 本(同じ並び)。**開発の 5 本**は並びの頭の 5 本。**本番だけの 62 本**は残りで、予測の分母。実装の席は、本番の前には開発の 5 本だけを開く。
- **対象の fact**: 包みの PublicDoc の `.htm` の中の `ix:nonFraction` の全部(便 XB0 の `strip_text` が返す表 F の `kind` が `nonFraction` の行。関数は呼ぶ・写さない・変えない)。`nonNumeric`・`footnote` は数えない(§7)。便 XB0 の `strip_text` が断った file の在る書類は「断った」に数え、分母から除く(数は書く)。
- **見る属性 7 つ**: `name`・`contextRef`・`unitRef`・`decimals`・`scale`・`sign`・`format`。属性が無いことは「無い」という 1 つの値として扱う。
- **空の fact**: `xsi:nil` が `true` の fact。空の fact は `name`・`contextRef`・`unitRef` の 3 つだけを見る。
- **fact の置き場**(元の `.htm` の字の上で決める。大文字と小文字を分けない):
  - その fact の開きタグの位置で開いている `table` のうち、いちばん内側のものを **その fact の表** とする。
  - その表に直に属する(その表より内側の表の中でない)開いている `tr` を **行**、その行の中の開いている `td` か `th` を **cell** とする。
  - 表・行・cell のどれかが無い fact は **表の外**。
  - **行の番号**: その表に直に属する `tr` の、開きタグの順の番号。
  - **列の番号**: その行の中で、その cell より前に在る `td`・`th` の `colspan`(無い・整数でない・1 未満は 1)の和。`rowspan` は見ない。
  - 閉じタグの欠けなどで上の決めが 1 通りに読めない file の在る書類は「断った」に数える。
- **表の向き**(表ごとに 2 通りを試す):
  - **向き A**: 要素の線 = 行・文脈の線 = 列。
  - **向き B**: 要素の線 = 列・文脈の線 = 行。
- **線の決め**(ある向きの下で):
  - 要素の線の `name` の決め = その線の上の fact の `name` の最頻の値。
  - 要素の線の `unitRef`・`decimals`・`scale` の決め = その線の上の fact の、それぞれの最頻の値(`unitRef` は空の fact も含めて・`decimals` と `scale` は空でない fact だけで)。
  - 文脈の線の `contextRef` の決め = その線の上の fact の `contextRef` の最頻の値。
  - 最頻が並んだときは、並んだ値のうち、書類の中で先に現れた fact の値。
- **表の決めで決まる fact**: ある向きの下で、`name` と `contextRef` と `unitRef` が線の決めと同じで、空でない fact は `decimals` と `scale` も線の決めと同じ fact。
- **表の向きの選び方**: 表の決めで決まる fact の数が多い向き。同じなら向き A。
- **符号の規則**(空でない fact): cell の開きタグの終わりから fact の開きタグの始まりまでの字(タグを除いた字)に `△`・`▲`・`-`・`－`・`−`・`‐` のどれかが在れば「負」と読む。**符号が合う** = 「負」と読んだことと、`sign` が `-` であることが一致する。
- **書式の規則**(空でない fact): fact の中の字(タグを除き、前後の空白を落とした字)を 3 つの類に分ける ― (1) `－`・`―`・`‐`・`-`・`—`・`−` だけ (2) 半角か全角の数字・`,`・`，`・`.`・`．` だけ (3) そのほか。**書式が合う** = `format` が、その書類の、同じ類の空でない fact の `format` の最頻の値と同じ。
- **全部決まる fact**: 表の中に在り、選んだ向きの下で表の決めで決まり、空でない fact は符号も書式も合う fact。
- **書く欄の数**(書類ごと): fact が 1 つ以上在る表ごとに、1(向き)+ fact の在る要素の線の数 × 4(`name`・`unitRef`・`decimals`・`scale`)+ fact の在る文脈の線の数 × 1。それに、書類で現れた書式の類の数、空の fact の数 × 1、表の中で全部決まらない fact の数 × 7、表の外の fact の数 × 7 を足す。
- **書く欄の比** = 書く欄の数 ÷(fact の数 × 7)。**何も決めなければ 100%**(fact ごとに 7 つ書く)。**表の中の fact が全部決まる場合の比**(= 全部決まらない fact の項を 0 に置いた比)も並べて書く。
