# 席への指示書: 素材から材料の束を書く(章 1)・置き場から資料を書く(章 2)

この指示書は 2 つの章から成る。**あなたに渡された役の章だけを読む。** 渡された folder の外は読まない・書かない(出力の file として指定された path だけ書いてよい)。
ほかの file(この repo の文書・script・別の folder)を探しに行かない。答えを推し量るための道具は使わない。やり直しは無い。1 回で書く。

---

## 章 1 材料を書く席

### 1-1 渡されるもの

渡された folder に、次の file が在る。

- この指示書
- `definition_A.json`(定義表。要る材料の一覧)
- `指定.json`(資料の指定。`成果物`・`当期の始まり`・`当期の終わり`の 3 つ)
- 素材の file: `決算.xlsx`・`月次売上.csv`・`借入金一覧.csv`・`人員.csv`(無い会社が在る)

定義表の `行` のうち、`取り方` が `素材` か `素材の和` の行が、あなたが書く材料の全部。`計算` の行は書かない(別の道具が作る)。
行ごとに `id`・`名`・`単位`・`期`・`範囲`・`見出し`(その行の素材に付く見出しの言い方の例)・`期の読み` が在る。

### 1-2 出力

JSON 1 つを、依頼文で指定された path に書く。ほかの file は書かない。頂の鍵は次の 2 つだけ。

- `型の版`: 字 `u0`
- `材料`: 並び。頼まれた行を、id の字の昇順に **1 回ずつ**(抜かさない・重ねない)。

### 1-3 材料 1 つの書き方

材料の鍵は `状態` によって決まる。

**素材が在るとき**(`状態` が `在る`)。鍵は次の 7 つだけ。

| 鍵 | 書くもの |
| --- | --- |
| `id` | 定義表の id |
| `状態` | `在る` |
| `数値` | 本当の大きさの 10 進の整数の字。半角の数字だけ。負は頭に `-`。桁区切りの `,`・先頭の `+`・先頭の余分な `0`・指数・小数点は書かない |
| `単位` | 定義表の `単位` と同じ字 |
| `期間` | 時点の行は `{"時点": "YYYY-MM-DD"}`。期間の行は `{"始まり": "YYYY-MM-DD", "終わり": "YYYY-MM-DD"}` |
| `範囲` | 定義表の `範囲` と同じ字 |
| `出どころ` | 下の 1-4 |

**素材が無いとき**(`状態` が `無い`)。鍵は `id`・`状態`・`無い理由` の 3 つだけ。`状態` は `無い`、`無い理由` は字 `素材が無い`。
渡された素材の全部の file を見て、その行に当たる数が 1 つも見つからないときだけ `無い` と書く。

**見出しが定義表の `見出し` の言い方と違っても、意味が合うと判断した行は、その素材の位置と見出しをそのまま書く。**
黙って別の行の数で埋めない。意味が合う素材が本当に無ければ `無い` と書く。

### 1-4 出どころ

**`素材` の行**(1 つの cell の数をそのまま取る行)。鍵は次の 6 つだけ。

- `種類`: 字 `素材`
- `file`: file の名(例 `決算.xlsx`)
- `位置`: xlsx なら `{"sheet": sheet の名, "セル": "C12"}`。CSV なら `{"行": n, "列": m}`(n・m は 1 から数える。CSV の頭の行が 1 行目)
- `行の見出し`: 数の cell と同じ行で、その cell より左にある、空でなく数でもない最初の cell の字。cell の字をそのまま写す(空白・番号が付いていても削らない)
- `列の見出し`: 数の cell と同じ列で、その cell より上にある、空でなく数でもない最初の cell の字。そのまま写す
- `表示の倍率`: 整数。下の 1-5

**`素材の和` の行**(1 つの列の明細の行を足す行)。鍵は次の 6 つだけ。

- `種類`: 字 `素材の和`
- `file`: CSV の file の名
- `列`: 足す列の番号(1 から)
- `行の並び`: 足す行の番号(1 から。昇順)。その列に数が入っている行のうち、小計・合計を表す行を除いた**明細の行の全部**
- `列の見出し`: 足す列の見出しの字(上の `列の見出し` と同じ読み方。足す行のいちばん上の行から上へ見る)
- `表示の倍率`: 整数

`数値` は、足した結果を本当の大きさにしたもの。

### 1-5 表示の倍率と数値

- 表の中の数が円でなく千円・百万円で書いてあることがある。sheet のどこかに `(単位:千円)`・`(単位:百万円)` のような cell が在れば、その sheet の数はその単位。無ければ円。
- `表示の倍率` は、円の行なら cell の単位の倍(円 → 1・千円 → 1000・百万円 → 1000000)。単位が `円` でない行(人数など)は 1。CSV は円。
- `数値` = cell に書いてある数 × `表示の倍率`。千円の表の 1,234 は `1234000`。
- cell の字の数は、前後の空白と桁区切りの `,` を取って読む。頭に `-`・`△`・`▲` が付くか、全体が `(` `)` で囲まれていれば負の数。

### 1-6 期間の書き方

`指定.json` の `当期の始まり`・`当期の終わり` から、定義表の `期` ごとに決まる。

- `当期`: 始まり = 当期の始まり、終わり = 当期の終わり
- `前期`: 当期の始まりの 12 か月前の日から、当期の始まりの前の日まで
- `当期末`: 時点 = 当期の終わり
- `前期末`: 時点 = 当期の始まりの前の日
- `当期の月:k`(k は 1〜12): 当期の始まりから k 番目の月の、初日から末日まで

### 1-7 実物の 1 行の例

次は、別の会社(開発用)の、売上高(当期)の材料 1 つ。形の見本であり、あなたの会社の答えではない。

```json
{"id": "a01", "状態": "在る", "数値": "7806051940", "単位": "円", "期間": {"始まり": "2025-01-01", "終わり": "2025-12-31"}, "範囲": "全社", "出どころ": {"種類": "素材", "file": "決算.xlsx", "位置": {"sheet": "試算表", "セル": "B3"}, "行の見出し": "Ⅰ 売上高", "列の見出し": "当期", "表示の倍率": 1}}
```

### 1-8 書き終えたら

指定された path に JSON 1 つだけが書かれていること(JSON として読めること)を確かめる。説明文・コードブロックの印・注釈は file に入れない。

## 章 2 資料を書く席

### 2-1 渡されるもの

渡された folder に、次の file が在る。

- この指示書
- `definition_A.json`(定義表。資料に出す行の一覧。`名`・`単位`・`取り方`)
- `store_A.json`(置き場。材料と計算の結果。**資料に出せる数はこの中の数だけ**)

素材の file(決算・CSV)は渡されない。見に行かない。

### 2-2 置き場の読み方

`store_A.json` の `行` は、id をキーにした辞書。行ごとの `状態` は次のどれか。

- `在る`: `値` に本当の大きさの数の字が在る(円の行なら円、`純数` の行は割合の小数、`年` の行は年、`人` の行は人)
- `無い`: 数が無い
- `確認待ち`・`保留`: まだ数を出せない

### 2-3 資料の書き方

出力は markdown 1 つ(依頼文で指定された path)。次の約束で書く。

- 定義表の `行` の**全部**を、1 回以上資料に出す。定義表に無い id は出さない。
- 数は `<数の字><単位の字>[材料:<id>]` の形で書く。数の後ろに、その数の元の行の id を付けた札を必ず付ける。例: `1,234百万円[材料:a01]`・`12.3%[材料:a32]`・`4.5年[材料:a33]`・`45人[材料:a30]`
  - `単位` が `円` の行: 単位の字は `円`・`千円`・`百万円` のどれか。数の字は、置き場の値をその単位で割って、整数へ四捨五入した値(桁区切りの `,` は付けてよい。負は頭に `-` か `△`)
  - `単位` が `純数` の行: 置き場の値を 100 倍し、小数 1 桁へ四捨五入して、`%` を付ける
  - `単位` が `年` の行: 小数 1 桁。字は `年`
  - `単位` が `人` の行: 整数。字は `人`
- 置き場で `無い` の行は `無い[材料:<id>]`、`確認待ち`・`保留` の行は `確認待ち[材料:<id>]` と書く。**この行に数を書かない。** 数を推し量って埋めない。
- 置き場で `在る` の行を `無い`・`確認待ち` と書かない。
- **置き場に無い数を書かない。** 置き場の数から自分で足した・割った・言い換えた数(「約 3 割」「前年より 1,000 百万円増」など)も書かない。
- **札の無い数字(0〜9)を書かない。** 文章の中に数字を書くときは必ず札を付ける。日付(`2025年12月31日`・`2025年12月期`・`3月`)と、見出しの頭の番号(`## 1 概況` の `1`・行頭の `1.`)だけは、札なしでよい。id の字(`a01` など)は札の中以外に書かない。
- 構成(見出し・順序・文の言い回し)は自由。読む人は銀行の担当者。

### 2-4 書き終えたら

指定された path に markdown だけが書かれていること(コードブロックの印で全体を囲まない)を確かめる。
