## §2 工程(3 つに分ける)と数えるもの

### §2-1 作る側(会社の代わり。今年の書類の答えを読む)

今年の書類 1 本につき、xlsx を 1 つ書く(openpyxl)。**xlsx に書く欄はここに挙げるものだけ。**

- シート「書類」: 当期の始まりの日・当期の終わりの日・提出の日(どれも日付のセル)。`M.analyze` の書類の決めから。
- シート「数」: 行の中の数の fact 1 つにつき 1 行。欄は 9 つ。
  1. 見出しの字(h)
  2. 表の番号(th)
  3. 行の字(T)
  4. 列の番号(td)
  5. 表の頭の印(G の決め)
  6. 金額: 空でない fact は **数のセル**(表示の数。負の印ありなら負)。表示の小数の桁の数はセルの表示形式(`0`・`0.0`・`0.00`…)に持たせる。空の fact は字「－」。
  7. 期の始まりの日(期間のときだけ。日付のセル)
  8. 期の終わりの日(時点のときはその日。日付のセル)
  9. 単位の字(下の表)
- 作り物の字での例(実物の行ではない): `売上の表の見出し | 2 | 売上高 | 3 | 前期当期 | 1234 | 2001-04-01 | 2002-03-31 | 百万円`。
- **単位の字の表**(単位の形 × 表示の位 → 字): 通貨:JPY × 0 → 「円」、× 3 → 「千円」、× 6 → 「百万円」。株 × 0 → 「株」、× 3 → 「千株」。純数 × 0 → 「数」、× −2 → 「％」。通貨:JPY÷株 × 0 → 「円/株」。空の fact は表示の位が無いので、単位の形だけから決める(通貨:JPY → 「円」、株 → 「株」、純数 → 「数」、通貨:JPY÷株 → 「円/株」)。受ける側は、金額が「－」の行では単位の字から単位の形だけを決める。**表に無い組は「書けない」**。
- **xlsx に書かない fact**(理由ごとに数える。分母 D に入れない): 突き合わせの外・行の字が空(T が空)・型の外(`M.analyze` の理由が 1 つでも在る)・単位が書けない・有効数字が 15 桁を超える。
- 作る側は、採点のための **答えの file**(fact ごとの、便 XM0 の型の行の欄 ― 種類・名・期の日・期の種類・個別か既定か・区分・値・単位の形・表示の位・精度・空か)を、xlsx とは別の folder に書く。受ける側には渡さない。
- 行の中でない数の fact・文の fact・隠しの fact は扱わない(数だけ数える。§7)。

### §2-2 受ける側(別の工程。今年の書類も答えの file も開かない)

入力は **今年の xlsx と、去年の書類(受理済みの zip)だけ**。関数の引数にも今年の zip の path・答えの folder を取らない。

- **去年の表**: 去年の書類を §1 の読み方で読み、鍵 (h, th, T, td) ごとに、T が空でなく型の外でない fact の、次の集まりを持つ。
  - 候補: (要素の名, 個別か既定か, 区分の並び)
  - 符号の向き(空でない fact だけ)
  - 期の名(`M.period_name`。去年の書類の決めで)
  - 単位の形(空でない・空の両方)
  - 表の頭の印
- **xlsx の 1 行ごとに**、次の順で決める。先に当たった止めで止める。
  1. 鍵が去年の表に無い → 止め「去年に無い行」。
  2. 候補が 2 つ以上 → 止め「候補が 2 つ以上」。
  3. 守り G: 表の頭の印が去年の集まりに無い → 止め「表の頭が違う」。
  4. 守り G1: xlsx の日付と「書類」のシートから作った期の名が、去年の期の名の集まりに無い(期の名が作れないときも)→ 止め「期が違う」。
  5. 守り G3: 候補の区分に番号つきの member(`MEMBER_RE` に合う。接頭辞を除いた名で見る)が在る → 止め「番号つき」。
  6. 守り G2: 単位の字から決めた単位の形が、去年の単位の形の集まりに無い → 止め「単位が違う」。
  7. 金額が数で、去年の符号の向きが 2 通り → 止め「符号の向きが 2 通り」。
  8. 止まらなければ **決める**: 名・個別か既定か・区分は候補。期の日と期の種類は xlsx の日付(1 つなら時点・2 つなら期間)。単位の形と表示の位は単位の字の表の逆引き。金額が「－」なら空。金額が数なら、精度 = −(表示の位) + (セルの表示形式の小数の桁の数)、値 = |金額| × 10^(表示の位) に符号(金額が負)XOR(去年の符号の向きが逆)。**去年の符号の向きが 1 つも無い(去年は空だった)ときは「順」とする。**
- 受ける側は、行ごとの決め(か止めの理由)を file に書く。

### §2-3 採点(受ける側の出力と答えの file を比べる)

fact ごとに次のどれか 1 つ。

- **決めて全部同じ**: 決めた欄の全部が答えと同じ。
- **決めたが違う**: 1 つでも違う。違った欄ごとの数(名・個別か既定か・区分・期の日・期の種類・値・単位の形・表示の位・精度・空か)と、「違うのは値だけで、絶対値は同じ」(符号だけ違う)の数、そのうち答えの値が符号つきの 0 のもの、去年が空で既定の「順」を使ったものの数。
- **止めた**: 理由ごとの数。候補が 1 つの止め(守り G・G1・G3・G2)は、**止めずに決めていたら全部同じだったか**(「正しかった止め」)も数える。

ほかに数えるもの(場面の数。予測は付けない):

- 今年の側: 負の印ありの fact・表示の数が 0 の fact・空の fact・符号の向きが逆の fact・去年の同じ鍵と表示の位が違う fact(とその結果の分け)。
- 去年の表の鍵のうち今年の xlsx に 1 行も無いもの(無くなった行)。
- 型の欄ごとの出どころ(作りから決まる。数えるのでなく表に書く): 会社が書いた欄からそのまま・規則で・去年から持ち越し。
- 書類ごとの、決めて全部同じ ÷ D と、決めたが違うの数。

## §7 限界

- xlsx は、**道具で作られ受理された書類から起こした**もの。会社の手元の原稿ではない。行の字・表の並び・列の番号は、出来上がった書類のもので、経理の人が同じ字・同じ並びで書くかは測らない。
- 鍵の欄(見出し・表の番号・列の番号・表の頭の印)は「去年の書類と同じ並びの表に入れる」ことを会社に求める。これは XBRL の知識ではないが、会社の負担であり、この便は負担を測らない。
- 単位の字は答えから表で作った字。会社が実際に書く単位の字(「人」「倍」「回」など)は見ていない。
- 期の日は答えの文脈の日をそのまま書いた。会社が期をどう書くかは見ていない。
- 去年の書類が在る会社の、続いた 2 年だけ。63 組(判定は 60 組)。有報だけ。
- 数の fact で行の中に在るものだけ。文の fact・隠しの fact・行の外の数の fact・行の字が空の fact は扱わない。
- XBRL の側を組んでいない。決めた型の行から XBRL が作れるかは便 XM0 の範囲(型も対応表も答えから作った)。
- 答えは提出された書類そのもので、提出された書類の誤りは見ていない。
