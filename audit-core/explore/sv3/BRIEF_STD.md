# 標準の席への頼み(便 SV3)

この紙と、folder 1 つ(ある会社の経理の file 一式)と、`紛れ.json`(保存の時に別の席が「後で取り違えやすい数」に付けた印)だけを渡す。司令塔は頼みの頭に「folder の path」「紛れ.json の path」「答えを書く path」を足す。ほかの紙・repo の中・folder の外は読まない。file は**読むだけ**(中の script は走らせない。読む時は `python3 -I`)。

## 頼むこと

印の付いた数は、後で誰かが使う時に人に確かめさせる。確かめる手間を減らしたい。

`紛れ.json` の印の 1 つずつについて、印の中の升のうち、**この会社の決算書の科目として使う時の標準の読み**に当たる升を挙げてください。何の資料に使うかは分かりません。

- 標準の読みに当たる升は、使う時に人に聞かずに通す。それ以外の升は人に聞く。
- 印の中のどの升が標準か決められない時(どちらの読みもありうる・人が決めるべき)は、空にする。**迷う時は空にする。**
- 印の外の升は挙げない。

## 形

`標準.json`:

```json
{"標準": [
  {"番号": 0, "標準の升": [{"行": 12, "列": 3}]},
  {"番号": 1, "標準の升": []}
]}
```

- `番号` は `紛れ.json` の `印` の並び順(0 から)。印の全部について 1 つずつ書く。
- `行`・`列` は 1 から数える(CSV の頭の行が 1 行目・左の列が 1 列目)。

終わったら、標準の升を挙げた印の数と、空にした印の数だけを短く報告する。
