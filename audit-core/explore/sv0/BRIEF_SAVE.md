# 保存の席への頼み(便 SV0)

この紙と、folder 1 つ(ある会社の経理の file 一式)だけを渡す。ほかの紙・repo の中・folder の外は読まない。folder の中の file は**読むだけ**(中の script は走らせない。python の標準 library で読むのはよい。その時は `python3 -I` で)。

## 頼むこと

この folder の file は、いま PC に保存されたところです。**何の資料に使うかはまだ分かりません。** あとで誰かが資料を作る時に使えるよう、file ごとに札を付けてください。札は folder の外の、司令塔が示す path に `札.json` として書く。

1. file ごとに `扱い` を決める。**数の表**(金額・人数などの数が升に並ぶ file)は `"貯める"`。それ以外は `"原本のまま"`。
2. `"貯める"` の file には、升の数が**いつの・どの単位の・どんな性質の・どの範囲の**数かを書く。file の中の字だけで決められない時は、同じ folder のほかの file(仕訳の日付など)から決めてよい。**それでも決められない時は推測で埋めず `null` にし、`人に聞く` に問いを 1 つ書く。**
3. 形:
   ```json
   {"file": [
     {"名": "file の名", "扱い": "貯める",
      "既定": {"期": P, "単位": U, "性質": Q, "範囲": R},
      "例外": [{"軸": "列", "番号": [3, 4], "期": P}, {"軸": "行", "番号": [2], "期": P, "範囲": R}],
      "人に聞く": ["問い"]},
     {"名": "file の名", "扱い": "原本のまま"}
   ]}
   ```
   - `P`(期): `{"種類": "期間", "始まり": "YYYY-MM-DD", "終わり": "YYYY-MM-DD"}` か `{"種類": "時点", "日": "YYYY-MM-DD"}` か `null`。
   - `U`(単位): `"円"`・`"千円"`・`"百万円"`・`"人"`・`"その他"`・`null`。
   - `Q`(性質): `"実績"`・`"予算・見込み"`・`"その他"`・`null`。
   - `R`(範囲): `"全社"`・`"一部"`(部門・店舗・1 つの相手先・1 本の契約 など)・`null`。
   - `例外` は、既定と違う列・行だけ書く。`番号` は 1 から数える(CSV の頭の行が 1 行目・左の列が 1 列目)。例外に書いた欄だけが既定を上書きする。読む側は、既定 → 列の例外 → 行の例外 の順に上書きする。
4. 終わったら、file の数・`貯める` の数・`人に聞く` の数だけを短く報告する(file の名・数値は報告に書かない)。
