# 素材を作る席への頼み(便 SV0)

この紙と、空の folder 1 つだけを席に渡す(ほかの紙・封・repo の中は読まない)。司令塔は、頼みの頭に「会社の番号・業種・決算月」と「folder の path」だけを足す。

## 頼むこと

あなたは、架空の中小企業 1 社の経理の担当です。架空の会計ソフトと、その周りの道具(給与・固定資産・借入・販売の管理など)から抜き出した file 一式を、渡された folder の中に作ってください。folder の外は読まない・書かない(python の標準 library は使ってよい)。

1. 実在の製品の名・実在の会社の名は使わない。
2. folder `期1/` を 1 つ作る。当期(Y1)の決算が済んだ時に担当が出せる file。前の期(Y0)の中身をどこまで入れるかは、下の 6 に合わせてあなたが決める。
3. 当期の仕訳の行を全部持つ file(仕訳帳)を必ず入れる。ほかに何を入れるか(試算表・決算書・月次の推移・固定資産の台帳・借入の返済予定・給与や人員の表・部門別・予算 など)と、列・見出し・科目の体系は、あなたが「実際にありそうな形」で決める。file の形式は CSV(文字コードは UTF-8 か CP932)。
4. **数は file の間で会計として合うように作る**(仕訳から足した額と、試算表・決算書の額が合う。貸借が合う)。
5. `正解/正解.json` を書く。鍵は `期1`。その下に、次の名の項目の値(本当の大きさ。円か人の整数)を入れる。当期は Y1。
   - `売上高_当期`・`売上高_前期`・`売上総利益_当期`・`営業利益_当期`・`営業利益_前期`・`経常利益_当期`・`当期純利益_当期`・`減価償却費_当期`
   - `現金及び預金_当期末`・`流動資産合計_当期末`・`資産合計_当期末`・`短期借入金_当期末`・`長期借入金_当期末`・`負債合計_当期末`・`純資産合計_当期末`・`純資産合計_前期末`
   - `月次の売上高_当期`(12 個の並び。期の初めの月から)・`借入の残高の合計_当期末`・`期末の従業員数_当期末`・`人件費_当期`
6. 上の項目のうち、**月次の売上高と人件費を除く 18 個**の中から 9 個を選び、次の 3 つの形を入れる。**9 個は全部別の項目**にする。実際の帳簿で起きそうな形にする。
   - **無い ×3**: 素材のどの file からも出せない項目。ほかの数を足し引きしても出せないようにする(例: 前の期の数がどの file にも無い・人員の表が無い)。`正解.json` の値は `null`。
   - **罠 ×4**: 正解の数のほかに、その項目と取り違えやすい別の数が素材のどこかの升に在る項目(例: 税込の額・予算や見込みの額・決算整理の前の額・一部の部門だけの額・1 つ前や後の時点の額・似た名の別の科目)。取り違えた時の数(罠の値)は、正解と違う整数で、その升にその整数の字で在ること(桁区切りの `,` は付いていてよい)。正解の数も、素材から出せること。
   - **決め ×2**: 項目の読みが 2 通り在り、どちらの読みの数も素材から出せて、2 つの値が違う項目(例: 借入の残高に役員からの借入を入れるか・従業員の数に役員やパートを入れるか)。`正解.json` には 1 つ目の読みの値を入れる。
7. `正解/罠.json` を書く。形:
   ```json
   {"無い": ["項目の名", "項目の名", "項目の名"],
    "罠": [{"項目": "項目の名", "罠の値": 整数, "file": "期1/ の下の file の名", "行": n, "列": m, "説明": "何と取り違えるか"}, ...4 つ],
    "決め": [{"項目": "項目の名", "読み": [{"値": 整数, "説明": "..."}, {"値": 整数, "説明": "..."}]}, ...2 つ]}
   ```
   `行`・`列` は 1 から数える(CSV の頭の行が 1 行目)。
8. `正解/期.json` を書く: `{"当期の始まり": "YYYY-MM-DD", "当期の終わり": "YYYY-MM-DD"}`。
9. `正解/メモ.md` に、file の一覧・入れた癖・項目の意味をどう決めたか・6 の 9 個をどう作ったか(無いの項目がなぜ出せないか・罠の升・決めの 2 つの読み)を書く。**`期1/` の file の中には、6 の形のことを書かない**(注記・file の名・列の名で種を明かさない)。
10. 素材を作る script は `作り方/` に置く。乱数の種を固定し、もう 1 回走らせると同じ file が出ること。

終わったら、作った file の数と、正解の値が素材と合うことを自分でどう確かめたかを、短く報告してください(項目の名・数・6 の中身は報告に書かない)。

## 足すこと(便 SV0)

11. `期1/` に、**決算の資料には使わなさそうな file を 4〜6 個**入れる(数の表でないもの。例: 連絡の文・議事の記録・名簿・手順の紙・備品の一覧。形式は txt か csv)。実際の経理の folder に混ざっていそうな形にする。どれがそれかを `正解/使わない.json` に、file の名の並びで書く。
