# 埋める席への頼み(便 SV0)

この紙と、folder 1 つ(ある会社の経理の file 一式)だけを渡す。司令塔は頼みの頭に「当期の始まりと終わりの日」と「答えを書く path」を足す。ほかの紙・repo の中・folder の外は読まない。folder の中の file は**読むだけ**(中の script は走らせない。読む時は `python3 -I`)。

## 頼むこと

下の項目の値を、folder の file から出してください。答えは `答え.json` に書く。

項目(値は本当の大きさ。円か人の整数):

- `売上高_当期`・`売上高_前期`・`売上総利益_当期`・`営業利益_当期`・`営業利益_前期`・`経常利益_当期`・`当期純利益_当期`・`減価償却費_当期`
- `現金及び預金_当期末`・`流動資産合計_当期末`・`資産合計_当期末`・`短期借入金_当期末`・`長期借入金_当期末`・`負債合計_当期末`・`純資産合計_当期末`・`純資産合計_前期末`
- `月次の売上高_当期_01` 〜 `月次の売上高_当期_12`(期の初めの月から)・`借入の残高の合計_当期末`・`期末の従業員数_当期末`・`人件費_当期`

形:

```json
{"行": [
  {"項目": "売上高_当期", "値": 123456789,
   "出どころ": [{"file": "file の名", "行": 10, "列": 2, "倍率": 1, "符号": 1}]},
  {"項目": "売上高_前期", "値": null, "出どころ": []}
]}
```

- `出どころ` は升の並び。値は「升の数 × 倍率 × 符号」の和と同じにする。1 つの升で出せる時は 1 つだけ書く。足し合わせが要る時だけ複数書く。
- `行`・`列` は 1 から数える(CSV の頭の行が 1 行目・左の列が 1 列目)。`倍率` は升が千円の表示なら 1000。
- folder のどの file からも出せない項目は、`値` を `null`、`出どころ` を空にする。**推測で埋めない。**
- 31 項目を全部書く。

終わったら、値を入れた項目の数と `null` の数だけを短く報告する。
