## 2. 照合(script が機械でやる。席ではない)

埋める席の 1 行を、次の全部を満たす時だけ **通す**。1 つでも欠ければ **止める**(理由は最初に当たった 1 つ)。`値` が `null` の行は照合せず「無いと答えた」に数える。

- S1 値: 出どころの升の数 × 倍率 × 符号 の和が `値` と同じ。升の数は、`,`・空白・`円` を除き、頭の `△`・`▲`・`-`、または `( )` の囲みを負と読む。数として読めない升・在りかの無い升は S1。
- S7 置き場: 出どころの file が札に在り、`扱い` が `貯める`。
- 升の札は、既定 → 列の例外 → 行の例外 の順に上書きして決める。出どころの升の全部について:
  - S2 期が無い: 札の `期` が `null`。
  - S3 期が違う: 項目の期と合わない。合うの決め:
    - `_当期` の項目(月次を除く): 期間で、始まり = 当期の始まり、終わり = 当期の終わり。出どころが 2 升以上の時は、どの升も「期間で、当期の始まり以上・当期の終わり以下に収まる」でもよい。
    - `月次の売上高_当期_NN`: 期間で、当期の NN 番目の月の初日から末日。
    - `_当期末` の項目: 時点で日 = 当期の終わり。または期間で終わり = 当期の終わり。
    - `_前期` の項目: 期間で、終わり = 当期の始まりの前の日。
    - `_前期末` の項目: 時点で日 = 当期の始まりの前の日 か 当期の始まり。または期間で終わり = 当期の始まりの前の日。
  - S4 単位: `期末の従業員数` は札が `人`。ほかは札が `円`・`千円`・`百万円` で、答えの倍率がその単位の倍率(1・1000・1000000)と同じ。
  - S5 性質: 札が `実績` でない。
  - S6 範囲: 出どころが 1 升の時だけ見る。札が `全社` でない。
- 判定の順は S1 → S7 → S2 → S3 → S4 → S5 → S6。

**何もしない時の行**(並べて書く): 値だけ見る照合(S1 だけ)。**完璧に動いた時の行**: 正解と同じ行を全部通し、違う行・壊した行・決めの行を全部止める。

## 3. 数えるもの

正解は素材を作った席の `正解.json`(月次は並びの順に 01〜12)。`罠.json`・`期.json`・`使わない.json` も使う。

- 自然の行: 値が正解と同じ行(「正しい行」)のうち、通した数・止めた数(理由ごと)。値が正解と違う行のうち、通した数(誤りの通過)。正解が `null` の項目に値を入れた行は「違う行」に数える。
