## 3. 読み

この節のうち「記録の外」と断った所は、script が数えた数ではなく、司令塔が札・罠の実物を 1 度見て書いた読み。

- **止めすぎは 0 だった。** 記録に在るのは「`貯める` の file で既定の期が無いものは 0」まで。UM2 の 92・UM4 の 84 は別の素材・別の検査の数なので、「84 が 0 になった」とは言えない。言えるのは「この 3 社では、保存の時の札で、正しい行を 1 つも止めずに照合できた」まで。
- **札が効いたのは、期の違いと実績でない数。** 列をずらした誤りは 45 のうち 44 を S3 で止めた(通した 1 の理由は記録に無い)。罠は 7 を止め、理由は S5 4・S3 2・S2 1。
- **札が効かなかった所(記録の外の読み)。** 通した罠 5・決めの行 6・自然の誤り 2 は、値だけ見る照合でも同じく通っていて、札は 1 つも足していない(ここまでは記録)。実物を見た限りでは、どれも同じ期・同じ単位・実績の中での「範囲の違い」(税込の額・一部だけの合計・足し合わせる科目の取り方 など)に見える。型分けとして数えてはいない。
- **保管先の分けは、この素材では回し違いが 0。** ただし使わない file は「数の表でないもの」として作らせたので、見分けやすい。数の表だが使わない file・文の中に要る数が在る file は試していない。
- **そろっていない所。** 埋める席への頼みは、2 社には当期の日付を字で渡し、1 社には仕訳の日付から決めさせた。

## 4. 言えないこと

- 埋める席は元の file を見て答えた。「貯めた行だけを見て資料を作れるか」は測っていない。
- 素材は作り物の 3 社。札そのものの正しさは採点していない(照合の結果を通してだけ見た)。
- 止めすぎ 0 は 1 回の席の走りの数で、席を替えた時の揺れは見ていない。
