## 0. 問い

1. 札の方式で、正しい数を「要修正・精査」にする言い過ぎ(TR3 で 27)は減るか。
2. 札で誤りを隠す形(本文の数を前期や別の項目の値に替え、札もそれに合わせる)を、期の字と項目の字の食い違いで機械が止める割合はいくつか。止まらない分は、確認済みの行の原文の抜粋に出るか。
3. 札の付かない数は、全部「点検していない数」に出るか。

## 1. 前提(この封の commit に含める。結果を見る前に固定)

- **評価の判定** [judge_tr4.py](judge_tr4.py): 資料の数が「正しい数」かを、拾った読みも札も受け取らずに決める。正しい数とは、材料のどれかの項目の値・増減額・増減率のどれかと、資料の桁で同じもの(四捨五入か切り捨て・符号は見ない)。人数は人数の値と同じもの。TR0-1・TR3-1 の欠陥(読みのまま材料と比べたので、読み違いが言い過ぎから漏れた)を直す。
- **数を全部拾う** [numbers_tr4.py](numbers_tr4.py): 規則はこの file の頭に書いた。表の増減・増減率の列、`+` の付いた数、`%` の付いた升、「(人)」の行を拾う。日付・年・「第 N 社」・見出しの番号は除く。原文の抜粋は数の前後 18 字。
- **札と本文の食い違い**(同じ file): 札が金額・人数の時は期の字、種類によらず項目の字。
  - 文の行は、前の数の終わりからこの数までの最後の字で見る。期の字は、比べる字(「〜比」)と、項目の字の中の字(「当期純利益」の「当期」)を除く。
  - 表の升は、期は列の見出しで、項目は行の見出しで見る。
  - 字が無ければ見ない。
- **単体試験** [test_tr4.py](test_tr4.py)(20 件): 判定は、TR0 の 23・TR3 の 27 の形を作り物の値で写した例を、全部「正しい数」とする。拾い方と食い違いの例も含む。**封の commit の時点で全部通る**(`python3 -I test_tr4.py`)。
- **試験が赤くなるかの確かめ** [mutate_tests_tr4.py](mutate_tests_tr4.py): 判定と拾い方を 1 か所ずつ壊す 11 の変異で、試験が **11 / 11 とも赤**になることを、封の commit の前に確かめた。読みと比べる形の判定(M3)も赤。表の % の升の枝は、ほかの規則と重なって壊しても赤にならなかったので消した(重なっていた枝で、動きは変わらない)。

## 3. 点検(`check_tr4.py`)

札 1 枚ごとに、次の順で決める。

1. 札の数を探す: 札の行の中で、機械が拾った数のうち、字(符号の `+` を除く)が同じものの、何番目。見つからなければ要修正・精査(札の数が資料に無い)。
2. 単位: 拾った数のすぐ後ろ(表なら列・行の見出しか表の上)の単位と、札の単位が違えば要修正・精査。本文に単位が無ければ札の単位を使う。
3. 符号: 本文の数に負の印(△▲−-)が在るのに、札の向きが `+` なら要修正・精査。
4. 食い違い: 期の字か項目の字が札と違えば要修正・精査(確認済みにしない)。
5. 照合: TR1 の `check_tr1.verify`(基準 A・engine の `verify_external`)。
   - 値の大きさは本文の数で決め、向きは札から取る。
   - 金額 → 金額 1 つ、増減額 → 増減額、増減率 → 増減率、人数 → 人数。
   - 保留は軽量確認、一致は確認済み、ほかは要修正・精査。基準 A に要素が無ければ点検していない。
6. 札の付かない数(機械が拾った数のうち、どの札にも当たらないもの)は、全部、点検していない数に出す。

点検レポート(顧客向け):
- 確認済みの行に、札(項目・期・種類)・資料の数・原文の抜粋・基準 A の一次ソースを並べる。
- 点検していない数に、場所と原文の抜粋を並べる。
- 「この点検の限界」に次の 2 つを足す。
  - 札と本文の食い違いは期の字と項目の字だけを機械で見る。
  - 文の意味は抜粋で人が見る。

誤りを入れた資料(機械。点検で確認済みになった札から、1 社 5 種・合わせて 55):
- (a) 本文の数の最後の桁を 2 変える(札はそのまま)。
- (b) 期の隠し: 当期・当期末の金額の札(文)の数を、基準 A の前期・前期末の値(資料の単位と桁)に替え、札の期も前期・前期末に替える。
- (c) 札を 1 枚外す。
- (d) 項目の隠し: 金額の札(文)の数を、同じ期の別の項目の基準 A の値に替え、札の項目も替える。
- (e) 単位の書き換え: 文の数の後ろの「百万円」と「千円」を入れ替える(札はそのまま)。

どれも、選べる札が無い社では入れない(入れた数を数える)。

## 4. 数える(`tally_tr4.py`。記録は数だけ)

- 札の数・見つからない札・区分ごとの数(確認済み・要修正・精査・軽量確認・点検していない)と、要修正・精査の訳ごとの数。
- 機械が拾った数のうち、札の付かない数(点検していない)。
- 言い過ぎ: 要修正・精査のうち、新しい判定で正しい数のもの。
- 確認済みの行・点検していない数の行で、原文の抜粋を欠くもの。
- 誤りを入れた資料:
  - 種類ごとの、入れた数と止めた数(確認済みにならなかった数)。
  - (b)・(d) は、機械が食い違いで止めた数と、確認済みのまま抜粋に出た数。
  - (c) は、外した札の数が点検していない数に出た数。
- 判定の回帰:
  - TR3 の要修正・精査 27 を、新しい判定が正しい数とする数。
  - TR0 の要確認 23 を、新しい判定が正しい数とする数(TR0 の材料で)。
- 拾い方の回帰: TR3 の資料で TR3 が拾わなかった字 11 のうち、新しい拾い方が拾う数。

## 6. 言えないこと

- 書く席と札を付ける席は同じ subagent。席が札で誤りを隠そうとする形は、機械で入れた (b)・(d) だけで見る。
- 食い違いの機械の見方は、期の字と項目の字だけ。文の意味は見ない。
- 判定の「正しい数」は、どれかの項目の値・増減額・増減率と同じなら正しい、とする。別の項目の値を誤って書いた数も正しい数に数えるので、言い過ぎを多めに数える側に寄る。
- 素材は実在の 11 社。資料の言い回しの幅は紙の 3 種類と席の選んだ言い方だけ。
