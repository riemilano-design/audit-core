## 3. 読み(結果の後に司令塔が見た。記録の外の読み)

- **生の XBRL を基準にすると、AI の取り出しの誤りを、資料がそのまま書き写していても止められた(62/62)。** 点検レポートは、その行に「資料の数は、XBRL の同じ要素の『前期』の数と同じ」と添え、取り違えの形まで指した。基準 B では、材料と資料が同じ誤りを持つので、金額の照合そのものは誤りを通した。
- **TR1-1 の B の外れ(23/62)は、B が誤りを見つけたからではない。** 入れた誤りの多くの形(当期の値を前期の読みに替える)で当期と前期が同額になり、engine の保留 P(同額の期間兄弟)が働いた。23 は全部、保留で要確認になったもの(金額 21・増減率 2)。点検レポートの字では「決めきれない」で、「誤り」とは言わない。誤りが当期と前期を同額にしない形なら、B は素通りさせたと読む。これは推測で、測っていない。
- **TR1-2・TR1-3 の外れは、拾い方の読み違いではなく、engine の保留から来た。**
  - TR0 で 23 あった拾い方の読み違い(「前期の X から Y 減少」の Y を当期の値と読む等)は、TR0 の資料を点検し直して 0 になった。要確認 52 は全部が保留。
  - 保留の元になった同額の兄弟(基準 A の新しい資料の保留 45 の行から数えた兄弟の延べ数)は、株主資本等変動計算書の列(利益剰余金・株主資本などの枠)60・単体の枠(連結と単体が同額)20・期間の兄弟 4・報告セグメントの枠 2。第 36 社は 1 社で 16 の保留を出した。
  - 基準 A では、照合の参照先を、人が決めた範囲と engine の表で機械が決める。それでも engine の保留の規則は「参照先が外から来て、どの枠か分からない」時のための規則なので、ここでは正しい数を「決めきれない」と言う。顧客向けのレポートでは、合っている数にも確かめる手間を出す。
- **入れた誤りのうち 3 は止まらなかった(1 桁の違い)。** engine は、元の XBRL の値との差が資料の 1 桁(百万円)未満の数を通す。止まらなかった 3 件は、1 桁を変えた数がその幅の中に入った誤りだった(監査の指摘で、測っていない説明を消してこの字にした)。
- **増減率の照合が初めて働いた(21)。** TR0 では 0 だった。
- 誤りの項目を参照せず保留でもない要確認 4 は、どれも「増減 0 百万円」の書き方。誤りを入れた項目で当期と前期が同額になり、書く席がそう書いた。「増減」の字は封の増減の字に無いので、前期の金額 1 つとして拾った。
- 書く席のうち 4 席(第 31・33・36・38 社)が、売上高などで当期と前期がまったく同じ値だと気づいて報告に書いたが、材料の値のまま書いた(紙のとおり)。(席の返事から司令塔が拾った。返事の file は残していない)

## 4. 言えないこと

- 基準 A は「提出された XBRL と合う」ことを見る。XBRL そのものが帳簿と合うかは見ない。
- 取り出しの誤りは機械で入れた形だけ。22 項目のうち 17 は同じ要素の前期の値(連結か単体)と、5 は当期の単体の値と、資料の桁で同じだった。千円の表を円と読んだ形は 1 回も入らなかった(どの社も別の読みが 2 つ在ったため)。
- 拾い方の直しは TR0 の 23 件を見てから決めた。TR1-3 は見た資料。
- 追記(2026-11-25・監査の指摘。封は変えない): script の拾い方は、封 §3 の足しのほかに次の 3 つも入れていた。どれも拾い方を広げる側。① 増減の向きの字に「改善」「悪化」も足した(封は「増」「減」「拡大」「縮小」)。②「損失が Y」も増減額として拾う(封は「損失額が」だけ)。③ 向きの字を探す幅を、数の後ろ 25 字にした(TR0 は 8 字)。
- 書く席・範囲を決めた席は subagent。顧客が読んで分かるかは測っていない。
- 保留の 45・52 が「本当に決めきれない」のか「正しい数なのに止めた」のかは、この便では分けていない。司令塔が見た限りでは、資料の数は XBRL の値と資料の桁で同じだった(言い過ぎの数え方で 45)。

## 5. 次の候補(封 §7 の中から)と、外にある 1 つ

封 §7: (i) TR2(XBRL でない経路の確定の台帳)。(ii) 項目と要素の対応を人の確定で足す仕組み。(iii) 点検レポートを読む席で測り直す。(iv) 本物の会計ソフトの書き出しを借りる(人間の決め)。(v) やめる。

**封 §7 の外(人間の決めが要る)**: 参照先を人が決めた写像で固めた時に、engine の保留(d・P)をどう扱うか。engine に触れる話なので、司令塔は決めない。触れずにできるのは、点検レポートで保留を「要確認」から分けて「数は合ったが、同じ額が別の枠にも在る」と書くこと。
