# 保存の席への頼み(便 SV7。4 枚をまとめて 1 席でやる)

この紙と、下の 4 枚の頼みの紙と、folder 1 つ(ある会社の経理の file 一式)だけを渡す。司令塔は頼みの頭に「folder の path」と「答えを書く folder」を足す。ほかの紙・repo の中・folder の外は読まない。folder の中の file は**読むだけ**(中の script は走らせない。読む時は `python3 -I`)。

この folder の file は、いま保存されたところです。何の資料に使うかはまだ分かりません。次の 4 つを、この順にやってください。どれも、それぞれの紙の字のとおりにします(紙に「渡す」「司令塔が足す」と書かれた所は、この紙が渡すものに読み替える)。

1. `BRIEF_SAVE.md` のとおりに `札.json` を書く。
2. `BRIEF_MARK.md` のとおりに `紛れ.json` を書く。
3. `BRIEF_KIND.md` のとおりに、2 の `紛れ.json` の印ごとに `種類.json` を書く。
4. `BRIEF_STD.md` のとおりに、2 の `紛れ.json` の印ごとに `標準.json` を書く。

4 つとも、答えを書く folder に置く。終わったら、file の数・`貯める` の数・印の数・種類 B の数・標準の升を挙げた印の数だけを短く報告する。
