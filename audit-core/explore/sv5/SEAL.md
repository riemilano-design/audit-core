## 0. 問い

SV0〜SV4 は、素材の席が作りやすい形の 3 社で測った。表の頭に題や単位だけの行が在る・千円の表・小計の行・数の表だが資料には使わない file・**要る数が文の中にだけ在る** file を足した素材でも、次の形は成り立つか。

1. 保存の時に札を付けて貯め、作る時は貯めた行だけを見る(SV0・SV1)。
2. 保存の時の印と種類と標準で、決めの行と罠を「人に確かめる」で止める(SV2〜SV4。照合は SV4 の形)。

## 2. 照合と集計

- 照合 S1〜S7 は SV0 の `tally.py`、S8 は SV4 の形(印の中で、種類が B か、種類 A で標準の升でない)。答えは「貯めた行だけを見て埋める席」のもの。M-ずらしは SV0 と同じ数え方で数えるが、予測は置かない。
- 「元の file を見て埋める席」の答えは、貯めた行だけの席と比べるためだけに使う(正しい行・違う行・正解が在るのに無いと答えた数)。
- 文の中の項目(`正解/文の中.json`)は、貯めた行には入らない(txt は数の表でないので原本のまま。ただし保存の席が `貯める` にした時は別に数える)。
