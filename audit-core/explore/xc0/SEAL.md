## 1. 問い

受理済みの有報について、**今年の XBRL(答え)を見ずに**、今年の素の本文と同じ会社の前の年の XBRL だけから、表の中の数の fact をどこまで置けるか。置いた fact は、要素・文脈・単位・桁・倍率・書式・符号・空の fact の全部が元と同じか。黙って違う fact はいくつか。

これまでの便との違い:
- 便 XB0・XT0・XP0・XS0・XH0 は、置き場・要素・文脈・単位・タクソノミを**今年の答えから写して**組んだ。
- 便 XZ0・XZ1 は前の年から属性を決めたが、**置き場(どの cell のどの字に fact を付けるか)は今年の答えのタグの位置から取った**。属性も name・contextRef・unitRef の 3 つだけを測った。
- この便は、置き場も属性も今年の答えを読まずに決め、属性は 7 つ全部と空の fact かを測る。

## 2. 作り(`xc0.py`)

材料: 便 XY0 の `make_pairs` の 63 組(今年の有報と、同じ提出者の 1 年前の有報)。zip は手元の cache(信頼しない data として読むだけ)。

今年の側から組む部品に渡すのは、今年の `.htm` から ix のタグを剥がした素の本文(便 XB0 の `strip_text`)だけ。今年の表 F(fact の場所と属性)・表 H(文脈と単位の定義)は採点でだけ読む。

1. 行と cell: 素の本文を engine の `_TR_RE` で行に、便 XH0 の `cells_of` で cell に切る。行の鍵 (h, th, T) は便 XZ0 の `read_rows` と同じ決め方(見出し h は便 XG1 の `file_rows`)。列の鍵 td は行の頭から cell の中身までの `<td`・`<th` の数。
2. 置き場の候補: 便 XH0 の `predict_cell`(数の並びがちょうど 1 つの cell に fact 1 つ・横棒だけの cell に空の fact)。
3. 前の年の表: 前の年の素の本文を同じ切り方で鍵にし、前の年の表 F の数の fact を鍵ごとに集める。表の頭の印(規則が数を置く最初の行より前の行の字。数字を除く)も鍵ごとに集める。
4. 置く: 置き場の候補ごとに、
   - 鍵が前の年の表に無い → **置かない**(人が書く側)。
   - 表の頭の印が前の年のどれとも違う → **止める**(便 XZ1 の守り G の考え方)。
   - 前の年の (name, contextRef, unitRef) が 2 つ以上 → **止める**。
   - 空の fact でなく、前の年の (decimals, scale, format) が 1 つに決まらない → **止める**。
   - そのほか → 前の年の属性で**置く**。符号は cell の中の数の前の字に △ などが在れば `-`(便 XA0 の `reads_negative`)。
   - 便 XZ1 の段 O(番号の振り直し)は使わない(XZ1-3 で新しい誤りを作ったため)。
5. 文脈と単位の定義: 前の年の表 H の定義の日付を 1 年後にずらす。
6. 組む: 置いた fact だけの表 F で、便 XB0 の `build_text` で `.htm` の字を組み、`strip_text` で剥がし直して、素の本文と置いた fact が戻るかを見る。

採点(今年の答えをここでだけ読む):
- 分母は今年の答えの `ix:nonFraction` の全部。表の外(文の中)の fact も分母に入れる。この便は表の外には置かない。
- 答えの fact ごとに、同じ置き場((start, end) が同じ)に置いた fact が在り、7 つの属性と空の fact かが全部同じなら**一致**、どれか違えば**黙って違う**。
- 同じ置き場を止めていれば**止めた**、どちらでもなければ**置かない**。答えに無い置き場に置いた fact は**余計に置いた**。
- 使った文脈・単位の id ごとに、ずらした定義が今年の答えの定義と同じか。メンバーの並びの順は問わない。
