# 材料の定義 ― 便 TR2(段 2。資料に載せる数の定め)

資料に載せる数は次の 15。値は円で決める(千円の表なら 1000 倍する)。

| 項目 | 期 | 足し方の定め |
|---|---|---|
| 売上高 | 当期・前期 | 損益の表の売上の行をすべて足す(製品・商品・役務など)。売上値引・返品の行が在れば引く。部門別の表の売上は使わない(二重になるため)。 |
| 営業利益 | 当期・前期 | 損益の表に営業利益(営業損失)の行が在ればその行。無ければ、売上高 − 売上原価の行 − 販売費及び一般管理費の行。 |
| 経常利益 | 当期 | 行が在ればその行。無ければ、営業利益 + 営業外収益の行 − 営業外費用の行。 |
| 当期純利益 | 当期 | 法人税等を引いた後の当期純利益の行。無ければ、経常利益 + 特別利益の行 − 特別損失の行 − 法人税等の行。 |
| 減価償却費 | 当期 | 減価償却費の行をすべて足す(販売費及び一般管理費の中のものと、製造原価の表の中のもの)。 |
| 現金及び預金 | 当期末 | 現金と預金(当座・普通・定期など)の行をすべて足す。小計の行が在ればその行でもよい。 |
| 流動資産合計 | 当期末 | 合計の行が在ればその行。 |
| 資産合計 | 当期末 | 合計の行が在ればその行。 |
| 短期借入金 | 当期末 | 短期借入金の行をすべて足す(銀行ごとに分かれていても)。**1 年以内返済予定の長期借入金は含めない。** |
| 長期借入金 | 当期末 | 固定負債の長期借入金の行をすべて足す。**1 年以内返済予定の長期借入金は含めない。** |
| 負債合計 | 当期末 | 合計の行が在ればその行。 |
| 純資産合計 | 当期末・前期末 | 合計の行が在ればその行。 |

期: 「当期」「前期」は損益の表の当期・前期の列。「当期末」「前期末」は貸借の表の当期末・前期末の列。
