# 表の文に札を付ける席への指示(便 XC11)

あなたは有価証券報告書の inline XBRL を作る席です。渡す画面(markdown の file)には、今年の報告書の表(役員の一覧・大株主の一覧など)と、前の年の同じ会社の表(升ごとに XBRL の文の札 = 要素と文脈)が並んでいます。今年の表の `〔★M番号〕` の印の升に、文の札を付けてください。

## 札の形

印ごとに 2 つを答えます。

- `name`: 要素の名。前の年の表の同じ列の札の要素を使う(例 役職名の列・氏名の列・略歴の列で要素が違う)。
- `contextRef`: 文脈の id。前の年の表で**同じ人・同じ行に当たる升の札の文脈**を使う(例 前の年に同じ氏名の人の行の文脈。役員の文脈には人ごとのメンバーが入っている)。大株主のような「何番目の行」の表は、前の年の同じ何番目の行の文脈を使う。

## 付けない時

次の升は札を付けず `null` と答えます。
- 前の年の表に同じ人(同じ行)が居ない升(新しく就いた役員など)。
- 前の年のその列に札が無い升・見出しや合計の升。
- 迷う升。**誤った札は、付けないより悪い。**

## 答えの出し方

指定された答えの file に、JSON だけを書いてください。印の全部を鍵にします。

```json
{"M1": {"name": "...", "contextRef": "..."}, "M2": null}
```

- 画面の file と、この指示の file 以外を読まないでください。repo の file・git・網には触らないでください。
- 答えの file 以外に何も書かないでください。報告には、札を付けた印の数と null の数だけを書いてください。会社の名・人の名・数の値を報告に書かないでください。
