# 封 ― 便 XC11: 表の中の軸のメンバーの付いた文の fact(役員ごと・大株主の行ごとなど)を、AI の席が置く(2026-11-26)

軽い型(CLAUDE.md 作法 7)。commit は 2 回(この封 → 結果)。監査は結果の前に 1 回。engine 0 行。`measure/` と便 XC0〜XC10 の file は 0 行(読み込んで関数を呼ぶだけ)。費用 0 USD(席は subagent)。人間の指示 2026-11-26「進めて」(便 XC10 の後の問い「役員ごとの項目を進めるか ― 人の名を席が読み書きする」への答え。人の名は scratchpad の画面と答えにだけ置き、記録・repo・commit の字には入れない)。

## 1. 問い

便 XC5 の文の fact の置き方は、軸のメンバーの付いた文脈の文の fact を置かない。作りの 6 組で置けなかった文の fact の約半分がそれで、658 のうち 620 は文脈が 1 年ずらした前の年の定義に在り(続けて居る役員・大株主の何番目の行など)、617 は表の升の中に在った。
これを、AI の席に前の年の札つきの表を見せて置かせると、どれだけ正しく埋まるか。

## 2. 作り(`xc11.py`)

- **画面**: 今年の表のうち、前の年の「軸のメンバーの付いた文の fact の在る表」と行の字・表の前の字の重なり(便 XC7 の `match_score`)が 2 以上の表。前の年の表で札の在る列の、字の在る・数だけでない・規則で置いた fact の入っていない升に `★M番号`。前の年の表は升ごとに要素と文脈を見せる。画面は約 6 万字ごとに分ける。
- **席への指示**: [BRIEF.md](BRIEF.md)。要素は前の年の同じ列の札・文脈は前の年の同じ人(同じ行)の札。新しい人・迷う升は null。
- **機械**: 文脈が 1 年ずらした前の年の定義に在る・要素がタクソノミ(便 XC8 の T1)か今年の提出者の xsd に在る物だけ。升の中の置き場は、前の年の同じ要素・文脈の fact が升の中で前と後ろに持っていたタグと字の塊の並びを今年の升に当てて決める(無ければ升の中の字の範囲)。S1: 前の年の升で fact の外に在った見える字を今年の置き場の端からも除く。置いた fact と交わる物は置かない。属性は前の年の同じ要素・文脈の fact の属性(文脈は席の答え)。
- **採点**(`tally11.py`): 置き場は前後の空白を除いて比べ、属性(`TEXT_ATTRS`)も同じなら「答えと同じ」。

## 3. 分けと開発の申告

- 組は便 XC7〜XC10 と同じ: 作り 1〜3、判定 25〜28。判定の組の画面はまだ作っていない。
- 作りの 3 組で席を 1 度回し(10 席)、その答えを見て機械の側を 3 度直した(席は回し直していない): 印を札の在る列・数だけでない升・重なり 2 以上に絞る(画面を作った時)・升の中の並びに字の塊を入れる・S1。
- 席のうち 1 つは、指示の「前の年の表の要素を使う」に従わず、続きの表の要素を自分の読みで選んだと報告した。2 つは答えを作るのに scratchpad に一時の script を書いて消したと報告した。
- 作りの 3 組の数(封の前に見た): 印 2239。席が置いた 313・答えと同じ 291・置き場が違う 22(全部、同じ要素・文脈の答えと置き場が重なる ― 升は合い升の中の範囲が違う)・属性が違う 0・形で落とした 0。席の誤りの割合 7.03%。答えの軸のメンバーの付いた文の fact 416 の覆い: 規則だけ 0% → 規則と席 69.95%。
