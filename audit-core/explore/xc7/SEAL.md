# 封 ― 便 XC7: 規則で置けなかった表の数の升に、AI の席(subagent)が札を付ける(2026-11-26)

## 1. 問い

便 XC0〜XC6 の規則は、表の数の fact のおよそ 2 割を置けない。置けなかった升を、AI の席に前の年の札つきの表を見せて札を付けさせると、**誤った札をほとんど足さずに**どれだけ埋まるか。

## 2. 作り(`xc7.py`。土台は便 XC6 の `place3_g`)

- **画面**(`build_screen`。今年の答えを読まない): 今年の表ごとに、規則で置いた升には付けた札を、置けなかった数の升には `★M番号` の印を付けて見せる。並べて、前の年の表のうち「行の字の重なり + 表の前の字(年の数字を除く)の似かた」が最も高い表を、升ごとの札つきで見せる。同じ高さの表が幾つも在れば、今年の何番目と前の年の何番目で組む。印は、札の在る列だけ・規則で置いた最初の行より下だけ・行の字の在る行だけ。画面は表の切れ目で約 6 万字ごとに分ける。
- **席への指示**: [BRIEF.md](BRIEF.md)(この封で固定)。札は 6 つ(要素・文脈・単位・桁・倍率・符号)か null。誤った札は付けないより悪い。注記の表で前の年に同じ意味の表が無い・提出者のコードの入ったメンバー(役員の名など)・迷う升は null。
- **席の回し方**: 画面 1 枚に席 1 つ(general-purpose の subagent)。席は指示の file と画面の file だけを読み、答えの JSON だけを書く。画面と答えは scratchpad(repo に入れない)。
- **機械の確かめ**(`check_tag`): 要素の前置きが標準か今年の提出者の xsd に在る・文脈と単位が 1 年ずらした前の年の定義に在る。通らない札は置かない(形で落とした)。
- **採点**(`score_answers`・`score7.py`・`tally7.py`): 今年の答えの数の fact の置き場(file・始まり・終わり)と、札の 6 つの属性が全部同じかを見る。記録は数だけ。

## 3. 分けと開発の申告

- 作りは訓練の 3 組(番号 1〜3)だけで見た。画面と指示は 4 度作り直した:
  1. 行の字だけで組む → 注記に本表の要素を付けた(組 1 で置いた 88 のうち 25 が答えと違うか答えが無い)。
  2. 表の前の字を足し、注記の表と軸のメンバーを null にする指示 → 誤り 0 だが、株主資本等変動計算書の標準のメンバーまで止めた。
  3. 同じ行の字の表の繰り返し(会社ごとの投資株式の表)を何番目で組む → 組 2 の要素の取り違え 14 が消えた。
  4. 止めるメンバーを提出者のコード入りの物だけにし、表の前の字の年の数字を除いて組む(この封の形)。

## 5. 言えないこと(先に書く)

- **席の札は道具 P に読ませていない。** 組んだ包みに席の札を入れて誤りの符号が鳴るかは、この便では測らない。
- 答えと「同じ」は、置き場と札の 6 つの属性が元の XBRL と同じこと。元と違っても正しい札(別の要素の選び方)は誤りに数える。
- 印の付かない升(規則で置いた最初の行より上・札の無い列・注記の数の多く)の答えの fact は、席に見せていない。覆いの残りの大半はそこ。
- 席は同じ型の subagent で、答えは回すたびに揺れうる(1 度しか回さない)。
- 文の fact・タクソノミ(持ち込み)・頭の部は便 XC6 のまま。便 XC0〜XC6 の限界を全部継ぐ。
