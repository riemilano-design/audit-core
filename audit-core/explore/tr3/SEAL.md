# 封 ― 便 TR3: TR1 の拾い方を、言い回しを変えた未見の資料で測り直す(2026-11-25)

軽い型(CLAUDE.md 作法 7)。commit は 2 回(この封 → 結果)。監査は結果の前に 1 回で、報告は `AUDIT.md`。engine 0 行・費用 0 USD・通信なし。数は外に出さない。人間は 2026-11-25 に「TR0 の資料で点検し直して 0 件になったのはインサンプルの再テストに過ぎない。表現を変えた未見の資料に対する再測定を必ず実行し、結果を監査ログに残せ」と指摘し、TR2 の後に「任せる進めて」と言った。

最終の仕組みの部品: 7 → 5 の点検の、資料の数を拾う所。TR1 の拾い方は、TR0 の資料の 23 件を見てから足した規則を含む。同じ紙で書かせた資料でしか測っていない。

## 0. 問い

拾い方(`explore/tr1/check_tr1.py` の `extract`。**この便では 1 字も変えない**)は、書き方の型を変えた未見の資料で、言い過ぎ(正しい数を「合わない」と言う)と、拾わない数をどれだけ出すか。

## 1. 材料と席

- 会社: TR1 と同じ 11 社(番号 31〜41)。基準は TR1 の基準 A(生の XBRL。`<TR1 の根>/A/{n}.json`)をそのまま使う。
- 材料: TR0 の材料(`<TR0 の根>/mat/{n}.json`。誤りを入れていない)。
- 書く席は 1 社 1 席(11 席)。紙は [BRIEF_WRITE_TR3.md](BRIEF_WRITE_TR3.md)。紙は、TR0 と TR1 の紙が書かせた文の型(「前期の X 百万円から Y 百万円(Z%)増加しました」)を使わせない。資料の種類と単位を、社ごとに次のとおり割り当てる。
  - 資料の種類:
    - 甲: 決算短信の経営成績等の概況(文が中心)。
    - 乙: 取締役会向けの業績の要約(箇条書きが中心)。
    - 丙: 金融機関向けの業績の説明(表に増減と増減率の列を持つ)。
  - 割り当て(社: 種類・単位): 31 甲・百万円、32 乙・千円、33 丙・百万円、34 甲・千円、35 乙・百万円、36 丙・千円、37 甲・百万円、38 乙・千円、39 丙・百万円、40 甲・千円、41 乙・百万円。
- 席には点検の規則を見せない。拾い方を見て書かせない。
- やり直しは「形が読めない」時と利用の上限で止まった時だけ。

## 2. 点検(`check_tr3.py`)

- 拾い方と照合は TR1 のまま(`check_tr1.extract`・`check_tr1.verify` を基準 A で)。区分は TR2 §6 の 2 段(要修正・精査 / 軽量確認)で数え、点検レポートも TR2 の `report_tr1_v2.report` の形で出す(repo の外)。
- 拾わなかった字: 資料の中の、数字の後ろ 3 字以内に「円・％・%・人・名・ポイント・pt」が続く字と、表の第 1 列以外の数だけの升。このうち、拾った数の始まりの位置と重ならないもの(見出しの行と、日付・年の字は除く)。

## 3. 数える(`tally_tr3.py`。記録は数だけ)

- 拾った数・区分ごとの数(確認済み・要修正・精査・軽量確認・人の判断が必要・点検していない)。
- 言い過ぎ: 要修正・精査のうち、資料の数が材料の値(と、そこからの増減額・増減率)と資料の桁で同じもの(TR1 の `tally_tr1.same_as_material` と同じ判定)。
- 書く席の誤りの候補: 要修正・精査のうち、言い過ぎでないもの(司令塔が 1 件ずつ見て、書く席の誤りか、拾い方の読み違いかを分け、結果の文書に書く。記録には数だけ)。
- 拾わなかった字の数と、数えた字の数。
- 比べ: TR1 の新しい資料(同じ紙で書いた 11 枚)の同じ数。

## 4. 事前予測(外れうる形)

| 番号 | 予測 | 外れの形 |
|---|---|---|
| TR3-1 | 言い過ぎは 11 枚で 5 以下 | 6 以上 |
| TR3-2 | 拾った数のうち点検していない数は 15% 以下 | 15% を超える |
| TR3-3 | 拾わなかった字は、数えた字の 10% 以下 | 10% を超える |
| TR3-4 | 言い過ぎの半分以上は、種類 乙・丙 の資料(箇条書き・増減の列のある表)から出る | 半分未満 |

外れ方: TR3-1 が外れたら、TR1 の拾い方の直しは TR0 の書き方に合わせたもので、ほかの書き方には広がらないと読む。TR3-3 が外れたら、拾い方は書き方によって黙って数を落とす(点検していない数にも入らない)と読む。

## 5. 言えないこと

- 書く席は subagent。書き方の幅は、紙が割り当てた 3 種類と 2 つの単位、と席の選ぶ言い回しの範囲だけ。
- 拾わなかった字の数え方は、この便の script の規則(単位の字が近くに在る数と、表の数の升)で、全部の数を見るものではない。
- 資料は材料から書くので、書く席の誤りが無ければ、要修正・精査は全部、言い過ぎか、engine の照合の作り(1 桁未満の差など)から来る。
