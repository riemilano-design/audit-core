## 3. 読み(結果の後に司令塔が見た。記録の外の読み)

- **封 §3 の言い過ぎの判定は、TR0-1 と同じ穴を持っていた。** 拾った読み(項目・期・種類)のまま材料と比べるので、読み違えた数は「材料と違う」になり、言い過ぎに入らず「書く席の誤りの候補」に落ちる。封は候補を司令塔が 1 件ずつ見ると決めていたので、27 件を資料の字と材料で見た。**書く席の誤りは 0、27 は全部が拾い方の読み違い**だった。
- **読み違いの形(27)**:
  - 増減額の新しい言い方を、当期の値と読んだ: 18。例: 「〜の増益」「〜の減少」「赤字幅が〜拡大・広がり」「〜積み上がり・積み増し・伸び」「増加額は〜」「増収幅は〜」「前事業年度末比で〜」「〜に比べ〜」。
  - 前期の値を当期の値と読んだ: 6。項目の字の**前**に「前期の」「前連結会計年度末の」「前事業年度末の」が在る形。拾い方は、項目の字から数までの間しか見ない。
  - 「借入金は短期 X、長期 Y」を、前に在る別の項目(現金及び預金)に結んだ: 2。
  - 表の行の見出しの「(人)」を見ず、表の単位(百万円)で読んだ: 1。
- **TR1 で直した「前期の X から Y 増加」の形は、この便の資料でも読めていた。** 増えた読み違いは、その形を使わない言い方から来た。TR1 の直しは、TR0 の書き方の型に合わせた直しで、ほかの言い方には広がらなかった。
- **点検していない数(31)の多くは、増減率の言い方。** 31 を拾った読みの形で分けると(監査の席が script で数えた)、% の付いた率で増減率と見分けられなかったもの 21(例: 「率にして Z%」「(Z% 増)」「増収率は Z%」「増加率は Z%」)、表の「増減」の列の金額で項目の期に結べなかったもの 7、その他 3。
- **拾わなかった字(11)は、全部が丙の表の「増減」「増減率」の列。** 「+」の付いた数・「%」の付いた升・「赤字幅 47.1% 拡大」の字は、表の升の数の形に当たらず、拾った数にも点検していない数にも入らなかった。**顧客から見ると、点検レポートに出てこない数**になる。
- 読み違いは、点検レポートでは「要修正・精査」として顧客に届く。正しい数に「直してください」と言う形の言い過ぎで、軽量確認とは違って手間が大きい。

## 4. 言えないこと

- 書く席は subagent で、言い回しの幅は紙の 3 種類と席の選んだ言い方だけ。本物の資料の言い回しはもっと広い。
- 読み違いの形の分け方は、司令塔が 27 件を見て決めた(script でなく記録の外)。
- 読み違えたのに、たまたま照合が一致して確認済みになった数があるかは見ていない(確認済み 172 の読みを 1 件ずつは見ていない)。
- 拾わなかった字の数え方は、単位の字が近い数と表の升だけ。単位の無い文の数(例: 「前期比 3 割増」)は数えていない。
