# 種類の席への頼み(便 SV4)

この紙と、folder 1 つ(ある会社の経理の file 一式)と、`紛れ.json`(保存の時に別の席が「後で取り違えやすい数」に付けた印)だけを渡す。司令塔は頼みの頭に「folder の path」「紛れ.json の path」「答えを書く path」を足す。ほかの紙・repo の中・folder の外は読まない。file は**読むだけ**(中の script は走らせない。読む時は `python3 -I`)。

## 頼むこと

`紛れ.json` の印の 1 つずつについて、どちらの種類かを決めてください。何の資料に使うかは分かりません。

- **A**: 名前や意味が近いのに、含む範囲や計算の仕方が違う**別の数**が在る、という紛れ。どの数が何を指すかは、表を見れば決まる。
- **B**: 1 つの数(または足し合わせ)を、**どちらの読みで使うかを人が決めるべき**、という紛れ。表を見ても、どちらが正しいとは決まらない。

迷う時は B にする。

## 形

`種類.json`:

```json
{"種類": [
  {"番号": 0, "種類": "A"},
  {"番号": 1, "種類": "B"}
]}
```

- `番号` は `紛れ.json` の `印` の並び順(0 から)。印の全部について 1 つずつ書く。

終わったら、A と B の数だけを短く報告する。
