## 3. 読み(結果の後に司令塔が見た。記録の外の読み)

- **TR6-3・TR6-4 の外れは、正解の作り方の見落とし。** 単位の変更は、TR2 の build で、円の社(51・53・55)の表を千円にして升の値を千円に丸めている。正解は期 2 の円の値のまま。千円に丸めた file から円の値は、どの台帳でも読めない。封を書く時にこれを見落とした。補足(`extra_tr6.py`。封 §4 に無い)で、違った値が file の丸め(成分 1 つにつき 500 円以内)で説明できるかを数えた: 案だけ・席の後とも、3 つの止めの違う値 24 / 24 が丸めの内。意味の変わる改名の案だけの違い 5 は、丸めの内が 0 / 5(本当の誤り)。だから、外れの 3 は台帳の読み違いでなく、正解の桁の問題と読む。判定は外れのまま。
- **縮めた差分は、どの変異も 1 行になった。** TR2 の形は、科目の追加で、足した行より下の行が 1 つずつずれて全部「変わった」と並んだ(1 社 15〜16 行)。並びの差で取ると「行の追加 1」になる。行の並べ替えも、TR2 の形の 2 行(入れ替わった 2 つ)が「順の変更 1」になった。
- **案だけを当てると、意味の変わる改名は 6 のうち 5 で黙って違う値を読んだ。** 「投資信託」を「定期預金」(か「普通預金」)と同じものとして読み、現金及び預金に投資信託が入った。字が変わった所を機械が「同じもの」とみなして読むと、意味の変わった字を通す。だから案は人が確かめるまで当てない、という作りの要る訳になる。第 54 社は預金の小計の行で読むので、案でも正しかった。
- **席は、案のある 42 のうち、意味の変わる改名の 6 だけを変え、ほかの 36 は案のままにした。** 足した行 12 は全部、定義どおり(短期借入金(F銀行)は短期借入金に足す・リース債務は使わない)に決めた。第 54 社の改名の行は台帳で使わない行だったので、案のままでも「使わない」でも値は同じ。
- **席の気づき(6 席の報告から)**: 画面の作りの穴が 3 つ挙がった。
  - 前後の行に列の見出しが無く、どの列が当期末か分からない(足した行の値が 0 か額か)。
  - 足した行の「影響する項目」が「なし」と出て紛らわしい(案の無い所なので影響はまだ決まっていない)。
  - シートの名の変更で、元の名のシートが file に残っていないかが画面から分からない。機械は知っている。
  - ほかに、単位の変更で前後の行(生の数)が出ないので、桁を確かめられないという声が 4 席から在った。第 53 社の席は、千円の表なので千円未満が丸められていると書いた(丸めに気づいた席は 1)。
  - 意味の変わる改名で、元の行が file の別の所に残っていないか画面から分からない(3 席)。列の追加で前後の行が出ない(1 席)。
  - どれも、この便の結果を変えてはいない。ただし本物の人には要る情報。

## 4. 言えないこと

- 素材は作り物で、変異は 1 つの file に 1 種だけ。本物では複数の変化が重なり、並びの差の対の作り方(置き換えの 1 対 1)が外れうる。
- 確定し直しは人の代わりの席(subagent)。案を疑う形は 2 種だけ。意味の変わる改名は、第 54 社では案でも値が正しいので、席が見抜いたかが値に出るのは 5 / 6(5 とも正しかった)。紙の行の字の変更の説明に「別の科目になったので使わない」という選び方が書いてあり、改名を疑う手がかりになりえた。単位の変更は、同じ社の 9 画面を 1 席が見たので、画面をまたいだ桁の照合が効いた(3 席がそう書いた)。本物の人が 1 枚ずつ見る時の力は測っていない。もっと紛らわしい改名(定義の境目の科目)は測っていない。
- 同じ字の行が 2 つ以上在る所の変化は試していない。
- 単位の変更の 3 は、円の正解を読めない作り(§3)。千円の桁で合っていることは補足で確かめたが、封の数え方では外れ。
