## 3. 読み(結果の後に司令塔が見た。記録の外の読み)

- **TR5-2 の外れは、規則の穴でなく誤りの入れ方の欠陥。** `check_tr5.mutate_all` の (b) は、替えた札の「何番目」を 1 に固めていた。表の行では、当期の欄の数を前期の値に替えると、同じ字の数が同じ行の前期の欄にも在る。札の「何番目 1」は前期の欄の数を指し、前期の欄の期の字は前期なので食い違いが無く、確認済みになった。補足(`extra_b_tr5.py`。封 §3 に無い)で表の形を数え直した:
  - 替えた当期の欄の数は、札の付かない数として「点検していない」に出た: 新しい資料 10 / 10・TR4 の資料 12 / 12。人が「点検していない」を見れば、そこに誤りが在ることは分かる形。
  - 「何番目」を替えた位置に合わせて入れ直すと、期の字の食い違いで止まった: 新しい資料 10 / 10・TR4 の資料 12 / 12。
  - 同じ欠陥は文でも起きうる(替えた数が同じ文の前期の数と同額の時)が、文ではその形を R1 が止めた(新しい資料 8)。TR4 の (b) も同じ作り方で、TR4 の (b) の数にもこの欠陥が入っている可能性が在る(TR4 では 7 が文。表の数は数えていない)。
- **文の期の隠しは 30 / 30 止まった。** TR4 で止まらなかった「数の前に期の字が無い」形は、R2(6)と R1(8)が止めた。
- **項目の隠しを止めた 88 の内訳は、項目の字の食い違い(TR4 からの規則)77・R1 10・engine の照合 1**(監査が出力から数えた。TR4 の資料では R1 7、食い違いだけなら 75 / 93)。R1 は期の隠しのために足した規則で、項目の隠しも止めた。
- **項目の隠しの止まらなかった 16 は、どれも数の近くに項目の字が無い形**(補足で数えた: 16 / 16。TR4 の資料も 11 / 11)。形の内訳は数えていない。この形を止める規則は、この便では足していない。
- **言い過ぎ 1** は、「当期末の純資産は、当期純損失の計上により前期末比 X 千円減」の増減額。数の前の一番近い項目の字が「当期純損失」で、札の項目(純資産合計)と食い違うとして止めた。ふつうの書き方で起きる止めすぎの形。
- **点検していない 7** は、基準 A に売上高の要素の無い第 31 社の売上高(TR4 の資料の点検していない 4 と同じ訳。数は資料に書いた売上高の数の数で違う)。札の付かない数は 0。
- **漏れ: 書く席は R1・R2 の中身を見ていた。** 封の commit message(直近の commit)に R1・R2 の字が在り、書く席 11 の全部の文脈に入っていた(席の出力の file を機械で数えた: 11 / 11)。席のうち少なくとも 1 は「前期の売上高の前が『前連結会計年度』になっていたので『前期の』に書き直した」と報告した。だから **新しい資料での R1・R2 の止めすぎ 0 と言い過ぎ 1(TR5-4)は、規則に合わせて書かれた資料での数で、ふつうの資料での止めすぎの数としては使えない。** 止めすぎの数として使えるのは、封の前に書かれた TR4 の資料での 0(TR5-6)だけ。ただし TR4 の資料も、席が全部の前期の数の近くに期の字を置いていた(R2 の止め 0)ので、期の字を離して書く資料での止めすぎはまだ測れていない。この漏れは記憶に教訓として残してあった形(盲検の席は直近の commit message を見る)で、それを書く席に当てはめなかった司令塔の欠陥。誤りを入れて止める割合 (b)・(d)・(a′) は機械が入れた誤りなので、この漏れの影響を受けない。ただし、資料の書き方(期の字を数の近くに置く)が規則に寄った結果として、R2 の効き(文の (b) の 6)は過大になりうる。R2 の効きは、規則を知らずに書かれた TR4 の資料の側(9)を参考にする。

## 4. 言えないこと

- R1・R2 は字の位置だけを見る。文の意味は見ない。
- 新しい資料の止めすぎは、規則を知った席の資料での数(§3)。ふつうの書き方の止めすぎは TR4 の資料の 0 だけで、期の字を離して書く資料では測っていない。
- 隠しは機械で入れた形だけ。書く席は札を誤らない前提のまま(この便でも札の誤りは 0)。
- (b) の表は、誤りの入れ方の欠陥のため、封の数(0 / 10)は規則の力を表さない。直した入れ方での数(10 / 10)は結果を見てから足した補足。
