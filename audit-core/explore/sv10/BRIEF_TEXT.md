# 文の席への頼み(便 SV10)

この紙と、file の名の並び(ある会社の経理の folder の中で、数の表ではないとして「原本のまま」にした file)と、その folder の path だけを渡す。並びに無い file・folder の外・repo の中は読まない。file は**読むだけ**(読む時は `python3 -I`)。

## 頼むこと

これらの file は、いま保存されたところです。何の資料に使うかはまだ分かりません。文の中に、後で資料に使えそうな**金額や人数などの数**が書かれていれば、1 つずつ拾ってください。

- 拾う数: 会社の金額・人数・件数など、決算や会社の説明に使えそうな数。
- 拾わない数: 日付・時刻・電話番号・番地・番号(伝票番号・社員番号など)・ページ・回数・手順の番号。
- 1 つの数ごとに、いつの・どの単位の・どんな性質の・どの範囲の数かを書く。文の字だけで決められない欄は `null` にする(推測で埋めない)。

## 形

`文の数.json`:

```json
{"数": [
  {"file": "file の名", "行": 12, "値": 23, "何の数": "期末の従業員の数(役員を除く)",
   "期": {"種類": "時点", "日": "YYYY-MM-DD"}, "単位": "人", "性質": "実績", "範囲": "全社"}
]}
```

- `行` は file の何行目か(1 から)。`値` は本当の大きさの整数(「1.2 億円」なら 120000000、「3 千円」なら 3000)。
- `期`・`単位`・`性質`・`範囲` の書き方は、保存の札と同じ(`期` は `{"種類": "期間", "始まり", "終わり"}` か `{"種類": "時点", "日"}` か `null`。`単位` は `円`・`千円`・`百万円`・`人`・`その他`・`null`。`性質` は `実績`・`予算・見込み`・`その他`・`null`。`範囲` は `全社`・`一部`・`null`)。`値` を本当の大きさで書いたので、`単位` は `円` か `人` か `その他` にする。

終わったら、拾った数の数だけを短く報告する。
