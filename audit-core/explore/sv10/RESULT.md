# 結果 ― 便 SV10: 保存の時に文の中の数を拾って貯めると、文の中にしか無い数を出せるか(2026-11-24)

封: [SEAL.md](SEAL.md)(commit 5a4b498a)。記録: [record.json](record.json)。script: [build_sv10.py](build_sv10.py)(SV7 の貯めた行に文の数を足す)・[tally_sv10.py](tally_sv10.py)(SV9 の新しい照合に文の行の扱いを足した TextCompany。流れの数え方は SV7 と同じ)。軽い型。engine 0 行・費用 0 USD。席は 6(文 3・埋める 3)で、やり直しは 0。数は外に出さない。

**直した欠陥(結果を見る前の数え直し):** 最初の集計では、文の中の項目 3 が 3 とも S1 で止まった。原因は司令塔の build_sv10.py で、文の行の map に `値` を入れていなかったため、照合が文の字の中の数と突き合わせられなかった(作法 5「0 件は自分の欠陥を疑う」)。map に `値` を足して作り直した。`貯め.csv` は作り直しの前後で sha256 が同じで、席の答えも替えていない。下の数は直した後のもの。

## 3. 読み

- **文の中にしか無い数は、保存の時に拾えば出せた。** 3 社とも、従業員の数を議事の記録の文から拾い、埋める席が貯めた行から正しく出し、照合も通った。
- **拾った数が別の取り違えを生まなかった。** 文の席の出力は 3 社で 6 で、資料に残る誤りは 0。
- **SV0〜SV10 の部品を合わせた形(この便の流れ)の数:** 3 社 93 行で、正しい行 86、資料に残る誤り 0、人に聞く項目 10(SV8)、聞いたり照合で止めたりした正しい行は 78 のうち 4。決めの行 9 のうち 3 は聞かずに通る(SV8 の読みでは、通った 3 は正解の読み)。

## 4. 言えないこと

- 文の席・埋める席は 1 社 1 回だけ走った。文の中の数を持つ素材は 1 社 1 項目(どれも従業員の数)。
- 照合の文の行の確かめは「その行の字に、値か値の千・万・百万・億分の 1 の数が在る」まで。1 や 3 のような小さい数は、行の字にその数字がどこかに在れば通るので、小さい数の誤りは S1 では止めにくい。文の意味が項目と合うかは、札(期・単位・性質・範囲)と埋める席に頼る。
- 素材は作り物。聞いた後の人の手間は測っていない。
