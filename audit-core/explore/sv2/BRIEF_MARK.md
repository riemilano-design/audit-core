# 印の席への頼み(便 SV2)

この紙と、folder 1 つ(ある会社の経理の file 一式)だけを渡す。司令塔は頼みの頭に「folder の path」と「答えを書く path」を足す。ほかの紙・repo の中・folder の外は読まない。folder の中の file は**読むだけ**(中の script は走らせない。読む時は `python3 -I`)。

## 頼むこと

この file 一式は、いま保存されたところです。後で誰かが、どれかの数を取り出して資料を作ります。何の資料かはまだ分かりません。

保存の時に、**後で取り違えやすい数**に印を付けてください。印の付いた数は、使う時に人に確かめさせます。印を付けすぎると、確かめる手間が増えます。

印を付けるのは、次のどちらかに当たる数です。

- 名前や意味が近く、期・単位・性質(実績か予算か など)も同じなのに、含む範囲や計算の仕方が違う数が、同じ file か別の file に在るもの。その組の両方に印を付ける。
- 1 つの数に、読み方が 2 通り以上あり、どちらの読みで使うかを人が決めるべきもの。

## 形

`紛れ.json`:

```json
{"印": [
  {"file": "file の名", "行": [12, 13], "列": [3], "訳": "どんな紛れか(短く)"}
]}
```

- `行`・`列` は 1 から数える(CSV の頭の行が 1 行目・左の列が 1 列目)。`列` を空のリスト `[]` にすると、その行の全部の列。
- 組の両方に印を付ける時は、file ごとに別の印にしてよい。
- 印が要らないと思えば、`{"印": []}` でよい。

終わったら、印の数だけを短く報告する。
