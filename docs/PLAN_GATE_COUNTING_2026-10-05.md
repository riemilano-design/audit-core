## 2. 司令塔の裁定(2026-10-05。この束に入るもの)

- **(xi) は誤り**(⑥ の限界ではない)。**用語・閾値・小数を「数の主張から外す例外の一覧」で直すのは採らない**
  (表から作った出力を同じ表と比べる家族。語が増えるたび一覧が追いかける)。
- 採るのは **型からの再構成**: 門が `exit_fill` の型(追跡された定数 1 か所)を知り、行を型に当て、**穴に入った数だけ**を集計行の数と照合する。
  **型の字の中の数**(第 1 候補の 1・+300・10 秒・4 秒)は主張ではない。**型に当たらない行は今の `number_claims` のまま**。
  **`slot_map` を信じるのではなく、行から再構成して一致を見る。**
- ⑧ の印の数え方の直しを同じ 1 束に入れる(2026-10-01 の訂正: 印は印字されないので文字数の門が数える理由が無い)。

## 3. 設計

### 3.1 G-1 ⑧ の数え方(**なぜ**: 印は印字されない。持ち分 200 は顧客に出る字の枠)

`check_structure.question_section_body` が、行ごとに **印の文法の家族ぜんぶ**(`pos`・`menu`・`priority`・`agg`・`ans`)を剥いてから
`.strip()` して繋ぐ。家族の一覧は **`check_answer.MARK_TAG_RES`(新しい tuple 1 つ。既存の 5 つの正規表現を並べるだけ)**に置く ―
文法そのものは今までどおり `check_answer` の 1 か所で、一覧もその隣。`scan_numbers` の 3 行は触らない(G-4 で「2 か所に並んでいる」と上げる)。

**期待の数**(測ってから書く): `exit_fill_test.f25` の **163 → 133**(53 + 80。印 29 と、印の前の空白 1 は `.strip()` で落ちる)。
`check_structure_test.q16` の **115 は不変**(土台に印が無い)。**133 と 134 の両方を試験に書いて取り違えを赤にする**(空白を数える変異)。

**理由を破る変異**: 剥かない / 1 家族だけ剥く(`ans` だけ)/ 剥いた後の空白を数える / 一覧を `check_structure` に写す(写しの変異は構造の試験で)。

### 3.2 G-2 (xi) の型からの再構成(**なぜ**: 型の字の中の数は主張ではない。穴の数だけが主張)

`exit_gate` に **`fact_line_holes(line, templates)`** を 1 つ足す。

1. 行から印を剥く(`MARK_TAG_RES`)。先頭の `- ` を落とす。
2. **`exit_fill.READING_PREFIX`(`― 読み: `)で事実部と読み部に割る**(無ければ全体が事実部)。
3. 事実部を**型の並びの連結**に当てる。型は 2 種で、どちらも `exit_fill` の定数から作る(写さない):
   - 接続型: 候補の JSON の `actionFractions` の `name`・`unit` ごとに `exit_fill.connective_fact(name, 穴, 穴, unit)` の形を正規表現にする
     (穴 = `(\d+)`。字の部分は `re.escape`)。
   - 優勢後敗: `exit_fill.AHEAD_THEN_LOST_TEMPLATE` の穴 2 つ。
   事実部が**型の連結でちょうど尽きる**(余りが 0 文字)ときだけ「型に当たった」。1 本以上・順は任意。
4. 当たったら、**穴の数**(分子・分母)を集計行の数(その行の印ぜんぶの合併)と照合する。
   読み部は**今の `number_claims`** で同じ合併と照合する(**Q1** を参照)。
5. 当たらなければ**今の `number_claims`** のまま(行全体)。

**なぜ候補の `name` を型に使うか**: 事実の文は `check_answer` の `name`(審査済みの字)から作られる(司令塔の判断 (D))。門が同じ `name` から型を組めば、
**⑥ の出力と門が同じ 1 か所の字を見ている**ことになる。`slot_map.json` は読まない(司令塔: 信じずに再構成)。

**理由を破る変異**: 穴以外の数も照合する / `slot_map` の `text` と比べて通す / 型に当たらないのに通す(余りを許す)/ 読み部を照合しない /
穴の数を集計行と比べない / 型の字を 1 字変えても当たる(`re.escape` を外す)。

### 3.3 G-3 ⑥ は門の判定を呼ぶ

`exit_fill.agg_marks_for` の中の判定(`number_claims` ⊆ 集計行)を、**`exit_gate` の新しい関数**に置き換える(⑥ の中に判定の写しを残さない)。
通れば印を付け、通らなければ今までどおり注記(読み部に集計に無い数が在るときはまだ付けられない ― それは ⑤ の採用の側)。
**期待**: 封じた形の 3 本は**事実部は全部型に当たる**。読み部の数が印の集計行に在れば **3 / 3 に印が付く**。
