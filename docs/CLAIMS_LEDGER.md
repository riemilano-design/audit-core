# 主張台帳(Claims Ledger)

**営業・資料・外部への説明で使う数は、この台帳の行から引く。チャットの数・他席の報告の数を直に使わない**
(人間の決定 `R-2026-10-12-03`「営業が使う数字は、台帳の行番号で引く」)。

## 決まり

1. **1 数 1 行。** 数を出したコミットと同じコミットで行を足す(後から集めない)。
2. 各行に必ず: **数 / 分母 / 区間(あれば)/ 範囲の限定 / 出どころ(commit)/ 再現コマンドか根拠ファイル / 言ってはいけないこと**。
3. **範囲の限定を省いた引用を禁止**する。「1 書類のみ」「1 モデル・1 生成」等は数と同じ文に書く。
4. 測り直して値が変わったら**行を書き換えず、新しい行を足して古い行に「置き換えられた」と注記する**(履歴を消さない)。
5. **未測定は「0 件」と書かない**(例: A5)。
6. 書き手は司令塔のみ。
