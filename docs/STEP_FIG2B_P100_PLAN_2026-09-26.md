## 0. 先に報告すべき 3 つの事実(計画より重い)

### (あ) **`figure: false` は、本番の形の一覧(82 形)では構造上たどり着けない**

`figure = candidates.length > 0`、`candidates = rankReachableShapes(results, [])`。
`rankReachableShapes` の除外は 2 つだけ ―(1) `side === "opponent"`、(2) `status === "completed"`。
したがって **`figure: false` になるのは、自分側の形(`side` が `self` / `both`)が 1 つも残らないときだけ**で、条件は:

| | 条件 | 本番の一覧(82 形)で起こるか |
|---|---|---|
| **C1** | 渡した形の一覧に**自分側の形が 1 つも無い**(opponent だけ・空) | **起こらない**(自分側 47 形が常にある) |
| **C2** | **自分側の形が全部 `completed`** | **起こらない** ― 47 形は玉の位置などが互いに矛盾するので同時に完成できない。実測でも 167 局面すべてで `completed` は **0 件**(候補数が常に 47 = 47 形がそのまま残っている) |

**つまり P-100 は「材料にその場合が無い」のではなく、「本番の入力では通らない枝」です。**
これは P-94 の型(材料が無いだけ)とは**別の型**で、材料を増やしても通りません。

### (い) **顧客から見た「図を出さない」は、いま別の場所で決まっている**

司令塔の (b) の決定は「**`hedged` が 0 件の局面は選ばない**」で、これは **87 / 167 局面**に当たります。
**顧客の目に見える「図が無い」を実際に決めているのはこちらで、道具の `figure` ではありません。**
`figure` は「到達できる候補が 0 件」という別の意味の旗です。**2 つが別物であることが、今いちばんの穴**です
(自動化したとき、`figure` を見て「図あり」と判断し、`hedged` が 0 で図が描けない、という食い違いが出る)。

### (う) **冊子側(render)は、まだこの道具を読んでいない**

`git grep` で `shapeCandidates` / `figShapeCandidates` を参照しているのは**この道具自身の 3 本だけ**
(監査も同じことを確かめている)。**したがって「`figure: false` のとき冊子が何を出すか」は、測れる対象がまだ無い** ―
落ちるのでも空の枠が出るのでもなく、**誰も読んでいないので何も起きない**が正確な答えです。
**この問いが本当に効くのは、組版の道具を作るとき**で、そこが司令塔の言う「手で流し込む席の目が消える」場面です。

## 5. 司令塔の判断(2026-09-26)。STEP を 2 本に分ける

司令塔も §0 の 3 点を独立に確かめて一致。**(い) は依頼より重い発見**という評価 ―「道具が `figure` という名前で出している旗が、紙面が図を出すかどうかとは別のことを言っている」。**名前の付け方の穴。**

  この「バイト不変」を安全装置として残すため、**意味を変える変更と同じコミットに混ぜない。**
- **STEP 2(STEP 1 のコミットの後、別の計画・別のコミット)= 名前を取り違えられない形にする。判定は変えず足すだけ。**
  - いまの `figure`(到達できる候補が 1 件以上)を**名前だけ**意味の読めるものに(例: `hasReachableCandidates`)。値は不変。
  - **`drawable`(`hedged` が 1 件以上)を新設** ― これが紙面の判断と同じ意味の旗。
  - 期待値を先に書く: `run1.json` は変わる(キー 1 つ改名 + 真偽 1 つ追加、**`drawable: false` が 87 / 167**。**87 以外が出たら止める**)。
  - **改名が安いのは今だけ**(読んでいるのは自分の 3 本だけ。組版が読み始めると高くつく)。

**② 形の一覧が空 → 例外にする(STEP 1 の範囲)。** 0 件は正当な入力ではなく**読み込みの失敗**で、黙って `figure: false` を
返すと失敗が「図なし」に化ける。**しかもこちらは実際に起こりうる**(ディレクトリの取り違え・パスの変更)。
**例外の文面に、どこを読もうとしたか(ディレクトリのパス)を入れる。** → §1 の 1 の 3 本目は「空 → `figure: false`」ではなく
**「空 → 例外(パスが文面に出る)」**に変える。期待値: 新しい試験は 3 本(C1・C2・空で例外)で変わらず。
