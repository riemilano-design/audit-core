## 4. 判定

| 問い | 答え |
|---|---|
| 構成を凍結したまま別の 1 社に当てて、層・form・modifier・scheme は増えたか | **増えなかった(0 / 0 / 0 / 0)。** 増えたのは Adapter の登録簿(セグメントの member・語彙・正規化 2)だけ |
| 束縛と一致の率は移ったか | **移らなかった。** 束縛率は範囲内だが、束縛内 GROUNDED 率と再計算一致率は半分以下に落ちた。原因は 1 つ(セグメント)が大半で、語彙の固有性が残り |
| 通った誤りはあるか | **0**(2 社とも)。誤りは全部 VALUE_MISMATCH か未束縛で、止まる側 |
| v0.2 は「将棋 + 1 社に寄った仕様」か | 層と形の側では寄っていない(2 社目で増えなかった)。**登録簿の側は会社ごとに育つ**(語彙 34 語のうち移ったのは 4 語) |
| Core 接続の GO / NO-GO | **まだ判定しない。** 計器 4 つ(予測 §4)は接続のときに測る。2 社目は「接続前に層が増えない」ことを 1 回分増やしただけ |

**一言**: 2 社目でも 4 層・4 form・3 modifier・1 scheme は維持された。しかし率は会社の書き方(セグメント・千円・状態の語)で大きく動き、語彙は移らない。**「構造は移るが、率と語彙は移らない」**。これが Adapter の登録簿を会社ごとに持つ設計の実測の根拠になる。
