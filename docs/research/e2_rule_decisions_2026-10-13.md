## 規約 1: 方向(増加/減少)の主張の根拠

| 欄 | 内容 |
|---|---|
| **採用案** | 文が CF 計算書の行の名前で「〜の増加/減少」と書いている場合、**根拠は CF 計算書の調整項目 1 件とし、残高の 2 時点は含めない** |
| **反対案 A** | 残高の 2 時点も根拠に含める(席 2 の読み)。理由: 方向は残高の大小でも決まる |
| **反対案 B** | 方向の主張は**根拠を定めない**(E2 の対象外にし、別の指標で扱う) |
| **測定値への影響** | 方向の形は GROUNDED 14 件。E2 は**厳密 5 件(35.7%)/ 同値類 v0 で 3 件(21.4%)**。値を持つ形(44 件)の E2 は厳密 8(18.2%)/ 同値類 3(6.8%)。**方向を主分母から外すと E2 の率は 22.4% → 18.2%(厳密)、10.3% → 6.8%(同値類)に下がる** |
| **独立ラベルとの整合性** | **採用案を採ると不一致が 3 件減って確定になる**(T097・T093・T092 は 2 席とも CF の調整項目では一致し、残高の対を足すかだけが違う)。反対案 A を採ると同じ 3 件が確定(席 2 の側)。**どちらでも 3 件は確定する**が、**正解の中身が変わる**。判定不能(片側)の 2 件(T034・N062)も同じ引当金の CF 項目で、同じ規約が効く |
| **封印済み条件との関係** | 封じた事前登録(§3)の一致の定義は「ラベルの fact 集合と**集合として一致**」なので、根拠に残高の対を含めるかは**ラベル側の定義**であり、採点器は変えずに済む。ただし**ラベルを作り直す**ことになる(T097・T093・T092 の 3 件)。既存の封(`INTEGRATED_SEAL` ほか)はこの規約に言及しておらず、抵触しない |
| **採用しない場合に残る問題** | 方向の主張 38 件(確定ラベルの 21%)の正解が決まらないまま 2a を走らせることになり、その 38 件については E2 を計算できない |

## 規約 2: 率(比)の主張の根拠

| 欄 | 内容 |
|---|---|
| **採用案** | **率そのものの fact が在ればそれを根拠とし、無ければ分子・分母の 2 fact を根拠とする** |
| **反対案** | 率の fact が無い場合は**判定不能**にする(根拠を合成しない) |
| **測定値への影響** | 確定ラベルの率は 13 件。**第 2 便で `分子`・`分母` の役割欄を足したことで、第 1 便で形式差により不一致だった 4 件(N037・N148・N036・N103)が 2 席一致で確定した**(別の 2 席による再判定)。採用案を取り消すとこの 4 件が判定不能に戻る |
| **独立ラベルとの整合性** | **整合する。** 自己資本比率・ROE のように率そのものの fact が在る行(N113・N252)では席が率の fact を選んでおり、無い行(売上総利益率・負担率)では分子・分母を挙げた。**席の振る舞いが採用案と一致している** |
| **封印済み条件との関係** | 封じた一致の定義は集合一致なので、率の根拠が 1 件でも 2 件でも採点器は同じ。**抵触しない** |
| **注意** | engine は率の主張に対し額の符号や額そのものに結ぶため(T023・T038・T086)、この規約を採ると engine 側が不一致になる件数が増える。**これは規約の欠陥ではなく engine の挙動の可視化**である |

## 規約 3: 同値類に `OrdinaryIncomeLoss` ↔ `OrdinaryIncome` の対を足す

| 欄 | 内容 |
|---|---|
| **採用案** | 同値類 v0(末尾の `SummaryOfBusinessResults` を除いた名前が同じなら同値)に、**`…Loss` の有無で名前が割れる対**(`OrdinaryIncomeLoss` ↔ `OrdinaryIncome`)を明示的に足す |
| **反対案 A** | 同値類を**一切使わない**(封じた事前登録 §3 が実際にそう書いている: 「同値類は**使わない**」) |
| **反対案 B** | 同値類の代わりに「**値と期間が同じ fact は 1 つの同値類**」と機械的に定義する(名前に依存しない) |
| **測定値への影響(いちばん大きい)** | **同値類 v0 の有無で E2 が 13 件 → 6 件に変わる**(58 件中。22.4% → 10.3%)。**`…Loss` の 1 行(N089)を足すと 6 → 5 件(8.6%)**。つまり**規約 3 の採否だけで E2 が 5〜13 件の間を動く** |
| 同値類 v0 で判定が反転する 7 件 | N105・N014・N009・N130・N131(単一・差・率)と T049・T044(方向)。**全部が `jpcrp_cor:…SummaryOfBusinessResults`(主要な経営指標等の推移)↔ `jppfs_cor:…`(本表)の対**で、値・期間は同じ |
| **独立ラベルとの整合性** | 席は 3 席とも「本文が財務諸表の科目名を使っているので本表側を選ぶ」規約を理由欄に明記し、**同値の他の候補として Summary 側を列挙している**。つまり**席は「どちらとも決められない」と記録している**。確定ラベル 183 件中 83 件(45%)に同値の他の候補が在る |
| **封印済み条件との関係(重要)** | **封じた事前登録 §3 は「同値類は使わない」と書いている。採用するには封の再発行が必要。** さらに、**帯の根拠にした実装席の 5/60 = 8.3% は、この 7 件を全部 `correct` と判定している**(= 実装席は暗黙に同値類を使っていた)。**帯の根拠と、封じた一致の規則が互いに矛盾している**(§2 の比較可能性の判定の根拠) |
| 反対案 B の評価 | 「値と期間が同じなら同値」は名前に依存しないが、**概念違いを同値に飲み込む**(N092 特別利益 1 百万円 ↔ 固定資産売却益 1 百万円、N137 現金及び預金 ↔ 現金同等物)。再監査 B の notes が実例を挙げている。**採らない方がよいと考えるが、決めるのは人間** |

## 規約 4: T025 を判定不能のままにする

| 欄 | 内容 |
|---|---|
| **採用案** | 文の語が 2 つの異なる数を同時に受ける主張(T025「人員は着実に増加」が従業員数 1,462/1,447 と臨時従業員 409/393 の両方を受ける)は、**判定不能のままにする**(規約で片方に決めない) |
| **反対案 A** | 抜粋の窓の位置に近い方(臨時従業員)を採る(席 1 の読み) |
| **反対案 B** | 両方を根拠に含める(席 2 の読み。4 fact) |
| **測定値への影響** | 1 件のみ。確定ラベルは 183 → 184 になるが、**T025 は main の記録に pointer が無い**ので E2 の数は変わらない |
| **独立ラベルとの整合性** | **2 便・4 席すべてで不一致**(第 1 便の 2 席、第 2 便の 2 席。第 2 便は役割欄を足した材料でも一致しなかった)。**材料の欠陥ではなく文の多義性**であることが、欄を直した再判定で確かめられた |
| **封印済み条件との関係** | 抵触しない。封じた採点の定義は「両方が独立判定で fact が違う → 不一致。多数決・第 3 席の裁定はしない」であり、**採用案はこの定義そのまま** |
| **私の意見** | 採用案を推す。これは Claim の切り出し側(1 文に 2 系列の数が入る窓)の問題で、根拠の規約で解くと「窓の位置で概念を決める」ことになり、engine の部分一致と同じ弱点を正解側に持ち込む |

## 規約の相互作用(採否の組み合わせで E2 がどう動くか)[測定]

分母は **pointer が記録されている GROUNDED 58 件**(条件つき。登録定義の分母は 90 で、§2 を参照)。

| 規約 1(方向を主分母から外す) | 規約 3(同値類) | E2 | 率 |
|---|---|---|---|
| 外さない | 使わない(**封じた定義**) | **13 / 58** | **22.4%** |
| 外さない | v0 | 6 / 58 | 10.3% |
| 外さない | v0 + `…Loss` | 5 / 58 | 8.6% |
| **外す**(値を持つ形 44 件のみ) | 使わない | 8 / 44 | 18.2% |
| **外す** | v0 | 3 / 44 | 6.8% |
| **外す** | v0 + `…Loss` | **2 / 44** | **4.5%** |

**同じ材料・同じ engine の出力で、規約の採否だけで E2 が 4.5% から 22.4% まで動く。**
したがって**規約を決めずに 2a を走らせても方式の比較はできない**。これが本監査の最大の所見である。

## 追記 2026-10-13(本文は 1 行も変更していない。追記のみ)

**規約 1 の欄の「判定不能(片側)の 2 件(T034・N062)も同じ引当金の CF 項目で、同じ規約が効く」は誤りである。**
席 1 の回答を読み直した結果、この 2 件の判定不能の理由は「残高の対を足すか」ではなく、**文に概念名が無い**(「この786百万円の増加は」の指示語「この」の先行詞が別の文にある)ことであった。席 1 は自身の規則「値の一致だけが決め手になる場合は判定不能」を適用している。**規約 1 を採っても解決しない。**

したがって **5 つめの規約が必要になる**: 指示語で主語が文の外にある主張をどう扱うか。main はこの 2 件を `UNVERIFIABLE / no_subject` で止めており、**止め方としては正しい**。判定不能のままにすると、この 2 件は E2 の分母にも E3' の分母にも入らない。
