### 2.1 `scripts/playtest/report-pdf/check_answer.py`(python。fitz で付録 2 の印字を読むため)
入力: B の markdown と、**組ごと**(前回 20 局・今回 14 局・10 分 10 局の 3 組。組ごとに `--time-limit-sec`)の `patient_report_data.json`(findings・time・overview・games)、`whatif_report_data.json`、READ の jsonl のフォルダ(summary 行を合算)、whatif-v2 の jsonl のフォルダ(M4 の側の一致を数える)、`whatif.pdf`(付録 2)、`type-combined/summary.json`、メニュー(§3 を JSON にした `answer_menu.json`)。3 分の 2 組は合算して「34 局」の数を作る(分子・分母を別々に足す)。出力: rc=0 なら通過、rc=1 なら**落ちた文と理由の一覧**。

検査(すべて機械):
1. **数の照合**: 単位つきの数(局・回・手・秒・ポイント・%・ノード・/ の分数)は、許す集合になければ落とす。許す集合 = 上の JSON にある値(組ごと・合算)+ JSON の分数から計算した割合(四捨五入の整数 %)。**「a / b」「n のうち m」「n 局のうち m 局」の形は、登録済みの組**(timeUpLosses の n/m、aheadGames/aheadLossGames、bySpent の各段の fell/n、afterLongThink の fell/n、tagCrossTable の sacrifice 行合計/対角、firstVisibleNodes の 600 以上/分かれ道、M4 の側の 2 分数、opponentReplyMatchesPv の matched/measured)のどれかに一致しなければ落とす — 単独の数がどこかにあるだけでは通さない(別指標の数の接続を落とす)。単位の無い小さな数(「2 つ」「3 段」「1 行」「(a)」)は対象外。**「〜倍」「〜割」は許さない**(書くなら元の 2 つの数を並べる)。
2. **手の答え合わせ**: 「▲」「△」で始まる指し手の表記は、付録 2(`whatif.pdf`)の印字に**同じ文字列**が無ければ落とす。「第 1 候補は ▲X」の形は、その手が付録 2 の該当局の候補の 1 番目でなければ落とす(局と手数が文に書いてあること: 「n 局目 m 手目」の形を要求)。
3. **禁止語と断定**: 禁止語 18 + 「すべき」「した方がよい」「すれば直る」「間違いなく」「危ない」「確実」「絶対」「安い」(§1 と同じ一覧)。
4. **行動のメニュー**: 「こうしてみては」の各項目は `<!-- menu: M1 -->` の印を持ち、M1 が `answer_menu.json` にあり、**その条件(§3 の「出す条件」)が今回の JSON で成り立つ**こと。成り立たなければ落とす。印の無い行動の項目は落とす。**印の外の行**でも、行動・優先順位の表現(「してみては」「を目安に」「を選ぶ」「選ぶなら」「1 つだけ」「先に」「〜で指す」「〜を混ぜる」「候補に入れ」)を含む行は落とす。例外は `<!-- priority: M1 -->` の印がある段落(その M が成立していること)。
5. **数が足りなければ言わない**: メニューの各行動に `minN`(根拠の数の分母の下限)。下回れば落とす。
6. **戦法・陣形の名前**: `data/` のレビュー済みの形の名前の一覧(`review_status` が `human_reviewed` または `expert_verified` のもの。2026-09-24 時点で 5 件)に無い戦法名(「〜戦法」「〜囲い」「〜飛車」「〜銀」の語)は、「〜のような形」の後ろに付いていなければ落とす。
