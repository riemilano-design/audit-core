# 行動の表の拡張案(下書き。**承認前**)

**これは何か**: 冊子の「こうしてみては」で使える行動の**案**である。2026-09-25 夜の人間の指示「癖だけでなく、アドバイスも必要」(DESIGN_BRIEF_OBSERVATION_LAYER_2026-09-25.md §5 #2b、`e7ffcfd`)を受けて、知識レーンが 4 領域(側・形・反応・分かれ道)について下書きした。

**これは何ではないか**

- **承認済みの行動ではない。** 承認済みの表は `scripts/playtest/lib/answerMenu.ts` の `ANSWER_MENU`(M1〜M9)だけで、この下書きはそこに**入れていない**。表に足すのは人間の承認が要る(CLAUDE.md「絶対に守るルール」4 番の判断的知識)。
- **冊子にこのまま載せるものではない。** 司令塔が PDF の見本に「(承認待ちの案)」の印つきで載せ、人間に見せる工程がある。
- **条件を判定するコードではない。** 条件の関数は開発・診断レーンの仕事(§5 の順 #7)。ここに書いた「条件」は、**どの数を見れば出せるか**を人が読める形にしたもの。

**書き方の規則(依頼のとおり)**

| 欄 | 中身 |
|---|---|
| 条件 | 冊子が**数から言えること**。観測項目([DESIGN_OBSERVATION_LAYER_2026-09.md](../../../../docs/DESIGN_OBSERVATION_LAYER_2026-09.md) §1・§2 の `obs.*`)に実在する数だけを指す |
| 合図 | **対局中に本人が自分で気づけること**。評価値・エンジンの候補・「優勢かどうか」は使えない([DELIVER_GATES.md](../../../../docs/DELIVER_GATES.md) §2.5 の教訓。分析の条件を発動の合図に写さない) |
| 行動の核 | 1 文。**指すことを勧める形にしない**。「候補に入れてから比べる」「〜してからひと呼吸」の型 |
| 答え合わせ | 次の 20 局で動くはずの数(参考。`verifyName` に当たる) |
| 出典 | URL + 参照日。丸写ししない |
| 言葉 | 用語に初心者向けの説明を添える |

**合図に使わないもの(2026-09-25 夜の人間の軌道修正。DESIGN_BRIEF §5 `3b58350`)**: **時計の数は合図に使わない。** 「残り時間を見る」「X 回目の長考で」「N 秒迷ったら」の型は作らない。**時間は症状として観測する側に置き、時間が必要になった理由を形・攻守・反応・分かれ道・知識から説明する**のが人間の方針である。時間の帯(5〜9 秒など)を**条件**に使うのは構わない ― 使わないのは**合図**のほう。これは既存の「評価値・エンジンの候補・優勢かどうかを合図に使わない」(DELIVER_GATES §2.5)に並ぶ 2 つ目の禁止である。

**対象の顧客**: 3 分切れ負けが主、玉が最初の場所から動かない局が多い、囲いを組まないことが多い初心者。
