# 統合(役 C・2 周目)― `p4` の 3 分の組 18 局、15 本の読み

**入力**: `04b-H-<レーン>-00N.json` 15 本、`00-obs_snapshot.p4.min3.r2b.json`(**48 項目**。統合役は 49 と書いていたが、実物は 48 ― レーン長が数え直して直した。49 は STEP OBS-5d で写しの道具に足した後の項目数で、この周の役に渡した写しはその前に作ったもの)、`hypothesis.v0.3.schema.json`、`docs/OBSERVATION_ITEMS.md` §1。
**役割**: 整理者。そのうえで「いま一番通る読み」を 1 つ選ぶ。将棋の事実判断はしない。形・戦法・狙いの名前は写しに無いので一切書かない。
**言える範囲**: この顧客の 3 分の組 18 局だけ。初心者一般には広げない。

**`result` を並べ替えにも足切りにも使っていない。** 15 本とも `weakened` で、これは分母が小さい材料では反証がいつでも「分母が小さい」を挙げられることの反映(P-93)であり、読みの優劣ではないため。見たのは `counterEvidence.items` の中身だけ。

**3 値の付け方(この文書の中で一貫させた決め)**: `stands_after_refutation` = 文に出た数と向きを打ち消す項目が無く、反証は範囲を狭めるだけだったもの。`weak` = 文に出た向きの一部が、同じ写しの数で打ち消されたか、ほぼ空の分母の上に乗っていたもの。`refuted` = 文に出た数そのものが写しと食い違うもの(**0 本**)。**「正しい」は無い。**

## 7. 新しい仮説の候補(`counterEvidence.items` の `alternative`。ID 無し・文だけ)
