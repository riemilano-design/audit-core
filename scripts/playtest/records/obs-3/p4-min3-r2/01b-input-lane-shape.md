# 役 L-形(2 周目・第 2 陣。この周から入る新しい役)への入力(2026-09-26)

共通の指示は `01b-input-common.md`。**先にそれを読むこと**。ここには、あなたの役に固有のことだけを書く。

## あなたの役
- `lane`: `"shape"`。ファイル名の `<レーン>` は `shape`。

## 問い

> **この人の陣形づくりは、どの段階まで進んで、どこで止まっているか。止まり方は局によって違うか、それとも同じところで止まるか。**

**「どの囲いを目指していたか」を当てる役ではない。** 写しには形の名前も id も入っていない(下の「名前は渡していない」)。あなたが見るのは **`none` / `forming` / `completed` の件数と、「あと 1 枚」「数え直し」の数だけ**で、答えるのは **止まる段階**についてである。

## 使ってよい観測(この周から入った新しい 6 項目が中心)
- **中心**: `obs.vocab.shapeStatus`(形の認識の状態の件数。自分側・相手側 × `none`/`forming`/`completed`)、`obs.vocab.shapeMissingSummary`(`shapeMissingTotal` = 欠けたマス・駒の延べ、`selfClosestOneAwayGames` = 自分側の「最も近づいた形」の欠けがちょうど 1 枚だった局の数)、`obs.vocab.shapeMovedRequiredSummary`(`completeTotal`・`zeroCount`)
- 併せて: `obs.vocab.openingStatus`・`obs.vocab.intentStatus`・`obs.vocab.exposure`、`obs.eval.game`・`obs.eval.score`、`obs.report.overview`・`obs.report.event`、`obs.time.perMove`・`obs.time.phaseMoves`(陣形づくりに使った手数と段の関係を見る目的でなら引いてよい)
- `obs.geo.moveCombination` の `facts.kingMove`(玉を動かした手の数)は引いてよい
- `obs.menu.*` は読んでよいが仮説の根拠にしない

## 数の性質(**必ず読むこと**。ここを取り違えると読みが壊れる)
1. **`shapeStatus` の件数は「延べ」**(局面 × 形のレコードの数)であって**局数ではない**。18 局・594 局面 × 形 82 種(自分側 47・相手側 35)を数えた結果である。**局数に言い換えない**(「18 局中 N 局」と書かない)。
2. **`selfClosestOneAwayGames` だけが局数**(18 局のうちの数)。分母が違う数なので、1. の件数と同じ文に並べない(**P-89**: 行は組で絞るのに数は絞らない、という取り違えが実際に 2 回起きている)。
3. **`shapeMovedRequiredSummary.completeTotal` は「形が完成した局の数」ではない**(**既知事項 P-90**)。この数え直しは**平手の初期配置にある必要駒を分母から外す**ので、**外した駒がその後に動いてしまった局でも「揃っていた」に入る**。**「完成した」「囲えた」と言い換えないこと。**
4. **`zeroCount`** は「初期位置から動かす必要がある駒が 1 枚も無い形」の数(= 数え直しが測れない形)。自分側 0・相手側 0 なら「全部の形が測れた」と読む。
5. **初期配置の駒が『そろった』証拠に数えられる**という既知の誤認が 2 つある(**P-85・P-86**)。そのため「そろっている」側の数(`completed`・`named`)は、**動かしていないだけのものを含みうる**。この点は `obs.vocab.exposure` の `hedged`/`hidden` の多さにも表れている。**「そろっている」を強く読まない**。

## 名前は渡していない(規則 8 (4))
写しには**形・囲い・戦法・狙いの名前も id も入っていない**(白いリストの門で意図的に落としてある)。**自分の将棋の知識で名前を補わないこと**。「どの囲いか」を推測して書いた時点でこの役の仕事から外れる。

## 前書き(**仮の材料**。背景としてだけ使い、仮説の根拠にはしない)
レーン長が写しに載っていない内訳まで見て数えた事実として、**欠けがちょうど 1 枚だった 13 局のうち 10 局は同じ種類の駒が 1 枚欠けており、残り 3 局は別の 2 種類だった**。また **18 局のうち 5 局は 2 枚欠け**だった。**この数は写しに無いので `observations[]` にも `prediction.metric` にも使えない**(obsId が無く、H-2 で落ちるのが正しい)。**どの駒か・どの形かは渡さない**(名前と盤を役に渡さない門のため)。

## 弱い読みも出す
自分側の `completed` が 0 であることは、**「囲えていない」という結論ではなく、「どの段階で止まるか」を聞く入口**である。`forming` の件数が大きいこと・「あと 1 枚」が 13 局あること・数え直すと件数が減ることを、**別々の読みとして 2〜3 本に分けて出してよい**(1 本にまとめない)。分母が小さい・弱いと思う読みも出し、弱さは `prediction.alsoRequires` に「確かめるのに要る局数・件数」として書く。
