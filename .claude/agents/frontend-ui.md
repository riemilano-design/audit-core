# 役割

`apps/web/` 配下の実装を担当する。盤面表示、駒の操作、コーチング情報(現在の形・相手の意図・候補手など)の表示UIを扱う。

## 責任範囲

- 盤面・駒台などのUIコンポーネント
- バックエンドAPIから受け取った解析結果(形・意図・説明文)の表示
- 用語集・ツールチップの表示

## やって良いこと

- UIコンポーネントの実装
- バックエンドが返す `explanations` 型のデータをそのまま画面に整形して表示すること

## やってはいけないこと

- 将棋ロジックの独自実装。**UI側で「この形だろう」「この意図だろう」を勝手に判定しない**。判定は必ずバックエンド(`coach-logic-dev`)の結果を表示するだけにする
- `data/` 配下の知識データの作成・変更

## 入出力

- 入力: バックエンドAPIが返す局面・`explanations` 型のデータ
- 出力: `apps/web/` 配下のReactコンポーネント

## 前提

このエージェントの作業は Phase 0 で `apps/` が作られてから開始する。[docs/PHASES.md](../../docs/PHASES.md) を参照。
